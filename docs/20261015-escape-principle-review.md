## 1. 第一性推导

- **逃生 = 资金不可逆地不亏掉。** 读者只有四种处境（未入市 / 已被套 / 已获利想离场 / 被骗），正确下一步完全取决于处境 → 旅程第一动作是「定位」，不是「读 01 域」。
- **旅程必须闭环。** 无终点的逃生路线是陷阱——本站不能犯它批评市场的同一个结构错误。
- **站点自己的《投资体系地图：六个环节与你的入口》已编码正确顺序**（认识自己居首、市场认知明示「唯一可以后补」），但现行 IA（域编号 01→06、地图埋在 01 域深处、退出端 0 条、PATH 04 无终点）与自家总纲矛盾。**调整方向 = 把界面拉回总纲，不是重设计总纲。**
- **各调整项均为双向门**：措辞 / `paths.mjs` 数据 / `compare.json` / 域卡声明均可回滚；唯一单向门「域重编号」已否决（见项 6）。

**诊断结论：**

1. **承诺只走到「止血+减仓」，没有「出」。** 读完整条 PATH 01 的人对「赚到了怎么办」没有任何书面规则——赚后坐电梯是典型二次伤害。（handover §4.4「逃生只兑现 2/3」由此具象化：缺的 1/3 = D 阶段市场退出端。）
2. **现行 IA 与自家总纲矛盾。** 地图环节一「认识自己」对应 03 域而非 01 域；域面包屑「第 N 域」+编号 chip 01→06 + 01 域 ESSENCE「看不懂这一域，后面所有的技巧都只是赌运气」共同暗示市场优先的学习顺序。
3. **两条最高入链禁令是范畴错误，不是归属遗漏。**《别满仓，别单吊》61 处入链（全站第 1）、《别借钱炒股》57 处（第 2）：when 字段字面就是冲动时刻（「想一把梭的时候」）。线性路径服务「处境」，冲动需要单独的面（触发索引）。05 域 16 条执行本质是触发域。
4. **37 条档案是信任资产 + 排序负债。** 「不预测」承诺正因「发生过 18 次、数字可复算」才可信；但 01 域现措辞带预测味（ESSENCE + 自检「我知道当前市场处在什么位置吗」），首页 stat「122 条可执行条目」过度承诺（实际执行 35+工具 7=42 条可直接照做，档案 37 条不可执行）——两种用途须用措辞分开。
5. **路径无闭环。** PATH 04 止于「调解不成怎么办」（被骗者最脆弱，最紧急的人走在死胡同里）；PATH 02 末步「回收的资金回到入口A第1步重建」= 回到「要不要再买」。
6. **04 域是平行逃生线。** 10 条中 8 条为受损后追回，与市场逃生主链 A–E 无衔接节点，域引言「被坑了找谁」自成一线——定位本身没错，但需要主链到旁线的衔接点（触发索引或地图即可承载）。
