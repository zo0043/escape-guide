## 1. 不可妥协清单（内核）

判断标准只用一条：**这个要素负责的是不是「可信度」与「差异化」的最后一公里——丢掉它，122 条就退化成一个普通炒股博客，而不是一本可核的手册。** 下面逐条，每条先给「为什么不可丢」，再给「反方手里最硬的那张牌」（即我主动交出去的反驳口径，完整攻防见 §4）。

### 1.1 证据分级 A/B/C + C1/C2/C3（含转引不升格、不编造链接）

- **为什么不可丢**：证据等级只回答一个问题——「这个说法的数字可不可信」，它不衡量收益大小（`about.md:117`）。这是全站可信度的**单一原子**：A＝有一手数字、B＝有监管原文/同行评议但只能引定性、C＝经验或共识无出处（`about.md:119-123`）。更重要的是它有三个把「自我定位」做实的推论——**转引不升格**（`about.md:136`：站内条目互相转引不把 B 洗成 A）、**C 拆 C1/C2/C3 三个子档**（`about.md:139-149`：史料不可核 / 民间共识无出处 / 二手通说待核）、**不编造链接**（`about.md:149,162`：C 级如实写「无一手出处」）。这三条把「诚实」从口号变成可机读的字段。
- **反方手里最硬的牌**：当前 evidence 分布 A 29 / B 76 / C 17，**B 占了 62%**——大半站点内容是「确定但不可量化」，读者刷了十条只有三条能拿到硬数字。红队会说「你费这么大力气分级，结果绝大多数条目连一个数字都给不出，分级是给一个没数字的站陪跑」。这确实是真的（复算同 §0.2），是我的结构性短板而非反驳盲区，回应见 §4.1。

### 1.2 收益的量级 / 无量级二分——「算不出就如实说算不出」

- **为什么不可丢**：收益节只有两种合法开头，「量级（口径：X）」**必须真的含阿拉伯数字**，「无量级（方向性）」必须说明为什么算不出（`about.md:70-75`）。站史写得明白：曾经「按口径给量级」，实测 41 条通篇没有一个数字全是形容词（`about.md:67`），于是改成硬约束。`about.md:75` 一句是全站可信度的**宪章**：「**算不出就如实说算不出，这份指南可信度靠的就是这条。**」`metric` 五值词表（亏损/收益/时间/自由/处罚）与「不同口径不做比较」（`about.md:151`）是配套的防混淆装置。
- **反方手里最硬的牌**：metric 分布 亏损 97 / 收益 18 / 时间 6 / 处罚 1 / **自由 0**（`about.md:153` 已声明「词表 ≠ 用量」，复算同 §0.2）。一半以上的条目口径挤在「亏损」上，五值词表里「自由」从没人用过——红队会说这套五值词表是**过度设计**，真正被用到的只是「亏损 vs 收益」。回应见 §4.4。

### 1.3 六段「怎么做」+ 算例必选（防格言装置）

- **为什么不可丢**：`about.md:36` 说破了动机——**「概念类条目最容易写成一句格言——读起来像道理，却没有任何可执行的东西。」** 所以这一节强制六段固定顺序：什么时候用 → 步骤 → 算例 → 常见错 → 做完你会得到 → 怎么算过关（`about.md:40-47`），**缺一段或顺序不对构建失败**（`about.md:37-38`），其中**算例是必选段**（`about.md:44`）：一个可复算的假设案例，给初始条件、逐步写出每个动作的输入输出数字，且显式标注「（假设案例）」，且**算例数字不改变证据等级**（`about.md:44`、`content-v2-spec.md:11`）。这是「手册感」的第一来源：一条理念也必须能落成一个能照做的动作+一个能复算的数。
- **反方手里最硬的牌**：概念类条目被硬塞进六段，等于给「讲道理」的内容强穿「执行」的衣服。`content.config.ts` 把 layer 分成理念/执行/档案/工具（`about.md:106-111`），**理念条目的 43 条里有多少其实本不需要「步骤」「怎么算过关」？** 红队会说「六段是给执行条目订的，硬套到理念条目上是模板暴力」（回应见 §4.3）。

### 1.4 「说人话」三段命名 + 禁阿拉伯数字

- **为什么不可丢**：这一节只负责解释，**不许引入收益栏之外的新数字**——正文里出现阿拉伯数字构建直接失败（`about.md:57`）。三段必须段首命名——是什么 / 为什么发生 / 什么时候不成立（`about.md:59-63`），其中「什么时候不成立」写的是**这条会失灵的边界条件**（`about.md:62`）。这三段是「防别吹成永远正确」的装置：每条都必须自己说出自己在什么情形下会失效。
- **反方手里最硬的牌**：禁数字是把双刃剑——很多机制用数字一句话就能讲清（「跌 50% 要涨 100% 才回本」），却说人话里一个数字都不许写，被迫绕弯子用「跌一半要翻倍」。红队会说这是**为仪式感牺牲表达效率**（回应见 §4.5）。

### 1.5 来源纪律（只引原始出处 + checked 必填 + 打不开＝没有来源 + 不引二手转述）

- **为什么不可丢**：来源节的规则是全站可信度的**执行层**：只引原始出处（证监会/交易所/中国结算/统计局/最高法/同行评议原始论文，`about.md:157`）、**不引知乎/微信公众号/股吧/财经自媒体等二手转述**（`about.md:161`）、原始文本类出处默认 B 级且注明「原文未逐条核对」（`about.md:158`）、推导型出处记 A（`about.md:159`）、`checked` 对所有条目必填（`about.md:163`，A股规则会变，这日期就是说法保质期）、**每个带链接的来源都要真的 `curl` 打开过——打不开的链接等于没有来源**（`about.md:164`）。
- **反方手里最硬的牌**：这条纪律严到「很多散户真正需要的东西（实操经验、踩坑故事）天然只有二手、只有股吧」，C 级例外（`about.md:162`）虽然承认了无出处共识，但**已经把「亲历者口述」这类最高价值的一手经验也一起挡在门外了**（回应见 §4.1 末尾；这条与 1.1 共用同一张反牌）。

### 1.6 双链网络 + 反链（手册感 ＝ 网络感，出度下限）

- **为什么不可丢**：`about.md:52` 给的理由最直白——**「手册感 = 网络感」**。每条出度 ≥2（唯一目标数，机检，`about.md:52`）；写错的条目名不产生死链而是渲染成「未收录」橙色虚线（`about.md:13`），每个条目底部自动列反链（`about.md:14`）。当前实测 122 节点 / 931 唯一边 / 平均出度 7.63 / 出度≥2 全覆盖（§0.2 复算）——122 条不是目录里并列的清单，而是一张可以沿 `[[…]]` 横向穿行的手册。「未收录」标记把错链从「断」变成「可见」，是比维基更严的网络卫生。
- **反方手里最硬的牌**：双链是「**维基百科学舌**」——一个面向散户的避险手册，最需要的是「先读哪条、再读哪条」的**顺序**，而不是一张人人互联的网。审计自己就抓到「两条官方阅读顺序互不一致且互不引用」（C-08，`01-content.md:101-108`）——**有网络、没路径**（回应见 §4.6）。

### 1.7 机器闸门（「体例即合同」，绕不过去）

- **为什么不可丢**：闸门是**上面 1.1–1.6 的全部承诺得以强制执行的原因**。`about.md:21-22` 写死：「**闸门由 `npm run build` 在 `astro build` 之前调用——不是外挂脚本，所以绕不过去：缺任何一节、缺任何一段、段顺序不对、任何字段取值非法，构建都会直接失败。**」当前 v5、21 条断言（`about.md:20`），本次复跑 `node scripts/check-content.mjs` → 「122 条全部合规」+ 6 条不阻断警告（§0.2）。**注意我要守的是「体例必须有机器强制、且是构建的有机组成部分」这个理念，不是 21 这个数字、也不是 350 字这个阈值**——后者全是可调参数，归入 §2。
- **反方手里最硬的牌**：闸门自己也有伤疤可打——它的注释引用了两份**已不在仓库里的审计文件**（C-19，`01-content.md:181-184`，`check-content.mjs:24/107/116` 引 `audit-synthesis-20261012.md`）。红队会说「一个靠注释里已消失的审计文件来证明自己规则的闸门，其『体例即合同』的自我宣称本身就是证据链断裂的」（回应见 §4.7）。

> 以上七条不是七根柱子，**是一根柱子的七个截面**：诚实（1.1/1.2/1.5）→ 可执行（1.3）→ 可理解且有边界（1.4）→ 可穿行（1.6）→ 可强制执行（1.7）。丢掉任何一个截面，剩下的都会跟着失效：没有 1.7，1.1–1.6 只是写在 about 页上的愿望（而 about 页自己就过期过，见 C-16）；没有 1.1/1.5，1.3 的算例数字再漂亮也是编的。

## 2. 可进化清单（历史包袱）

判定标准：**不碰 §1 的内核，只改「参数、覆盖、文档同步、工程卫生」**。每条给「现状 → 改进方向 → 代价」。多数项审计已给出落地处方（引用编号），我只补充「为什么它不伤内核」。

### E1 · about.md 公共格式节停留在 v1，与闸门脱节（最重的一个包袱）

- **现状**：`about.md:32-42` 仍写「怎么做」是**四段**，第 3 行 description 也写「四段式」；front matter 模板（`about.md:79-102`）**缺必填字段 `layer`**（`content.config.ts:43` 必填枚举，漏填被判 error，`01-content.md:166`）。而闸门实际强制六段 + 算例必选 + 三段命名 + 字数下限（`check-content.mjs` 规则 2/14 + `about.md:44/51`）。`00-final-report.md:193` 的定性是：**「严格按 about 页写新条目必构建失败」**。
- **改进方向**：按闸门现行规则重写 about「条目格式」节 + 模板补 `layer` 与四个一屏速览可选字段，并在节首声明「与 `scripts/check-content.mjs` 保持一致，闸门为准」（P1-5，`00-final-report.md:117`）。
- **代价**：2–3h；且暴露一个长期义务——**about 页与闸门是两份事实源，凡闸门加规则，about 必须同步**。这是「最小进化」的副作用，不是拒绝修的理由。

### E2 · 「这个数怎么用」收尾句：spec 强制、闸门未强制

- **现状**：`content-v2-spec.md:43` 要求「量级」档结尾带一句「这个数怎么用」；`01-content.md:154` 审计机检 71 条量级档 **0 缺失**，但 `01-content.md:165` 标注该句「**未机检**」——即它是规格承诺、却不是闸门断言。
- **改进方向**：二选一并对齐——(a) 升格为闸门断言（与「量级必须含数字」同待遇）；(b) 降级为「建议写」。**守成倾向 (a)**：这句子回答「这个数对读者决策的作用」（`about.md:77`），正是把数字从「炫技」变「可用」的关键，不该是软约束。
- **代价**：(a) 加 1 条闸门断言 + 一次全量重跑，约 0.5h；若历史有漏网会判红，需先清理。

### E3 · 一屏速览四字段 41/122（漂移前旧值 29/122），界面重做功能只对 1/3 条目生效

- **现状**：`lede/when/keyNumber/maxRisk` 四字段全部 optional（`content.config.ts:58-67`，注释「界面重做新增，没有就回落」），**41/122** 条四字段同条齐全（`01-content.md:176-179`；本节初稿写 29/122，系审计基线漂移前的旧值，已按 `verify-t2.log` 复算就地改为 41/122）；PATH 02「被套」指向的 4 条路径条目**无一命中**。
- **改进方向**：给 3 条路径的 12 条优先补全（PATH 02 被套 4 条第一优先），压缩 3 个超长字段（`2015到2016` when 78 字、`1997` keyNumber 212 字、`2007到2008` maxRisk 108 字，P1-8，`00-final-report.md:121`）。
- **代价**：12+3 条、3–4h 纯写作；不伤任何内核（字段本就是可选，补全只是兑现界面承诺）。
- **后续口径**：本轮各任务报告一律以 **41/122 → 122/122** 陈述（`00-final-proposal.md:39` 已禁用 29/122 与「93 条」两个漂移前数字）。

### E4 · 双链网络「有下限、无质量治理」：孤岛/单向对靠人工事后抓

- **现状**：闸门只机检出度≥2（`about.md:52`），**不机检孤岛、不机检 A↔B 单向互链**。审计抓到的三组同人/同题对（马克斯对 C-05、博格对 C-06、损失厌恶/前景理论对 C-07，`01-content.md:71-91`）全是人工发现的；本次复算已证明马克斯孤岛修复后网络 0 孤岛（§0.2）。
- **改进方向**：把「孤岛数 = 0」「指定同题对必须双向互链」纳入**审计口径**（像 `audit/01-content.md` 这次做的那样），而**不进闸门**——孤岛/互链是语义判断，硬编码进闸门会制造误报（闸门自己就踩过「只查标记存在不查语义」的坑，`01-content.md:182`）。
- **代价**：一次性补链已由 P1-1/P1-2/P1-3 覆盖（约 2h）；长期是每轮审计多一项检查，无构建成本。

### E5 · C 子档固定句式「等级说明：C2」被 B 级条目污染

## 3. 对「详细内容」的建议

### 3.1 体量判断：平均 100+ 行/五节是否过重？——**不过重，但峰值与均值之间藏着一个错判**

先纠正任务书里的口径：「平均 100+ 行」如果指**整文件**（含 front matter），均值 ≈101.6 行/条没错（12390/122）；但**五节正文**（去 front matter）实际是**均值 85.2 行、中位数 76.5 行、P90=122 行**（§0.2 复算）。也就是说：

- **中位数 76 行**这条，离「过重」还远；真正把平均值顶起来的是少数长条目——最长 `2008全球金融危机:雷曼那一夜.md` 正文 155 行，>120 行的只有 14 条，>150 行只有 1 条。
- 结论：**「100+ 行过重」是个用均值误导自己的伪命题**。该做的是**按分布治理**——不砍整体深度，砍「重复的深」和「散文式的长」。

### 3.2 该收敛的（重复段 + 超长散文字段）

1. **博格对步骤 3–5 大面积重复**（C-06，`01-content.md:79-84`）：`博格：大多数基金经理就是跑不赢指数` 的步骤 3/4/5 与 `博格：别试图跑赢市场，定投宽基指数` 实质相同（约 3/5 篇幅）。收敛方向：前者步骤 3–5 改一句「动作见 `[[博格：别试图跑赢市场，定投宽基指数]]`」，本条只保留 85% 跑输数字的四要素核对（P1-2）。

2. **工具层 7 条（5.7%）支撑 122 条转引**（C-02，`01-content.md:34-37`）：`查规则只去这三个地方` 入度 24 全库第 4。这不是缺陷，但「查*」入口的**每条都该配一个真实复算型算例**（复用 `content-v2-spec.md:12` 的真实数据复算例外），把「去哪儿查」落实成「照这个动作你能查到什么」。

4. **04/05/06 三章单层构成的门面声明**（C-01，`01-content.md:29-32`）：三章全是执行（04 十条、05 十六条）或工具（06 七条），读者看不到 layer 分层信号。最小修法是章页注明「本章条目均为执行层/工具层」，不必为凑四层硬造条目（`00-final-report.md:166`）。

### 3.4 新增哪些角度的详细内容（真正「新」的，避免与既有五节重复）

五节已经覆盖了：可执行（怎么做）、可理解+失效边界（说人话「什么时候不成立」）、可量化或如实说算不出（收益）、可核（来源）、前提/反例/有效期（备注）。所以**新增角度必须回答五节都没回答的问题**。我提三个，按价值排序：

1. **「冲突链」（回答：这条和哪一条公开矛盾？）。** 现有双链只表达「相关」，不表达「反对」。A股民间智慧大量互相矛盾——`别摊平亏损`（05/执行）与「定投摊平」类做法、`亏钱的理念:满仓单吊` 与「分散」类理念——站里其实有「三层拆分」去承载这种矛盾（`01-content.md:63-67` 的摊平三件套就是），但没有一个**显式标注「它与 X 冲突，冲突点在哪」**的固定位置。新增方式代价小：在「备注」四类之外，给**确有对立方的条目**加一条 `与 [[X]] 冲突：分歧点在 Y`（或复用 `disputed` 语义做站内互指）。价值：读者不会再以为「两条都是对的，我随便选」，可信度的天花板被这一条直接抬高。
2. **「置信上限」（回答：这条最多值得你信到什么程度、改变多大决策）。** 证据等级回答「可不可信」，`maxRisk` 回答「用错会怎么死」，但都**不回答「下注强度上限」**。建议给关键执行条目加一句「这条最多：动 ≤ 一个单位决策（例如不超过 X 仓位 / 不改主策略）」。**注意边界**：这接近投资建议，须与 `about.md:178` 免责声明对齐，措辞要停在「自我备忘」而非「建议你买多少」。
3. **「数字失效触发器」（回答：盯哪张官方表的哪个数，一旦变，这条作废）。** 规则的「有效期」现在只写「什么情况会变」（`about.md:58`），是**方向**不是**装置**。建议规则类条目在备注把「有效期」具体化为「盯 `巨潮/交易所` 的哪张表、哪一列；该列数值变动即回看本条并更新 `checked`」——把 `checked` 从「写作日期」升级成「下次复核的触发器」。（这是把 `about.md:163` 的「保质期」承诺做实，属 @@1.5 内核的进化而非动摇。）

## 4. 主动 strawman（预判红队怎么打、我怎么回）

这里我对 §1 的**每一个不可妥协主张**和 §2/§3 的**关键可进化主张**预演红队最狠的打法。规则：红队打法必须是我自己都觉得「有点道理」的，不能是稻草人。

### 4.1 打「证据分级是形式主义」

> **红队**：A 29 / B 76 / C 17，你 62% 的条目是 B——「确定但不可量化」。这套 A/B/C 给了一个没数字的站陪跑：读者刷十条只有三条能拿到硬数字。而且你为「诚实」把亲历者口述、股吧踩坑故事这些散户**最值钱的一手经验**全挡在门外（`about.md:161` 不引二手转述），只剩官方文件和论文。你这是**用信源的洁癖，换掉了内容的说服力**。

**回**：第一，B 级占 62% 恰恰证明分级是在**工作**而不是陪跑——它逼着作者如实承认「我只引定性、不引统计数」（`about.md:122` 是 B 级定义原文），而不是像大多数财经自媒体那样把「确定性描述」包装成「有出处」。第二，A/B/C 的『死值』不是 62% 这个比例，而是「**说得出哪些条稳定可靠、哪些条只是共识**」这个能力：29 条 A（股灾数字、推导型数学）是全站可信度的锚点，17 条 C 挂着 C1/C2/C3 子档（`about.md:139-149`）把自己「不可核」的三类原因都讲明——这套透明度在炒股内容里**没有第二家**。第三，关于「挡掉亲历者口述」：这确实是我的结构性代价，但站规给 C2「民间共识无出处」留了门（`about.md:146`），亲历者经验可以以「C2、无一手出处、不编造链接」的形态进来——**接受它进不来『有出处』的层面，但不接受它被当成 A/B 级背书**。守成守的是「不把经验洗成证据」，不是「拒绝经验」。

### 4.2 打「五节八股、作者成本高」

> **红队**：五节 + 六段 + 三段命名 + 字数下限 + 出度≥2 + 量级/无量级 + 备注 ≥3 项，写一条要过 21 条断言。这是给一两个作者自用的备忘站套了一套维基百科的编辑部流程，**写作成本高到会杀死内容更新频率**。而且「说人话 ≥150 字、怎么做 ≥350 字」是**用字数下限制造注水**——短小精悍的条目被逼成凑字。

**回**：成本高是事实，但问错了对象——**该降的是「字数阈值」这个参数，不是「五节」这个骨架**（这正是 §1.7 里我明确划出的边界：守理念、不守 350 字）。五节本身不是八股，而是把一个「说法」逼回答五个不同的问题（怎么做/为什么/值多少/凭什么/例外在哪），缺一节读者就要靠猜。至于「杀死更新频率」：本站是**静态站 + 机器闸门**，天然不适合高频日更，它的价值形态是「低频、高可信、可核」，这跟形式是自洽的——**如果目标变成日更零成本，那才该换形式，但那已经不是这本指南要的东西**。字数下限我认它是可调参数（§2 未列，但逻辑同 E2/E8：把『下限』改成『有算例、有步骤』的语义断言更优）。

### 4.3 打「算例是编的数字，误导读者」

> **红队**：你的算例「给具体金额/价格/仓位」，本质是**编造数字**。读者（尤其散户新手）根本不会记得去读「（假设案例）」四个字，他们只会记住「那个例子赚了 5 万」。你在用假数字做真实说服，比形容词更危险。

**回**：这是我最愿意接的一招，因为它恰恰打在我的护城河上。防误导的三道闸已经焊死：(1) 显式标注「（假设案例）」是**机制性的必选**（`about.md:44`、`content-v2-spec.md:11`）；(2) **算例数字不改变证据等级**（`about.md:44`）——数字是演示计算路径的，不是主张依据，等级仍跟来源走；(3) 真实数据复算型算例必须逐字引一手源、每个数字都能在所引源里逐字找到（`content-v2-spec.md:12`）——**连『假』的例外都规定死了**。红队担心的「读者记不住标注」，本质上和「读者记不住免责声明」是同一种风险，解法不是删掉算例，而是**结论条/速览卡只展示有出处的数字、算例数字永远不进速览卡**（这正是 P1-8 + P-11 的关键点）。把「演示算」和「主张数」分开，是我这版进化里最想推的一条。

### 4.4 打「收益三档是假量化」

> **红队**：`metric` 五值词表里「自由」一次都没用过（`about.md:153` 自己也承认「词表 ≠ 用量」），97 条挤在「亏损」，收益节所谓「量级（口径：亏损）」其实就是给「少亏多少钱」编个口径。这是**拿形式主义的量纲，给一个几乎只谈『少亏』的站装门面**。

**回**：先认一半：「自由 0 使用」是真的过度设计，五值词表可以缩成「亏损/收益/时间/处罚」四值甚至后续再议——这是参数，可进（虽未单列为 E 项，逻辑同 §2 总原则）。但「量级必须真的含数字、无量级必须说清为什么算不出」（`about.md:75`）这一条**不是装门面，是反形容词的宪章**。它逼出的效果是审计实测的「71 条量级档 100% 含『这个数怎么用』收尾、0 缺失」（`01-content.md:154`）——这是全站唯一**每个数字都给读者讲清『这个数对你意味着什么』**的保证。把『亏损』从 97 条里拿走一半也改不了这条宪章的价值；恰恰是『少亏』占主导，才更需要把『少亏 5 万』和『少坐 2 年牢』硬性分开、不许折算（`about.md:151`）。

### 4.5 打「说人话禁数字是自我阉割」

> **红队**：「跌 50% 要涨 100% 才回本」一句话讲完的机制，被你的「说人话禁阿拉伯数字」逼成绕弯的散文。这是**为仪式感牺牲表达效率**，一个讲人话的栏目不让说数字，荒谬。

**回**：禁数字不是为了仪式感，是为了**切断「说人话」和「来源」之间的非法数据通道**——数字在哪里出现，就该在哪里被来源节背书（这正是 `content-v2-spec.md:14` 明文「数字出现位置：怎么做/收益/来源/备注均可，说人话仍禁」）。如果允许「说人话」随手写「跌 50% 涨 100%」，这个数字就**绕过了来源节的核对责任**，读者会以为它是站方给的，但作者可能根本没核过。红队的例子恰好证明规则有效：那个「跌 50% 要涨 100%」就该进「怎么做」的算例段（那里数字是被算例框架背书的），而不是进「说人话」。**代价我认——表达要多绕一点；收益是『数字永远有出处』这个不变量不被破坏。** 若要两全，进化方向是在说人话允许「中文小写数字」（跌一半要涨一倍）而非阿拉伯数字，把『禁数字』精确为『禁阿拉伯数字』（现状规则本就只机检阿拉伯数字，`about.md:57`），这是可进化的参数。

### 4.6 打「双链是维基学舌，有网络没路径」

> **红队**：散户最需要「先读哪条、再读哪条」的顺序，你给了一张人人互联的网。审计直接抓到两条官方阅读顺序互相矛盾、互不引用（C-08），出度 7.63 的网越多，新手越迷路。**双链只是把「结构性没想清楚」藏进了网络密度里。**

**回**：这是七招里**最疼的一招**，因为它引的是我自己引用的审计事实。拆两半回：**一半认账**——「网络」和「路径」是两回事，C-08（三路径×4 步 vs 地图×5 步，重合度 1/4、1/4、0/4）是真实缺陷，修法是让地图当唯一事实源、首页 PATHS 改抄它（P0-3，`00-final-report.md:106`）——这**不删双链，是在双链之上补「顺序」**。**另一半不认**——红队把「路径」和「网络」当成二选一，但它们解决不同问题：路径解决「新手从零进入」，网络解决「读到一条后横向跳到相邻证据」（反链 `about.md:14` + 出度下限 `about.md:52`）。一个只给路径不给网络的站，读者的视野被锁死在编辑排好的 12 步里；一个只给网络不给路径的站，读者迷路。**要的是路径优先、网络兜底**——这也正是 §3.4 里「冲突链」建议的基础：网络越实，越需要显式标出『哪个结点和哪个结点互相反对』。

### 4.7 打「闸门是官僚主义，绑架作者」

> **红队**：21 条断言、缺一段就构建失败、`[[目标]](半角括号)` 直接判死链——你在用一个 508 行的脚本当编辑。作者想改个措辞都要先过闸门，**这是把写作变成合规**。而且闸门的注释引用了两份已不在仓库的审计文件（C-19），你的『体例即合同』靠的是注释里一个消失了的文件。

### 4.8 打「守成本身——你在替现状背书，拒绝革命」

> **红队**：你的立场预设是「守成」，于是把现在这套说成七根柱子，把进化说成「补字段、补别名、修注释」。这本质是**幸存者问诊**：你只从『已经存在的优点』往回推『为什么必须存在』，却从没问『有没有一套完全不同、但明显更好的形式』（比如：一个结构化 JSON + LLM 生成的多视图工具，或者一个决策树/问答向导，根本不需要 122 条五节体例）。守成主笔的最大风险不是答错某个问题，而是**把『存在』论证成『必然』还不够，是把『换一个形态』的可能性从一开始就 ban 掉**。

**回**：我接受这条指控的一半，并把它变成我的收口立场：**守成不是『这套形式必然最优』，而是『这套形式已经为『可信度』付出了真实成本，换形态必须证明新形态不丢这四样：可核、可执行、可说人话、可强制。』** 我 ban 的不是「换形态」，是「不问代价地换形态」。具体说：`JSON + LLM 多视图` 丢的是「来源节逐字引一手源 + 打不开＝没有来源」（§1.5）这种**每条必过的审计性**；`决策树/问答向导` 丢的是「反链 + 出度下限」这种**读者自主横向穿行**（§1.6）；两者都丢的是「机器闸门保证任何作者都绕不过去」（§1.7）。如果新形态能同等兑现这四条，我第一个支持换——**但那不是进化，是从头再写 122 条，成本必须进提案的账**。守成主笔的职责就是：把这道『换形态的账』算清楚交给主编，让他用 P0/P1 的成本去和『从头再来』比，而不是空喊『现在这样也挺好』。
