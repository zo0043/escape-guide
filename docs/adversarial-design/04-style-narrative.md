# 04 · 内容风格：从「工具条款」到「场景化叙事」（证据纪律不下车）

- 角色：叙事风格作者（narrative-writer，t4）
- 输入：抽样精读 `src/content/escape/` 5 条（群体心理 / 前景理论 / 泡沫的共同结构 / 别跟荐股群的老师 / 2008全球金融危机）、`src/content/pages/about.md`（体例+来源规则+证据分级）、`docs/content-v2-spec.md`（五节/六段式/收益三档/双链出度）、闸门 `scripts/check-content.mjs`；对位对手是 `docs/adversarial-design/01-content-form.md`（守成 t1）、`02-presentation.md`（激进重构 t2）、`03-reader-cognition.md`（阅读科学 t3）。
- 立场：**叙事化，但证据纪律不下车**。当前风格的「冷峻工具条款」（步骤/算例/清单）让内容可读性受限于说明书腔，但它押住的两件事——数字逐字回源、算不出就写算不出——正是叙事化**最容易被冲垮**的地方。本文只主张一件事：给条款加一个「场景化的钩子」，不主张把条款替换成故事。任何叙事样本不得引入可被误读为真实的虚构数字。
- 纪律遵守：只读 `src/`、`dist/`、`scripts/`，只写本文；不改 `src/`、`dist/`、`scripts/`；所有站内断言带文件+行号或可复算命令；演示范例里出现的每一个数字都逐字回溯到原条目已核数字，并标注出处行号。

本文与 t1/t2/t3 的分工：t1 论证「内核不可丢」，t2 论证「长文本体该变形态」，t3 论证「读者的注意力根本没在配合」。我论证的是**文本的腔调**——同样 90 行，写成「说明书」还是写成「把自己放进那个处境」，读者读到的字数一样，愿意读下去的意愿不一样。t3 说「结论先行、一次一块」，我说「第一块最好是场景，不是条件」。

**先摆一个结论级观察**：全站的叙事能力**不弱，只是被圈死在一个位置**。找遍 5 条抽样，写得最好的「讲人语」都集中在 `## 说人话` 那 7–8 行里（t3 实测过行数），而且常常带比喻——但它被排在约 90 行的「怎么做」之后（五节固定顺序 `about.md:26-31`），且三条禁令锁死它：禁阿拉伯数字、三段固定命名、汉字仅 ≥150 下限（`about.md:56-63`）。也就是说，**唯一被允许叙事的地方，恰好是唯一被禁止出现具体数字的地方**。这是全部问题的一半。

## 1. 现有风格的优点与 3 条缺点

### 1.1 优点（叙事化必须继续押住的三件事）

**优点一 · 数字逐字回源 + 口径三标注，是反「注水」的硬闸。** 全站每个数字要么有等级（A/B/C，`about.md:115-137`），要么带「无公开统计 / 需人工核对 / 无单一官方口径」三种显式标注（三种语义不同，`about.md:166-176`）。最严的样本是 2008 条目：它把「全球散户平均亏损=无公开统计」「标普两点位=需人工核对」「各国救助规模合计=无单一官方口径」三项并列写清，并警告「拿不到就说拿不到」（`2008全球金融危机:雷曼那一夜.md:68`、`:103`、`:115`）。叙事化若敢绕过这一层，等于亲手拆掉本站可信度的地基——这是本文所有改写的上限护栏。

**优点二 · 「说人话」已经证明站内能把结论讲成大白话 + 比喻，叙事能力不缺。** 例：「人一走进人群，就像换了一个人：胆子变大、脑子变慢」（`群体心理:人群里没有个人.md:96`）；「每一次崩盘在当时的报纸上都有一个专属理由……但把它们的结构拆开，会看到同一套零件反复出现」（`泡沫的共同结构…md:127`）。这些句子不是「冷峻条款」，是合格的白话叙事。所以本文不提案「教作者写故事」，只提案「把这套能力从最后一节解放到开头」。

**优点三 · 「什么时候不成立 / 已知反例」已内置自我攻击，天然反单边结论。** 前景理论如实写下「λ 测量被证伪、禁止把具体倍数写进算例」（`前景理论…md:93`、`:134`）；泡沫条目单开「剧本不完整的四场」反例（`泡沫的共同结构…md:75-80`）。叙事是放大单边结论的最高效工具，所以叙事化必须把「反例随行」当硬规则带进来，而不是丢在叙事之外。

### 1.2 缺点（带条目实例 + 行号）

以下三条缺点的靶心不是 t2 说的「长文本体」，也不是 t3 说的「阅读顺序」——是**同一份内容用说明书腔写，白白扔掉了读者代入的通道**。

**缺点一 · 无人称的命令式条款：读者是「执行者」，不是「身处其境的当事人」。** 正文通篇是第二人称祈使 + 编号动作的堆叠：`2008全球金融危机:雷曼那一夜.md:25-31` 六步全是「先认清…再算…把…对照…读…按…算」，`前景理论…md:69-77` 七步全是「写出…做一次…划掉…写进…记录…识别…装闸门」。没有一个镜头把读者放进「雷曼上头条那天的清晨你打开手机那一秒」。读者读到的是一条条待办，而不是一次「我该不该现在动手」的处境。条款没有错，错在**它成了全文唯一的声音**。

**缺点二 · 算例是账簿不是场景：场景原料已经写好，却被拍平成 `| 动作 | 数字 |` 两列。** 群体心理的算例开头其实已经有一闪而过的镜头感——「某票三天涨了 20%，讨论区被『主力在建仓』刷屏，同一句话你数到 12 次……你正想『跟一波回本』」（`群体心理…md:40`），但紧接着 `:42-50` 立刻切回表格账簿，读者的情绪刚被勾起来就撞上「① 定位场景 | 讨论区刷屏 + 群『八十人跟单』」。别跟荐股群的老师用「21:00 / 21:05 / 21:10 / 21:15」的时间列（`:28-36`）已经是全站最接近叙事的算例，它证明作者**有能力**写出时间感——但仍然是账本，缺的是「你那几分钟里的犹豫」。**场景素材（时间、金额、触发、心态）全站都有，缺的是把它们讲出来，而不是列出来。**

**缺点三 · 唯一能叙事的位置被「禁数字 + 垫底」双重锁死，故事讲不完整。** 「说人话」禁阿拉伯数字（`about.md:56`），只许讲「是什么 / 为什么发生 / 什么时候不成立」三段（`about.md:57-63`），又被排在「怎么做」之后第 90 行上下（顺序 `about.md:26-31`；行数实测见 t3 §0）。结果是：**最该用具体数字把场景讲活的地方（雷曼那天道指 10,917.51、22.9%），讲不了数字；最该被读到的第一屏，被说明书占着。** 叙事能力被制度性地分配到了错误的位置。这条与 t3 的靶心重叠，但本文的结论不同：不是「把说人话提前」就够（那只是位移），还要**允许叙事在「怎么做」的开头出现且带上数字**。

## 2. 一个「叙事风格样板」（只在本文演示，不改原条目）

### 2.0 为什么选 2008 这条

- 它是 `layer: 档案`（`2008…md:7`），档案层的定义正是「发生过什么 + 可核数字」（`about.md:110`）——**是叙事化的第一顺位**，因为它有真事可讲。
- 它已经有一条写成叙事钩子的 `lede`（`2008…md:14`：「雷曼申请破产那天,道指已经跌了22.9%——但对后来在2009-03见底的人来说,最深的40%还没发生」），证明这条的叙事素材是全站最好的，只是没用在正文开头。
- 它的每一个数字都带口径 + 等级 + 逐字出处（来源 1–8 条，`2008…md:121-168`），是「档案路线」要的数字逐字回源最严的样本。

### 2.1 档案路线演示（真实事件：只许重排已核数字，禁止注入）

**原开头**（`2008全球金融危机:雷曼那一夜.md:23`）：

> **什么时候用**:三种场合。第一,你听到「跌了这么多,利空该出尽了吧」或者「雷曼那么大的机构都倒了,这就是底了」的时候——本条会用一组可复算的数字说明,**看到新闻的时候,下跌通常才走到中段**。……

**场景化改写**（替代「什么时候用」的入场段，原三种触发条件仍保留，只是先给镜头、再给条件）：

> 2008 年 9 月 15 日，星期一，你打开手机，满屏都是同一句话：雷曼申请破产保护了。你脑子里冒出的第一个念头是——「这么大的机构都倒了，一定是底了」。但此刻你站在的不是终点，是整段下跌的**四分之一处**：道指在 2007-10-09 已经收出这轮高点 **14,164.53**，到雷曼申请破产这天（2008-09-15，道指收 **10,917.51**）已经跌掉 **22.9%**；而从这天到 2009-03-09 的最终低点 **6,547.05**，还剩 **40.0%** 没跌。
>
> 那一年 12 月 16 日，美联储把利率降到 **0–0.25%**，你很容易第二次以为「这回总该是底了」。但那天仍然不是：道指要到 2009-03-09 才收出最终低点。这条条目要你记住的，不是「雷曼倒了股市就崩了」这么一句口号，而是——**你看到大事的那一天，事情才走到哪里，是可以算出来的。**

**这一段为什么守得住证据纪律——逐字回源表：**

| 改写段出现的数字/日期 | 是否新增 | 原条目出处（行号 + 原文） |
|---|---|---|
| 14,164.53（2007-10-09 高点） | 否 | `2008…md:26`「道指在 2007-10-09 就收出了这轮的高点 14,164.53」 |
| 10,917.51（2008-09-15 收盘） | 否 | `2008…md:26`「到雷曼申请破产的 2008-09-15(当日收 10,917.51)」 |
| 22.9% | 否 | `2008…md:26`「已经跌了 22.9%」 |
| 6,547.05（2009-03-09 低点） | 否 | `2008…md:27`「最终低点 6,547.05(2009-03-09)」 |
| 40.0% | 否 | `2008…md:27`「比雷曼破产当日又低 40.0%」 |
| 0–0.25%（2008-12-16） | 否 | `2008…md:51`「2008-12-16 将联邦基金目标区间降至 0–0.25%」 |
| 「利率到零后仍见底于 2009-03」 | 否 | `2008…md:51`「利率到零;下跌仍未结束,低点在 2009-03」 |

**档案路线的四条纪律（红线，缺一不可）：**

1. **只许重新排列已核数字，禁止新增任何数字。** 段中的「你」是读者本人（第二人称），不是一个有账号、有持仓、有亏损额的虚构亲历者——所以全段**没有**「你那天亏了 3 万」这类可被误读为真实记录的数字。
2. **关键数字必须连同口径与日期出现。** 「22.9%」「40.0%」离线就无意义，必须挂在起止日期与收盘口径上；裸数字等于给数字注水（同 `2008…md:103` 常见错第 3 条的纪律）。
3. **情绪句不得升格为事实句。** 「满屏都是同一句话」「你以为一定是底了」是修辞，不主张任何事实；一旦要写「人人都以为」，就退回「无公开统计」（`2008…md:68`）。
4. **反例随行。** 场景化开头之后必须立即接原条目的「什么时候不成立」主旨——「大机构倒闭不是预测信号，救与不救是政治选择」（`2008…md:115`），否则场景化会放大「看到大事=到底」这个正是本条要拆的错觉。

### 2.2 算例路线演示（标「假设案例」：可引入演示数字，但必须显式声明虚构）

档案路线管「真实事件，禁编数字」；算例路线管「想给读者一个具体金额时怎么办」。原条目的算例已经合规——`2008…md:83-96` 开头就是「**算例**(假设案例,不指向任何真实标的;比率取自本条已复算的道指数据)」，里面的 100,000 元、59,970 元、+30.6% 等都是标签内演示参数。

把它场景化，标签必须**拉高到句首、不能拿掉**（对照原表 `:87-94`）：

> **（假设案例：金额为演示参数，不指向任何真实标的，比率全部取自本条已复算的道指收盘数据。）** 假设你手里正好有一笔 100,000 元的闲钱。2008-09-15 雷曼上头条那天，你问自己「该不该抄底」——这句话背后其实藏着一个更难的问题：你赌的是「这是底」，还是「我已经看到新闻、不能再等了」。把 100,000 元在雷曼当天投进去，跟到 2009-03-09 的道指收盘，它会变成约 **59,970 元**（100,000 × 6,547.05 ÷ 10,917.51），跌掉 **40.0%**；同样的钱等到最终低点才投，才勉强站在起点上。两行数字的差，就是「看到新闻」和「等到低点」之间隔着的那段日子。

这里 `100,000 / 59,970 / 40.0%` 三个数都是原条目 `:89-91` 已算出的假设演示数（情形 A：`100,000 × 6,547.05 ÷ 10,917.51 ≈ 59,970 元(−40.0%)`），标签也已从原算术升级为显式声明。**红线：** 算例里的任何金额、价格、百分比都必须在「假设案例」标签内；标签内的数字不改变证据等级（`docs/content-v2-spec.md:11`）；一旦写「某人某年真实亏了 X 万」，就跳出了算例路线，必须按档案路线回源，否则就是编造。

### 2.3 两条路线的红线对比（判定表）

| 维度 | 档案路线（真实事件） | 算例路线（标「假设案例」） |
|---|---|---|
| 用途 | 把读者放进「真实发生过的那一刻」 | 让读者「亲手算一遍自己的数字」 |
| 数字来源 | 只能重排原条目已核数字，逐字回源 | 标签内可设演示参数，但必须显式声明虚构 |
| 可不可以出现金额 | 出现即必须是已核的历史点数/比例，**不出现虚构个人账户金额** | 可以出现（100,000 元等），但必须在标签内、不指向真实标的 |
| 是否影响证据等级 | 不升不降（叙事重排不产生新证据） | 不改变等级（`content-v2-spec.md:11`） |
| 最常见失手 | 「你那天亏了 X 万」式的无名实指 | 标签被省略 / 标签内数字指向真实公司或真实账户 |
| 对应本站已有合规态 | `2008…md:14` 的 lede（已核数字的叙事化） | `2008…md:83-96`、`群体心理…md:40-52` 的已有算例 |

## 3. 内容风格调整的通用规则（哪些条目适合故事，哪些必须保持条款）

### 3.1 四层 × 叙事适配度（依 `about.md:104-111` 的 layer 四层定义）

| layer（数量） | 叙事适配度 | 规则 |
|---|---|---|
| **档案**（37 条） | **最适合场景化开头** | 走**档案路线**：把读者放进事件当天的镜头（雷曼日、1990 日本、2015 熔断……），只重排已核数字并带口径日期；主体（时间线、对照表、八问复盘）保持条款与表格不变。 |
| **理念**（43 条） | **只给一个「触发场景」钩子** | 走**算例路线**做钩子，或用一个具名反例开头；主体必须是机制 + 步骤 + 表格。理念讲的是「为什么会这样」，叙事只能钩住注意力，不能替代解释过程——`前景理论` 的「死拿亏损、落袋盈利」场景是它的天然钩子，但四主张表必须原样留住。 |
| **执行**（35 条） | **必须保持条款，只在「什么时候用」给一次具体触发** | 执行条目是「照着做」的清单，可判定性优先于代入感。唯一允许的场景化是把「什么时候用」写成一次具名触发（`别跟荐股群的老师.md:28` 的「周二 21:00」已经是典范）。步骤、算例、怎么算过关一字不动。 |
| **工具**（7 条，查* 类） | **必须保持条款/入口清单** | 查证类条目读者要的是「点哪里、查什么」，叙事只会挡路；本条零叙事配额。 |

### 3.2 三条通用红线（跨 layer 一律适用）

1. **双轨原则：一条目最多一个「钩子式叙事」，其余必须保持条款/表格。** 叙事是钩子不是替代。它合法落点是六段第一段「**什么时候用**」（`about.md:40-48` 段序不变、不新增节），其余五段不动——这样闸门继续全绿（本轮的 122 全绿基线不受影响，落地即改「什么时候用」段内文字）。
2. **数字三不放：不放裸数字（必须带口径+日期）、不放无出处数字、不放「假设案例」标签之外的虚构金额/价格/账户。** 这等价于把 `about.md:166-176` 三种「算不出」标注的纪律原样带进叙事段。
3. **反例随行：任何场景化改写后面必须保留「什么时候不成立 / 已知反例」。** 叙事放大单边结论的能力最强，所以它以最严格的形态继承优点三（§1.1），缺反例护栏的叙事改写判为不合格。

### 3.3 「说人话」能否场景化（与闸门兼容性说明）

「说人话」可以更场景化、更有比喻，但**「禁阿拉伯数字」这条不能放松**（`about.md:56`，闸门 error）。结论是分工清晰：**具体数字的场景由「什么时候用」段（可选叙事钩子）承担；无数字的白话场景由「说人话」承担。** 两者都不破闸门、都把数字与白话分开，避免任何一个段里出现「不带出处的裸数字」。

### 3.4 落地边界（本文不自作主张的部分）

本文是风格提案，不给出「先改哪 10 条」「改多少字」的施工单——那属于主编收敛后的任务书。本文唯一指认清楚的是：**改动只发生在「什么时候用」段的入场文字与（可选的）算例标签措辞，不动 front matter、不动五节/六段顺序、不动双链与收益三档、不动来源/备注的纪律区，因此不需要改闸门。** 任何要破「零新增数字」红线的叙事方案，均应退回本文 §2.3 的判定表裁决。
