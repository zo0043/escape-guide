这里是 A股散户逃生指南，2026-10-11 从 blog.zero43.top 拆分出来独立成站。

它借用的是 HowToLiveBetter 那套条目骨架（每条写清成本、收益、证据等级、原始出处），但题材、内容、判据全部另起一套——不搬运它的任何正文。

双链怎么用

本站条目之间用 [[条目名]] 互相引用：写标题或别名都行，不区分大小写。 写错的条目名不会产生死链，而是渲染成橙色虚线的「未收录」标记； 每个条目底部会自动列出反链（哪些条目提到了它）。

想写字面的 [[方括号]]：用行内代码，或在源文件里写 \[[方括号]]。

条目格式

本节与 scripts/check-content.mjs 保持一致，两者不一致时以闸门为准（当前 v5，21 条断言，2026-10-12）。 闸门由 npm run build 在 astro build 之前调用——不是外挂脚本，所以绕不过去： 缺任何一节、缺任何一段、段顺序不对、任何字段取值非法，构建都会直接失败。

每条正文固定五节：

## 怎么做     —— 六段固定顺序，见下
## 说人话     —— 三段段首命名（是什么/为什么发生/什么时候不成立），不许出现阿拉伯数字
## 收益       —— 三档制，见下
## 来源       —— 原始出处 + 核对日期（C 级如实写「无一手出处」+ 等级说明）
## 备注       —— ≥3 个列表项（闸门机检数量）：适用前提/已知反例/关联条目/有效期

「怎么做」必须是六段固定顺序

概念类条目最容易写成一句格言——读起来像道理，却没有任何可执行的东西。 所以这一节强制六段固定顺序，缺一段、或顺序不对，构建就失败 （v2 把 算例 设为必选段；v3 把顺序固定——段齐了但排错位置同样判红）：

顺序段要求
1什么时候用翻这条的场景（触发条件，不是原则）
2步骤编号动作，一次能做完
3算例必选（闸门机检 **算例** 标记）：一个可复算的假设案例——给初始条件（金额/价格/仓位），逐步写出每个动作的输入与输出数字，读者照着能复算出同样的结果；显式标注「（假设案例）」，算例数字不改变证据等级；真实数字复算型标注「（官方数字的复算）」并逐字引一手源
4常见错建议写（闸门不机检其有无）：这个场景下最常犯的错
5做完你会得到手上多出什么（一张清单／一个数字／一份凭证）
6怎么算过关可自查的验收标准，不达标就是没做完

三条附带的机检规则（v2/v3）：

  • 汉字数下限（只数汉字，标点/数字/表格符号不计）：「怎么做」≥350 汉字，「说人话」≥150 汉字。
  • 出度双链 ≥2（按唯一目标计数）：本条必须链到至少 2 个其它条目——手册感 = 网络感。
  • 双链必须写全 [[目标]]；双链后紧跟半角括号（[[目标]](注释)）会被解析成死链，注释一律用全角（[[目标]]（注释））。

「说人话」必须是三段段首命名

这一节只负责解释——不许引入收益栏之外的新数字（「说人话」里出现阿拉伯数字，构建直接失败）。三段必须段首命名：

是什么：          一句话说清这条在说什么
为什么发生：       用大白话讲清为什么这样、为什么有效
什么时候不成立：   这条失效的边界条件

「收益」必须是三档之一

这一节曾经写过「按口径给量级」，但实测 41 条通篇没有一个数字，全是形容词。 现在只有两种合法开头：

量级（口径：亏损）：<必须真的含阿拉伯数字>……这个数怎么用：……
无量级（方向性）：<说明为什么算不出>
  • 写「量级」却通篇没有阿拉伯数字，构建会直接失败——那又变回形容词充数了。算不出就如实说算不出，这份指南可信度靠的就是这条。
  • 行内「量级（口径：X）」的 X 必须 ∈ 五值词表（亏损|收益|时间|自由|处罚），且与 front matter metric 逐字一致（不一致构建失败）；量纲说明写在冒号之后的正文里，不要塞进括号。
  • 「量级」档结尾带一句**「这个数怎么用」**（这个数对读者决策的作用）；「无量级（方向性）」档保持现状即可。

front matter 完整模板——照抄即可过闸门（临时 canary 条目已按本模板验证过，见交付日志）：

layer 四层定义（与 src/content.config.ts 注释逐字一致，改一处必须改另一处）：

layer定义

归类按条目性质，章节只作默认值。不要合并同题条目——本站刻意把同一主题拆成理念层与执行层两条，layer 是读者唯一的层级信号。

证据等级

等级只回答一个问题：这个说法的数字可不可信。它不衡量收益大小。

等级含义
A有一手数字：官方统计（上交所统计年鉴、证监会、中国结算）或同行评议研究，正文必须给出具体数字；推导型/定义性事实见「来源规则」（数字由推导确定）
B有监管原文或已生效的规则、判决，或同行评议文献/书目引用（只引定性结论、不引具体统计数），事实确定但无法量化
C经验或行业共识，没有可直接引用的出处

条目级等级怎么定（聚合规则）

一条条目往往引用多个来源，等级没法逐个来源都取。本站只用一种算法，写在这里免得读者猜：

evidence 取「正文主张的主要依据」的等级。 判断方法：把这条最核心的那个数字或那句话换掉，看条目主张还站不站得住——那个来源就是主要依据。 背景性与叙事性来源允许低一级，但必须在「来源」节逐条标级（站内写法如「机构与失业率叙事为 A/B」「护送船团机制为 B/C」）。 含低一级来源时不降级、不改判：A 级条目里出现 B/C 级背景，不因此变成 B。

由这条直接得出的三个推论：

  • A 级是「核心数字 A」，不是「全部来源 A」。 两条同为 A 的条目，一条可能含 C 级背景、一条不含，这不妨碍它们同为 A；读者该看的是核心数字那一行的等级。
  • 转引不升格。 引用站内其它条目的数字时，那一项的等级不高于被引条目的核验强度；凡本条没有亲手复算的转引，按书目/二手引用处理、最高 B——它不会因为被写进一条 A 级条目就变成 A。所以 泡沫的共同结构：五次崩盘里的同一套剧本 拿五场 A 级崩盘当骨架，仍记 B。
  • 降级只发生在主要依据本身降级时（来源打不开了、原研究被撤稿、规则修订了），并且要同步更新 checked。

C 级拆三个子档

「C 级」一条里其实装着三种不同的情况，读者看到的「不可核」不是同一件事。本站把 C 拆成三个子档；front matter 的 evidence 仍只写 C（不改字段），子档写在「来源」节，句式固定为 等级说明：C1 史料不可核，可机读检索：

子档含义本站实例
C1 史料不可核事件是真的，但当时没留下可核的价格序列或账目；引用的是后世研究与辞条1637郁金香狂热:第一场有记录的泡沫
C2 民间共识无出处共识性说法（祖训、口诀、行业或舆论俗称），没有可引用的一手出处，也不编造链接别满仓，别单吊
C3 二手通说待核机制表述来自二手通说，一手研究没取到；只引方向、不引数字情绪与决策:压力之下人退回习惯

C 级条目的例外不变：「来源」一节如实写「无一手出处」，不编造链接（见「来源规则」）。

「收益大」不等于「证据 A」——这是两个正交维度。另有一个独立维度是 metric（口径）：允许取值是「亏损、收益、时间、自由、处罚」，指这条说法最终落在哪个量纲上，不同口径之间不做比较（「少亏 5 万」和「少坐 2 年牢」不能折算）。

词表 ≠ 用量：上面五个是允许写的取值，不代表每种都有条目在用。写不存在的口径会让构建失败。

来源规则

  • 只引原始出处：证监会 / 交易所 / 中国结算 / 统计局 / 最高法等官方文件，同行评议的原始论文，或人物本人的原始文本（见下条）。
  • 原始文本类出处（人物自己的出版物 / 公开信件，如投资理论）：书引「作者 + 书名 + 年份」（能确定章节则带章节），并在「来源」注明「书目引用，原文未逐条核对，无 URL」；公开信件用 curl 对官方原文核验并附 URL。此类出处默认 B 级（归属事实确定、不可量化）；带独立可核一手数字时才可升 A 级。
  • 推导型出处（数学/定义性事实，如亏损回本不对称、期望值）：「来源」写推导过程（公式 + 数值示例），无需外部出处，记 A 级——数字由推导确定，比任何文献都确定。
  • 行为科学类出处（认知偏差/群体心理）：同行评议论文引「作者 + 题名 + 期刊/年份」，原始文本按书目规则；本指南当前环境无法打开学术出版社原文核验数字（2026-10-11 实测：Science/Springer 均为付费墙或机器人验证页），故此类条目只引定性结论、不引具体统计数，默认 B 级。
  • 不引知乎、微信公众号、股吧、财经自媒体等二手转述——即使它们说的是对的，也要回到它引的那份原件。
  • C 级条目的例外：「来源」一节如实写「民间共识（C 级），无一手出处」，不编造链接。
  • checked 对所有条目必填（C 级也不例外）：填你核对、写下这条的日期——A股规则会变，这个日期就是说法的保质期。
  • 每个带链接的来源都要标「核对于 YYYY-MM-DD」，并且真的用 curl 打开过——打不开的链接等于没有来源。

三种「算不出」的标注，语义不同

正文里出现这三种标注时，它们不是同一种「没有」，别混用：

标注含义本站实例
需人工核对有口径，但本站取不到或没逐条核（付费墙、反爬、原文太长）标普两点位需人工核对
无公开统计口径本身不存在——没有任何机构发布过这个数1993–94 年散户平均亏损
无单一官方口径各家都在发布，但统计范围与定义不同，无法相加或对比各国救助规模合计

这三条的权威定义见 1993到1994:千点到三百点 与 2008全球金融危机:雷曼那一夜；上面这张表是图例，不是新规定。拿不准时按最谨慎的那条写，不要用「无公开统计」去描述一个只是你没拿到的口径。
