## 1. 这是什么

中文 A 股散户投资科普静态站，**"逃生指南 / 先别亏钱"**：教方法不荐股、不预测、不保证收益。核心差异化 = **可验证性**（证据 A/B/C 分级 + 每个数字可复算 + 构建期闸门强制体例）——中文散户市场无第二家系统性地做这件事。

- **内容**：122 条 / 约 42.8 万字 / 六域×四层（01 市场与周期 21 · 02 理念与理论 39 · 03 人性与心理 29 · 04 规则与制度 10 · 05 风险与防御 16 · 06 实操与验证 7；理念 43 / 执行 35 / 档案 37 / 工具 7）
- **页面**：136 页（122 条目 + 6 域页 + 4 对照表 + 首页/about/别名/404），sitemap 135（404 有意不入）
- **链接**：双链 1936 处全部解析，0 孤岛、0 死链（2026-10-13 实测）
- **技术**：Astro 静态站，**零 JS（136/136 页 0 script）、零外部资源**，本地字体，明暗双主题，构建期内容闸门 v6（非 0 退出无产物）
- **部署**：`blog.zero43.top/escape-guide/`（GitHub Pages 子路径，**无 ICP 备案**，美国 IP）
- **维护**：匿名个人维护，无评论/社区/统计

### 不可破坏的不变式（改动前必读）
1. **零 JS**：不引入任何运行时脚本/外部资源（`script-src 'none'` 级别承诺；搜索/追踪/表单一律不做）
2. **数字逐字回源**：对照表与 `keyFigure` 中的数字必须是条目 `keyNumber` 的逐字子串（闸门已断言）
3. **title 即身份**：双链/对照表 src 全靠标题解析，**永不合并/重命名条目**（要收口同题用表+备注）
4. **体例五段**：速览 4 卡 → 白话 → 怎么做六段 → 收益成本 → 来源（逐源"已核 YYYY-MM-DD"）→ 备注，122/122 一致，闸门强制
5. **证据纪律**：evidence A/B/C（C1/C2/C3）；disputed=true 15 条带反证；"语义层仅人工审计，机器只防机械错"是诚实声明不是缺陷

### Agent team 使用约束（本环境实测）
- **并发上限 = 1**：同时派多个 worker 会全部 429 upstream_rate_limited。必须串行：派一个 → `wait_for_agents` → 读结果 → 再派下一个
- **敏感词过滤**：worker prompt 中密集出现金融合规/维权类直述词（投顾红线/荐股/无备案/被举报下架/维权/杀猪盘等组合）会触发 `500 sensitive_words_detected` 杀请求。此类任务用中性措辞（"服务边界/托管环境/可信度"），敏感词只以文件名形式出现可过
- worker 版本：pi-coding-agent 1.2.0 / pi-web 0.12.1（2026-10-13 升级；pi-web 服务进程需重启才用新包，worker 用 `~/.local` 独立安装即时生效）
