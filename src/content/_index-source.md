这里是 **A股散户逃生指南**：一个用 `[[…]]` 互相链接的条目区，和博客文章（`/posts/`）分开演进。

它借用的是 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) 那套**条目骨架**（每条写清成本、收益、证据等级、原始出处），但题材、内容、判据全部另起一套——不搬运它的任何正文。

## 双链怎么用

本区的条目之间用 `[[条目名]]` 互相引用：写标题或别名都行，不区分大小写。
写错的条目名**不会产生死链**，而是渲染成橙色虚线的「未收录」标记；
每个条目底部会自动列出**反链**（哪些条目提到了它）。

想写字面的 `[[方括号]]`：用行内代码，或在源文件里写 `\[[方括号]]`。

参与索引的分区名单在 `hugo.yaml` 的 `params.linkSections` 里（当前只有本区）；
追加分区名即可让别的分区进入同一套链接与反链索引。

## 条目格式

每条正文固定五节。**缺任何一节、或下面任何字段取值非法，构建会直接失败**
（校验器是 `layouts/partials/guide-guard.html`，由本区列表页在构建期调用；
不是外挂脚本，所以绕不过去）：

```text
## 怎么做     —— 具体动作，一次能做完
## 说人话     —— 用大白话讲清为什么，不许出现新数字
## 收益       —— 按「口径」给量级
## 来源       —— 原始出处 + 核对日期（C 级如实写「无一手出处」）
## 备注       —— 边界条件、适用前提、已知反例
```

front matter 里的机器可检字段：

```yaml
cost: { money: "0", time: "少", will: "否" }  # 钱=0|少|多  时间=少|中|多  毅力=否|些|是
gain: "大"              # 大|中|小
metric: "亏损"          # 允许值：亏损|收益|时间|自由|处罚（闸门强校验，见下）—— 收益数字的量纲
evidence: "B"           # A|B|C
disputed: false         # 可选：A/B 级存在反方证据时置 true
checked: 2026-10-08     # 来源的核对日期（所有条目必填，闸门强校验）
```

## 证据等级

等级只回答一个问题：**这个说法的数字可不可信**。它不衡量收益大小。

| 等级 | 含义 |
|---|---|
| **A** | 有一手数字：官方统计（上交所统计年鉴、证监会、中国结算）或同行评议研究，正文必须给出具体数字；推导型/定义性事实见「来源规则」（数字由推导确定） |
| **B** | 有监管原文或已生效的规则、判决，或同行评议文献/书目引用（只引定性结论、不引具体统计数），事实确定但无法量化 |
| **C** | 经验或行业共识，没有可直接引用的出处 |

**「收益大」不等于「证据 A」**——这是两个正交维度。另有一个独立维度是 `metric`（口径）：**允许取值是「亏损、收益、时间、自由、处罚」这五个**（词表由 `layouts/partials/guide-guard.html` 在构建期强校验，写第六种会让构建直接失败）。它指这条说法最终落在哪个量纲上，**不同口径之间不做比较**（「少亏 5 万」和「少坐 2 年牢」不能折算）。

> **词表 ≠ 用量**：上面五个是**允许写**的取值，不代表每种都有条目在用。当前 41 条实际用到的是「亏损」「收益」「处罚」三种；「时间」「自由」先留在词表里，等真有对应口径的条目时直接用，不用改闸门。

## 来源规则

- 只引**原始出处**：证监会 / 交易所 / 中国结算 / 统计局 / 最高法等官方文件，同行评议的原始论文，或人物本人的**原始文本**（见下条）。
- **原始文本类出处**（人物自己的出版物 / 公开信件，如投资理论）：书引「作者 + 书名 + 年份」（能确定章节则带章节），并在「来源」注明「书目引用，原文未逐条核对，无 URL」；公开信件用 `curl` 对官方原文核验并附 URL。此类出处默认 **B 级**（归属事实确定、不可量化）；带独立可核一手数字时才可升 A 级。
- **推导型出处**（数学/定义性事实，如亏损回本不对称、期望值）：「来源」写推导过程（公式 + 数值示例），无需外部出处，记 **A 级**——数字由推导确定，比任何文献都确定。
- **行为科学类出处**（认知偏差/群体心理，如「你的大脑会骗你」章）：同行评议论文引「作者 + 题名 + 期刊/年份」，原始文本（如勒庞《乌合之众》）按上条书目规则；本指南当前环境无法打开学术出版社原文核验数字，故此类条目**只引定性结论、不引具体统计数**，默认 **B 级**；哪条要引具体数字，先找到可打开核验的原文再升 A 级。
- **不引**知乎、微信公众号、股吧、财经自媒体等二手转述——即使它们说的是对的，也要回到它引的那份原件。
- **C 级条目的例外**：「来源」一节如实写「民间共识（C 级），无一手出处」，**不编造链接**；日后找到可核对的一手出处，再把该条目升级为 A/B 级并补链接。
- `checked` 对**所有条目必填**（C 级也不例外）：填你核对、写下这条的日期——A股规则会变，这个日期就是说法的保质期。
- 每个**带链接**的来源都要标「核对于 YYYY-MM-DD」，并且真的用 `curl` 打开过——**打不开的链接等于没有来源**。
