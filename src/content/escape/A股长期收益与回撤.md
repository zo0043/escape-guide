## 怎么做


**什么时候用**：你准备决定「要不要长期投 A股」之前；或者听到「A股是骗局」/「A股是好地方」时，想拿一套任何人可复算的数字时。

**步骤**
1. 用来源一节的重跑命令取最新全量日线，重算两个数：年化收益、最大回撤；
2. 核对口径：几何年化、日历年、中证指数官网复权序列（与上交所公布值的差异见来源的口径声明）；
3. 写下你自己的「可承受损失」：极端情况下你能接受亏多少（自设参数，不是市场数字）；
4. 倒推仓位：可承受损失 ÷ 历史最大回撤 = 你单押「A股」这一个方向的最大仓位。

**算例**（假设案例，不指向任何真实公司）：你有 100,000 元长期闲钱，打算长期投 A股大盘（如通过宽基指数基金，见 [[博格：别试图跑赢市场，定投宽基指数]]）。用本条的历史数字做参数。

| 动作 | 数字 |
|---|---|
| 历史年化（上证指数，2005-04-08 → 2026-10-09，复权口径，几何年化） | +5.33% |
| 若照此延续（假设），10 年后 | 100,000 × 1.0533¹⁰ ≈ 168,100 元 |
| 历史最大回撤（2008 段，上证 6092.06 → 1706.70） | −71.98% |
| 若你在 2007 年峰值满仓，2008 年底部账户 | 100,000 × (1 − 0.7198) = 28,025 元 |
| 我的可承受损失（自设参数） | 30,000 元（能接受闲钱亏三成） |
| 倒推最大仓位 | 30,000 ÷ 71.98% ≈ 41,700 元 → 实际用 40,000 元（40%） |
| 按 40,000 元持有，最大回撤时 | 40,000 × 71.98% = 28,792 元 < 30,000 元 → 在可承受范围内 |

算例说明：1.0533¹⁰ ≈ 1.6806，可手算复验。本例演示「把历史回撤换算成我扛得住的仓位」，不是「未来回撤与历史相同」的承诺。

**常见错**
1. 把年化当成未来收益的承诺——同一个指数：1990 年起年化 +1.97%、2005 年起 +5.33%、近 5 年只有 +1.20%（上证，截至 2026-10-09）——口径差这么大，就该记住「数字是历史，不是承诺」。
2. 只看收益不看回撤——你扛不住 −72% 时，满仓等于必然在底部割肉离场；这时收益再高也与你无关。
3. 混用口径不声明——1990 起点含基期小样本影响，与 2005 起点的年化不可直接比；引用时口径必须写清。

**做完你会得到**：两个带数据截止日期的可复核数字（最新年化、最新最大回撤），和一个由你的可承受损失倒推的仓位上限。

**怎么算过关**：你能报出数据的截止日期、口径（复权/公布、几何年化），以及仓位是怎么从可承受损失倒推的；只答得出「长期看好」= 不过关。

## 说人话

是什么：A股的长期回报，没有一些人想的那么高，回撤也没有多数人想的那么浅。从基日算到现在，上证指数年化收益只有百分之二不到（从二〇〇五年起算有百分之五出头）；而在全球金融危机那一年，市场从高点往下掉了七成多。这条是全站第一条带官方统计的条目，具体数字来自指数编制方的官网（见来源）。

为什么发生：A股的「长期年化不高」和「回撤很深」是同一个机制的两面：市场大部分时间在区间里来回磨（时间成本），而每次泡沫形成后，都要用一次大跌来消化（回撤成本）。回报是「磨好几年攒一点」，然后「一次跌掉一大截」——这就是为什么长期年化看起来平平，路上却难受：数字是平均的，路径不是平均的。

什么时候不成立：两种情形。其一，这组数字是「市场」的数字，不是「你持仓」的数字——你选股或押板块，结果可以显著高于或低于这组数，路径也更颠簸。其二，历史数字是历史——市场的结构变量（指数样本、市场规则、经济结构）从二〇〇五年到现在都变了，这组数字是「回撤可以有多深」的参照，不是「未来会赚多少」的承诺。

## 收益


量级（口径：收益）：长期年化口径（几何年化、日历年、中证指数官网复权序列，数据截至 2026-10-09 收盘，核对于 2026-10-11）：上证指数 1990-12-19 → 2026-10-09（35.81 年）+1.97%；上证指数 2005-04-08 → 2026-10-09（21.50 年）+5.33%；沪深 300 2005-04-08 → 2026-10-09（21.50 年）+7.02%。最大回撤：2008 年上证 −71.98%（6092.06 → 1706.70，2007-10-16 → 2008-11-04）、沪深 300 −72.30%（5877.20 → 1627.76）；2015 年上证 −48.60%（5166.35 → 2655.66，谷值 2016-01-28）、沪深 300 −46.70%（5353.75 → 2853.76）。官方阶段收益率（截至 2026-10-09）：上证近 3 年 +7.19%、近 5 年 +1.20%；沪深 300 近 3 年 +5.42%、近 5 年 −2.62%。这个数怎么用：用年化校准「长期能期待多少」（不是承诺），用最大回撤倒推「我扛得住的仓位」（见算例）。

## 来源

官方统计（A 级）：中证指数有限公司官网（csindex.com.cn，指数编制方官方渠道）API 全量日线数据，2026-10-11 全部 curl 实测 HTTP 200，JSON 全文可解析；序列截至 2026-10-09（抓取时最近交易日）。重跑命令（可复算）：
- 上证指数（000001）全量日线（1990-12-19 → 2026-10-09，6342 条）：`curl -sS -A "$UA" "https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=000001&startDate=19901219&endDate=20261009"`
- 沪深 300（000300）全量日线（2005-04-08 → 2026-10-09，5223 条）：`curl -sS -A "$UA" "https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=000300&startDate=20050408&endDate=20261009"`
- 指数基本信息（基日/基点）：`curl -sS -A "$UA" "https://www.csindex.com.cn/csindex-home/indexInfo/index-basic-info/000001"`
- 官方阶段收益率：`curl -sS -A "$UA" "https://www.csindex.com.cn/csindex-home/perf/get-index-yield-item/000001"`、`curl -sS -A "$UA" "https://www.csindex.com.cn/csindex-home/perf/get-index-yield-item/000300"`
- 官网人工入口页（JS 渲染，仅作入口）：`https://www.csindex.com.cn/#/indices/family/detail?indexCode=000001`、`.../000300`

关键输入数字（均取自上述 API，核对于 2026-10-11）：上证基日 1990-12-19、基点 100；上证期初收盘 1895.64 → 期末 3813.79（1990 口径）、1248.52 → 3813.79（2005 口径）；沪深 300 期初 1003.45 → 期末 4317.25（2005 口径）。年化 = (期末/期初)^(1/年数) − 1，年数 = 日历年/365.25（几何年化）；最大回撤为序列内峰→谷。

口径声明：csindex API 提供的日线为编制方重述（复权）序列，与上交所官网公布的单日收盘点数存在小幅差异（实例：2007-10-16 csindex 6092.06 vs 上交所公布 6124.04；2008-11-04 1706.70 vs 1664.93；2015-06-12 5166.35 vs 5178.19；2016-01-28 2655.66 vs 2638.30）。若按上交所公布值计算，2008 回撤 ≈ −72.81%、2015 回撤 ≈ −49.05%。本条正文统一采用中证指数官网复权序列；上交所公布值需人工核对（sse.com.cn 官网本环境 403 未打开）。

## 备注

- **适用前提**：数字是「市场」（指数）的数字，不是任何个股或基金的数字；口径为中证指数官网复权序列、几何年化、日历年；沪深 300 基日 2005-04-08，不存在「1990 年起的沪深 300」。
- **已知反例**：真实情形：同一市场、不同口径、不同结论——截至 2026-10-09，近 5 年上证 +1.20%、沪深 300 −2.62%，近 3 年 +7.19% / +5.42%；只看「近 5 年」会得到「A股不涨」的结论，只看「近 3 年」会得到「A股不错」的结论。本条把所有口径都列出，由读者对口径负责。
