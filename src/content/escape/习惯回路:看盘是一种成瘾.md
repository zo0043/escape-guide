## 怎么做

**什么时候用**：四个具名场景，出现任何一个就用——①开盘自动化：九点半一到，你的手自己点开行情软件，说不出今天要看什么；②红绿检查：一天里刷新持仓的次数多到你自己都吃惊，看到绿色才安心；③周末空落感：休市日打开软件无所事事，或者反而更频繁地刷财经新闻；④深夜与外盘：睡前、通勤路上反复看外盘与期货，只为「心里有着落」。也用于两个时刻：⑤你想「少看盘」却总在同一时刻破功的时候；⑥长假后第一个交易日——线索断裂后重建的那天，动作量通常会反弹（见算例二）。

**步骤**
1. 记录线索：连续五个交易日，每次打开行情软件前，写下「时间 + 地点 + 前一秒在做什么 + 当时情绪」——习惯的触发器藏在这四项里，不藏在意志里；
2. 记录奖励：打开之后你具体得到了什么（信息？安慰？刺激？）——看盘的真实奖励常常是「不确定性带来的兴奋」，不是信息；分不清就写「不知道」，连续几天就看得见；
3. 目标测试：每次打开前问一句「我现在看盘，是为了做成哪一笔决策？」答不出 = 这次是线索驱动，不是目标驱动；
4. 改线索，不改意志：把 App 从首屏移到第二页文件夹、退出登录、关掉推送、设定「开盘后一小时与午后各一次」的具体时段——情境变了，自动档才踩空；
5. 给动作设闸：只在写完当日计划后打开一次盘，看盘次数写进 [[投资日记:记决策不记盈亏]]，让次数成为被记录的数字而不是感觉；
6. 周末空落感用预设活动填充（运动、出行、家务、约人），别用「就看一下」填补——空落感是线索，「看一下」是奖励，用别的活动替换奖励；
7. 已经因为频繁看盘而频繁交易的，两条一起治：看盘的记录表与 [[亏钱的理念:频繁交易]] 的往返笔数放同一张表，次数一起降；
8. 冲动已经起来、准备「就看一下」的时候，用同轮新条目 [[戒断机制:想买先写下来等一天]] 兜底：写下来、等一天——在「线索触发」和「真动作」之间插一个时间闸，这是比意志力更可靠的隔板。

提示—惯常—奖励三段表（Duhigg 的科普框架，C 级；机制本身由两条 A·摘要支撑）：

| 段 | 盘中形态（你的版本） | 改法 |
|---|---|---|
| 提示（线索） | 开盘时间到、手机亮屏、午休结束、绿色数字出现 | 移 App、关推送、定时段——换情境 |
| 惯常（动作） | 打开软件、刷新持仓、翻评论区 | 只在写完当日计划后打开一次 |
| 奖励 | 刺激、安心、「心里有着落」 | 用别的活动替换（第 6 步），不是硬忍 |

三段表的用法：不要三段一起改。先改提示（最容易、最不靠意志），动作与奖励会跟着松；一上来就禁动作（「今天不准看」），奖励缺口会把动作拉回来——这是多数人「少看盘」失败的原因。

常见线索自检表（记录时对照打勾；勾得越多，说明你的看盘越接近自动档）：

| 线索类型 | 具体形态 | 你的频率（次/日） |
|---|---|---|
| 时间线索 | 开盘、午休结束、收盘前后、固定加班间隙 | |
| 设备线索 | 手机亮屏、推送弹出、电脑开机自启 | |
| 人际线索 | 群消息红点、大 V 发帖、同事谈论 | |
| 情绪线索 | 绿色数字出现想再看一眼、被套后想确认 | |
| 场景线索 | 通勤路上、睡前、卫生间、开会走神 | |
| 空档线索 | 一件事做完后的十分钟、等结果的间隙 | |

用法：连续五天把「你的频率」列填满，频率最高的两类就是你要先改的提示；改法见第 4 步（移 App、关推送、定时段）——一次只改一类，改完观察一周再改下一类。

记录表的达标线（五天后自检）：六类线索里至少三类有记录、日均打开次数有具体数字、「无目标」占比算得出来。三项齐了才算这张表能用；缺项就继续记，不要凭五天的印象改情境——情境改动要对着数字做，不对着决心做。

**算例**（假设案例，不指向任何真实公司，代码用 999999；记录者为假设人物）：一名散户连续五个交易日的看盘记录，与据此做的压缩方案。

| 时间 | 前一秒在做什么 | 打开前有具体目标吗 | 得到了什么 |
|---|---|---|---|
| 9:30 | 刚坐下开电脑 | 无 | 刺激（红绿跳动） |
| 10:15 | 回完一封工作邮件 | 无 | 无 |
| 11:20 | 泡茶回来 | 无 | 焦虑（−1.2%） |
| 14:00 | 午休结束 | 无 | 无 |
| 周六 10:00 | 醒来刷手机 | 无 | 空落感加重 |

统计与压缩方案（可手算复核）：

| 指标 | 数字 |
|---|---|
| 五个交易日打开次数合计 | 21 次（表中 4 个盘中时点 × 5 天，加周末 1 次） |
| 日均打开次数 | 21 ÷ 5 = 4.2 次 |
| 其中「有具体目标」的次数 | 0 次 |
| 一个月（22 个交易日）现状 | 4.2 × 22 ≈ 92 次 |
| 压缩目标：开盘后一小时 + 午后各一次 | 2 × 22 = 44 次 |
| 每月减少 | 92 − 44 = 48 次 |
| 按每次 5 分钟计，每月省下 | 48 × 5 = 240 分钟 = 4 小时 |
| 其中「被红绿数字牵走」的次数 | 3 次（周一、周三、周四各一次，假设） |
| 这 3 次里有几次触发了交易 | 1 次（假设）——看盘与动作之间的传导见 [[亏钱的理念:频繁交易]] |

算例说明：以上为假设记录，不是人群统计；「无目标刷新占比」是本条的自查指标。压缩方案的要点是改情境（第 4 步）而不是下决心——把 App 移出首屏、关推送、定时段，三件事都可在五分钟内完成，且不依赖意志力。

爆米花实验的读法（A·摘要怎么用）：Neal 等人的实验里，影院里的习惯性吃爆米花者不受饥饿与喜好影响，新鲜与不新鲜吃得一样多——对应到看盘：不在乎今天有没有新信息，照刷不误；甚至信息质量变差（周末没有盘中数据）也照刷。注意实验的另一半：习惯只在过去相关的情境中才被触发——所以换情境（关推送、移 App、定时段）比「提醒自己别刷」有效，这不是技巧，是机制。

算例二（假设案例，节后与周末）：长假后第一个交易日，你的记录表出现两组数字——假期七天里你打开软件 14 次（日均 2 次，全部「无目标」），节后首日 6 次（比常态的 4.2 次还高）。解释不是「自律崩了」，是线索断裂后重建：假期没有开盘时间这个提示，你用自己的方式（刷新闻）补足了线索；节后首日所有线索一起回来，动作量反弹。对应的动作：假期前写下「假期的替代活动清单」（第 6 步的预设），节后首日只允许自己打开两次——两次都用满，第三次记为「反弹样本」，不加自我评价，只记数。

**常见错**
1. 用「我是在跟踪市场」解释每一次刷新——跟踪是目标驱动，带着具体问题；说不出问题就是线索驱动；
2. 靠意志力硬扛——触发器是情境，情境不变，意志每次都输（A·摘要：Wood 等 2002 的行为在稳定情境中近乎每日自动发生，无需有意识引导）；
3. 把「卸载 App」当终极解法——卸载一周再装回来，时间点这个线索还在，习惯会重建；要改的是线索组合，不是单个软件；
4. 用周末「就看一下」填补空落——空落感本身是线索，「看一下」是奖励；填充要用别的活动，把奖励换掉；
5. 把看盘当勤奋——看盘次数与决策质量无关，看得多只说明线索强（站内 B 级复算，见 [[过度自信：你大概率跑不赢市场]]）；
6. 记录两天就下结论——线索模式至少要看满五个交易日；两天的记录只能证明你在记录。

**做完你会得到**：一张「线索—奖励记录表」（至少五个交易日，含时间、地点、前一秒、情绪、有无目标、得到什么六列），以及新情境的三件具体改动：App 位置、打开时段、周末替代活动。

**怎么算过关**：你能报出最近五个交易日的日均打开次数、其中「无具体目标」的次数占比、以及你为新情境改的三件事；报不出日均次数 = 记录没做，不过关，动作是从今天开始记，五天后带着数字回来。

## 说人话

是什么：看盘这件事，多数时候不是决策，是习惯——到点了手就点开了，并没有一个具体要看的事。心理学把习惯拆成三段：一个情境线索（开盘的钟声、手机亮屏、午休结束），接着一个惯常动作（打开软件、刷新持仓），然后一点奖励（红绿跳动的刺激、绿色带来的安心）。跑熟了之后，整段反应不需要你批准。

为什么发生：因为省力。大脑把重复过的动作交给自动档，好把注意力留给别的事——Wood 等人的日记研究发现，人在稳定情境里近乎每日重复的行为，执行时甚至不会去想它，因为不必有意识引导。到了盘中，这个自动档表现为：开盘自动开软件，每隔几分钟刷新一次，看到绿字松一口气，看到红字再刷一次。周末休市，线索断了，动作没断，于是心里空落。

什么时候不成立：一、习惯的解释不等于成瘾的诊断——本条的证据是习惯研究，不是成瘾研究；把看盘说成「病」需要另一套标准，本站不下这个判断。二、有明确目标的看盘不是本条对象：带着问题去看（止损单触发了、今晚有公告、计划里的调仓日），看完就关，那是工作流程；本条管的是没有目标、被线索牵着走的刷新。

## 收益

量级（口径：时间）：算例中，日均 4.2 次无目标刷新压缩到每天 2 次，一个月（22 个交易日）从约 92 次降到 44 次，少 48 次；按每次 5 分钟计，每月省下约 4 小时。这个数怎么用：先数你自己的日均打开次数（手机屏幕使用时间里行情软件的时长最准），再定一个具体数字（比如每天 2 次），一周后复查——数字不降，说明你在改愿望而不是改情境，回到第 4 步改线索。省下的四小时不自动变成收益，它变成的是「不被线索牵着做决定」的次数——后者才与收益有关（站内 B 级复算，见 [[结果偏误：按盈亏判决策是最常见的错]]）。

## 备注

- **适用前提**：针对「高频、无目标、情境触发」的看盘与刷新；带着具体决策目标的看盘（止损触发、公告日、调仓日）不在本条范围，那是工作流程。
- **不适用情形**：职业交易员每个交易日长时间看盘是工作要求，且有明确的决策清单与风控参数——同样的行为频率，目标结构完全不同；日内趋势交易者的看盘是工作流程，不是习惯回路。本条判据是「有没有具体目标」，不是「看了多久」。
- **给家长式监督者的提醒**：不要用「你就是上瘾」解释家人的高频看盘——本条的证据到不了「成瘾」这个诊断；能说的是「线索驱动的无目标刷新」，对应的动作是改情境（移 App、关推送、定时段），不是道德评价。评价会把记录表变成对抗，记录表一旦停记，线索就重新隐形。
- **什么时候该去找专业帮助（本条的责任边界）**：如果看盘或交易已经影响到睡眠、工作、家庭关系，或出现「不交易就烦躁、亏了必须立刻赚回来、向家人隐瞒持仓与亏损」这类情形，本站条目替代不了诊断——请到精神科或临床心理门诊就诊。本条给的是改情境的方法，不是治疗方案；两条同时进行不冲突，先就诊不会让后面的方法失效。同理，若你发现自己正在用赌博式的频率与杠杆交易，需要同时看资金侧的动作（[[别借钱炒股]]、[[买入之前先写下「错了怎么办」]]）。这一句放在这里，是因为本站说了「看盘是成瘾」，就不能在读者真到那一步时只给一张记录表。
- **已知反例**：真实情形：高强度看盘与收益之间没有稳定的正相关，但也没有稳定的负相关——存在以盯盘为工作方式并长期存活的交易者（真实情形，本条不量化）。反例推翻的是「看盘多一定亏」，推不翻「无目标刷新是被线索驱动的」；本条不给盈亏结论，只给时间账与线索账。
- **关联条目**：[[投资日记:记决策不记盈亏]]（把看盘次数写进记录）、[[亏钱的理念:频繁交易]]（看盘与交易的传导）、[[频繁交易的换手成本]]（每次动作的钱）、[[过度自信：你大概率跑不赢市场]]、[[结果偏误：按盈亏判决策是最常见的错]]（盘中数字如何劫持判断）、[[群体心理:人群里没有个人]]（同轮新条目）、[[心理学研究的证据强度:哪些结论能信]]（同轮新条目）。
- **给家人用**：把「线索—奖励记录表」的六列直接拿去用即可，不需要先讲心理学；对不肯记录的人，只问一句「你今天打开了几次」——多数人答不出来，这个答不出来就是本条要治的东西。
- **有效期**：习惯机制的研究结论长期稳定；「日均打开次数」的基线随市场热度与行情软件改版变化，需按月重测；「成瘾」一词若将来要升级为临床口径，需先补成瘾领域的诊断标准与对应研究（当前标需人工核对）。
- **证据口径备忘**：本条 front matter 的 evidence = A，来源是两条「摘要级」A（Europe PMC 官方摘要逐字、全文在付费墙后）；科普框架（Duhigg）是 C，机制陈述不引用它。这条区分本身示范了 [[心理学研究的证据强度:哪些结论能信]] 的做法：同一页里并存 A、C 两种等级时，读者要能看出哪句是哪级。
- **为什么标题用「成瘾」而证据只到「习惯」**：标题是钩子，证据是底账——本站不为了标题的锋利把证据往前推一格。读者若只想拿一句话转述家人，请转述「看盘多是被线索牵着走的无目标刷新」，不要转述「看盘是成瘾」；后一句在本站没有来源。
