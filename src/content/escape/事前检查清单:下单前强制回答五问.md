## 怎么做

**什么时候用**：任何一笔「动作类」操作前——买入、加仓、换股、以及卖出前的反悔（把五问里的「买」换成「卖」，问二变成「卖了错了怎么办」）。不用于判断行情：五问全部问的是「我这笔操作」，没有一问问「大盘会涨吗」。每笔的时间盒是十五分钟，从落笔开始算，超时未答完即视为放弃，不许「先买了再补」。

**形态**：一张纸，从上到下五问，每问下面一行答案、一行判定，最后一行写最终动作（下单 / 放弃 / 进观察名单）。答案写在问号后面，判定写在答案后面——顺序固定，是因为先把答案写死再判定，能防止「先决定要买、再倒找合格答案」。这一条是整套清单唯一不能被简化的地方：口头过一遍、心里过一遍，都等于没过。

**步骤**

1. **问一（理由）**：用一句话写买入理由，这句话里必须同时含一个**可观测指标**和一个**证伪阈值**。合格标准：一周后你能用同一个指标重新验证这句话；只有叙事（「资金在进」「逻辑硬」「要启动」）不合格，因为一周后无法复核。
2. **问二（错了怎么办）**：写出具体价格或具体条件，并算出**最大亏损金额 = 买入金额 × 止损幅度**，写在纸上。合格标准：能报出一个数字；「跌了再补」「套住就拿着」不合格——它们没有数字。这一问是 [[买入之前先写下「错了怎么办」]] 的展开版：那条要求写三句话，这里要求落到金额。
3. **问三（信息链）**：信息来源逐条列出来，数**独立链**的条数——互相转引的算一条。合格标准：至少两条独立链，且其中至少一条是一手材料（公告、财报、交易所数据、行情软件自身统计）；只有群聊、博主、短视频的，条数再多也算一条。
4. **问四（钱的格子）**：说出这笔钱属于 [[先分清三种钱：保命钱、闲钱、搏钱]] 里的哪一格。合格标准：能指出现金流里的具体用途和「最晚什么时候要用」；属于保命钱的一律不过——这一问不是风险测试，是资格测试。
5. **问五（情绪与变盘价位）**：写下此刻的情绪（一个词），再写下这个情绪会令你在什么价位改变主意（两个具体价位：什么价位想加、什么价位想割）。合格标准：两个价位都是具体数字；「跌多了就补」「涨多了就跑」不合格。
6. **判定**：五问各自「过 / 不过」，任何一问不过即**放弃这笔操作**，把五问的答案原样写进日志——不过的答案比过的答案更值钱，它记的是你当时的真实状态。放弃不等于删自选：可以把标的留在观察名单，注明缺什么（例如「待补：独立第二条信息链」）。
7. **例外通道**：只有一种情况可以带着「不过」下单——问三、问四、问五其中一问不过，但问一、问二双过，且能在日志里写清「这一问为什么这次不适用」。通道每月最多用一次，用第二次说明你在给自己开便门。
8. **答案的物理形态**：写在纸上或一个固定文件里，必须包含日期时间、五条答案、五个判定、最终动作四样；只存在于脑子里的一律视为没走。走完五问的用时记在末尾——它是你决策速度的自检，稳定超过十五分钟说明你在犹豫，而犹豫本身通常就是答案。

**五问与 [[买入之前先写下「错了怎么办」]] 的分工**：站内已有条目要求「买入前写下三句话」（为什么买 / 什么条件认错离场 / 对了怎么办），本条不是它的重复，而是把这三句话扩展成五问，补上它没有覆盖的三个维度。两件的分工如下表——同时用，不冲突。

| 维度 | 「写三句话」条目 | 本清单 |
|---|---|---|
| 买入逻辑 | 一句话理由 | 问一：理由必须含可观测指标 + 证伪阈值 |
| 离场 | 认错条件 + 最大亏损金额 | 问二：同一个金额，且要求是乘出来的 |
| 信息来源 | 不涉及 | 问三：独立链条数 ≥ 2，至少一条一手 |
| 资金资格 | 不涉及 | 问四：保命钱 / 闲钱 / 搏钱分格 |
| 情绪与自我预测 | 不涉及 | 问五：情绪一个词 + 两个变盘价位 |

**月度汇总表（月末一次，十分钟）**

| 统计项 | 本月 | 上上月 | 说明 |
|---|---|---|---|
| 走过五问的笔数 |  |  | 含放弃的 |
| 因五问不过而放弃的笔数 |  |  | 低于一笔要警惕 |

| 例外通道用了几次 |  |  | 每月上限一次 |

**五问与合格标准速查**

| # | 问题 | 合格的答案长什么样 | 不合格的样子 |
|---|---|---|---|
| 一 | 为什么买 | 「板块成交额连续三日放大，个股涨幅第一；若次日量能低于今日 80%，判断失效」 | 「感觉要涨」「资金在进」 |
| 二 | 错了怎么办 | 「止损 9.80 元，最大亏损 5,500 元（总资产 1.10%）」 | 「跌了再补」「长期看好」 |
| 三 | 信息几条链 | 「①行情软件板块统计 ②公司公告 → 独立链 2 条」 | 「群里三个人都说了」（互转，算 1 条） |
| 四 | 钱属于哪格 | 「搏钱，三年内不用」 | 「应该用不到吧」 |
| 五 | 情绪与价位 | 「怕错过；跌到 10.20 元想加，跌到 10.00 元想割」 | 「有点紧张」 |

**算例**（假设案例，标的为占位代码 999999，不指向任何真实公司；价格与比例全部为假设参数）

初始条件：总资产 50 万元。4 月 8 日 14:20，999999 从 10.00 元拉到 10.90 元（+9.0%），自选股群里在喊「加速了」。想追 5,000 股 × 10.90 元 = 54,500 元，占总资产 10.9%。坐下来走五问：

| # | 问题 | 写下的答案 | 判定 |
|---|---|---|---|
| 一 | 为什么买 | 原话「板块龙头连板，资金在进」——证伪阈值写不出。改写尝试：「若次日涨停打开且量能低于今日 80%，判断失效」 | **不过**：阈值要靠买入之后的数据才验得完，属于事后补证伪 |
| 二 | 错了怎么办 | 原话「跌了再补」——补多少、什么价位，答不出。按 [[买入之前先写下「错了怎么办」]] 补写：止损 9.80 元，最大亏损 = (10.90 − 9.80) × 5,000 = 5,500 元，占总资产 1.10% | 过 |
| 三 | 信息几条链 | 来源只有自选股群一条消息，群内三人转发同一张图，互相转引 | **不过**：独立链 1 条，且没有一手材料 |
| 四 | 钱属于哪格 | 这笔钱是三个月后要付的装修款 | **不过**：保命钱 |
| 五 | 情绪与价位 | 情绪「怕错过」；「低开 3% 我会想割，再涨停我会想加仓」 | 过（两个价位都具体） |

五问三过两不过——按规则放弃。放弃动作三个：①五问答案原样写进日志（用时 12 分钟，在 15 分钟时间盒内）；②把 999999 移进观察名单，注明「待补：独立第二条信息链」；③设一个次日 14:50 的提醒，只做记录，不下单。

次日 14:50 的提醒记录（假设参数）：

| 动作 | 数字 |
|---|---|
| 999999 开盘 | 11.12 元（高开 2%） |
| 当日收盘 | 10.70 元（−1.8%） |
| 若当日按原计划追入 5,000 股，收盘账面 | (10.70 − 10.90) × 5,000 = −1,000 元 |
| 一周后价格 | 10.20 元，账面 (10.20 − 10.90) × 5,000 = −3,500 元，占总资产 0.70% |
| 观察名单上的更新 | 补到独立第二条链了吗？没有——缺的是一手材料，不是消息数量 |

问一的细节值得单独说：第一次写出的「板块龙头连板，资金在进」是典型的叙事句——两个分句都不可观测。改写尝试「若次日涨停打开且量能低于今日 80%，判断失效」看起来有了指标，但它仍然不合格，因为这个阈值必须靠**买入之后**的数据才验得完。合格的证伪阈值必须能在**买入前或买入当下**被检验（例如「今日成交额未进板块前三即不成立」），否则它只是给已经做出的决定配一句事后解释。分界线是：阈值依赖的数据，在你按下买入键之前拿不到，就是事后补证伪。

一个月后回看这份记录，真正有价值的不是那 3,500 元，而是两行结构性的东西：问三的答案是「群聊一条」，问四的答案是「装修款」——这两条在这个月里出现了四次。这意味着问题不在 999999，在你的信息源结构和现金流；五问的价值就是把这种重复暴露出来。见 [[投资日记:记决策不记盈亏]]：五问表是它「买入记录」字段的前置，没有五问的记录，信息来源那一栏永远是空的。

必须说清的一点：那 3,500 元**不能记成「五问帮我赚到的」**——没走五问的世界线不存在，无法验证；纪律记录里只记一句「按规则放弃了，理由：独立链不足、资金属保命钱」。把避免的亏损计成功绩，是另一种自欺，见 [[结果偏误：按盈亏判决策是最常见的错]]。

**常见错**

1. **先下单再补五问**——答案会自觉向「合格」靠拢，清单退化成签字仪式；时间盒从落笔开始算，不从买入算。
2. **问三数消息条数而不是独立链条数**——三条群聊消息说的是同一句话，是零条独立链；判定标准是「去掉一条，另一条还在不在」。
3. **问四用「感觉」代替现金流**——「应该用不到」不是答案；合格答案要指到具体用途和最晚用款日。
4. **五问都过了就以为能买**——五问只拦糊涂账，不提供正面理由；问一、问二双过只说明这笔可承受，不说明它值得做。
5. **同一问反复不过却不改结构**——连续四笔卡在问三，要修的是信息源（去补公告、财报、交易所数据），不是继续在同一张表上打叉。
6. **问五只写情绪不写价位**——「怕错过」三个字没有约束力；配上「跌到 10.20 元想加、跌到 10.00 元想割」之后，这个情绪才在纸上留下痕迹，下次才认得它。
7. **放弃之后天天回头看错过的那只票**——五问的产出是「不操作」这个动作，不是「监视」这个动作；观察名单一个月更新一次即可，回看频率比操作频率高，等于没放弃。

**做完你会得到**：每笔操作一张五问表（日期时间、五条答案、五个判定、最终动作、用时），外加一张月度统计：本月几笔走了五问、几笔因此放弃、放弃的理由集中在哪几问、例外通道用了几次。集中的那一问就是你下一次要改的结构性问题——总卡在问三，说明你的信息源结构有缺陷，不是某只票的问题。

**怎么算过关**：随机调一笔你最近做过的买入，五问的答案能在纸上复原出四条以上（日期、金额、离场条件、信息来源条数）；复原不出，说明那笔当时没有走五问。再看本月记录：至少有一笔是因为五问不过而放弃的——一笔都没有，要么你的每一笔都真的合格（罕见），要么清单在给既成事实签字。

## 说人话

是什么：下单之前，逼自己回答五个问题，每个问题都要求一个能被别人核对的答案。五问答完，这笔买卖要么变得很清楚，要么暴露出它本来就是一笔糊涂账——两种结果都有用，因为你省下的是真金白银。

为什么发生：买入的冲动来得最快的时候，恰恰是你信息最不全的时候——群里在喊、分时线在拉、你的手已经放在键盘上。这时候问你「为什么买」，大脑会立刻编一个听起来像理由的故事，而且编得又快又自信。清单的作用是把五个问题提前印在纸上，让它们在冲动到达之前就问完：答案必须落在纸上，嘴里说的不算，因为嘴上的答案不用负责。

什么时候不成立：一、对多年期、低频率的定投与资产配置决策，逐笔走五问是浪费——这类决策的正确对象是比例和纪律，不是单笔（见 [[博格：别试图跑赢市场，定投宽基指数]] 一路的做法）；二、如果你用的已经是跑过很长时间的机械规则，五问的答案就是规则本身，走一遍等于抄一遍，留痕即可；三、清单拦不住「你已经决定要买」的那种状态——这时人会无意识地往合格答案上靠，所以问五要求先把情绪写下来，让答案的成色有据可查。

## 收益

量级（口径：亏损）：五问里唯一能事前算出数字的是问二的「最大亏损预算」= 仓位占比 × 止损幅度。本例 10.9% × 10.1% ≈ 总资产的 **1.1%**（5,500 元）；若满仓 50 万元配同样的 10% 止损，预算就是 **10%**（5 万元）——同一条止损线，差约 **9 倍**。这个数怎么用：把它当下单前必须书面批准的预算，预算超过你能承受的数就先降仓位；预算内的亏损触发时执行，不重新评估。至于「五问拦掉了多少亏损」，属反事实，「无公开统计」，本条不计入收益。

## 备注

- **适用前提**：五问针对**单笔操作**，不针对资产配置比例与定投纪律（那类决策的正确对象是规则本身）；时间盒十五分钟是自设值，可长可短，但不许跳过。卖出场景同样适用：问一改成「为什么现在卖」，问三改成「卖出的依据有几条」（怕跌不算依据，写下的离场条件才算）。
- **已知反例**：真实情形——pre-mortem 的原始文献（Klein 2007）自己指出，它在项目场景里也可能诱发「预防性悲观」与责任推诿；个人版本中对应的失效形态是「过度使用例外通道」，每月第二次开始，清单就变成橡皮图章。另一个真实边界：五问拦不住信息链结构本身的缺陷——如果一个人的全部信息源都在同一个圈子里，问三永远不过，该修的是信息源，不是清单。
