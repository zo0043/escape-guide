## 怎么做

**什么时候用**：你发现自己每天都要看盘、每周都要动手、空仓就难受的时候；或者年度复盘，想知道「手续费和税吃掉我多少」的时候。A 股现实形态：行情软件的分时脉冲、直播间的晒单、一键跟单，都在把「动手」的心理成本降到零；而印花税只向卖出方收——卖得越多，被刮得越频（本站已核原文，见来源）。另一个高发场景：月底或年末，账户差一点回本，你想「做回来」——此时动手欲最强，而它恰恰是成本率最高的时候（站内 A 级复算，见 [[一笔数学：亏一半要赚一倍才回本]]）。

**步骤**
1. 导出最近三个月的交割单，数「完整往返」：同一标的买入一次 + 卖出一次 = 一个往返，算出月均笔数（不凭记忆）；
2. 把算例里的费率换成你的实际佣金（问券商或看交割单），滑点先按 0.1%/边假设，算出你的单往返成本（占单次交易额的比例）与年成本率（占账户的比例）；
3. 检查税时钟：你有没有「赚点小钱就卖」？卖出时点离除权除息日多久？持有不满一个月，股息红利税负最高档（站内 A 级复算，见 [[红利税：持股期限决定税率]]）；
4. 检查触发源：每一笔交易对应的是「想法变了」还是「价格动了」？价格一动就下单的，归入「手痒类」，数出占比；
5. 替代动作：每笔交易前写下「这次买卖对应我原来的哪个判断变化」，写不出来就不动；把动手欲转移到零决策动作上——定投宽基指数，让「不动」也有产出（站内 B 级复算，见 [[博格：别试图跑赢市场，定投宽基指数]]）；
6. 设冷静期：任何计划外交易，写下理由后放二十四小时再执行；每月把往返笔数和上个月比，只降不升算达标。
7. 给「动手欲」找一个出口：把看盘时间换成读公司公告与规则的时间，把「想操作」变成「想清楚」——想法没变，手就不动；这是唯一能同时降低费用与税负的动作（站内 A 级复算，见 [[如果今天空仓，你还会买现在的持仓吗]]）。

**记录模板**（每月复盘用，直接抄）：

> 本月往返 N 笔；单往返成本 N 元；年成本率 N%；「想法变了才动」记录 N 条；卖出在持股不满一个月内的 N 笔；与上月比：降／平／升。

模板说明：五行就够。核心是第三行和第四行的对比——记录条数少于往返笔数的部分，就是你为手痒付的钱。

**机制拆解表**（为什么有害，一步一步）：频繁交易的花费不是一次性的，是四个环节按次累积，其中两个不出现在交割单上。

| 环节 | 发生了什么 | 算例里的数字 |
|---|---|---|
| 触发 | 价格一动就想动手；软件把下单成本降到零，手痒被记成盘感 | 每周四分之一仓轮动一次 = 全年 52 个往返 |
| 费用 | 佣金、印花税、过户费按次收；印花税只向卖出方收，卖得越多刮得越频 | 一个往返 151 元 = 单次交易额的 0.302% |
| 滑点 | 你下单的价格与成交价的差，每一笔都发生、每一笔都不开票 | 假设 0.1%/边 = 往返 100 元，占 151 元里的大头 |
| 税时钟 | 分红税按持股期限分三档；换来换去，把免税档换成最高档 | 同一笔 1,000 元股息，差 200 元 |

表说明：费用和滑点是「按次」的钱，税是「按期限」的钱，两者叠加的效果见收益节与长期收益的对比。滑点不在交割单里，所以最容易被漏掉——它不是小，是你看不见。

**算例**（假设案例，不指向任何真实公司，代码用 999999）：账户平均总资金 200,000 元；每周用四分之一仓位（50,000 元）轮动一次，全年 52 个往返。费率：佣金 0.025%/边、过户费 0.001%/边、滑点 0.1%/边（均为假设参数，以你与券商的约定和实际成交为准）；印花税卖出方 0.5‰（现行监管口径，见来源）。

| 项目 | 数字 |
|---|---|
| 买入边成本 | 50,000 ×（0.025% + 0.001% + 0.1%）= 63 元 |
| 卖出边成本 | 63 元 + 印花税 50,000 × 0.05% = 88 元 |
| 一个往返合计 | 151 元 = 单次交易额 50,000 元的 0.302% |
| 每周一轮（52 个往返/年） | 52 × 151 = 7,852 元 = 账户的 3.93%/年 |
| 每月一轮（12 个往返/年） | 12 × 151 = 1,812 元 = 账户的 0.91%/年 |
| 一年不动 | 0 元 |
| 红利税时钟（同一笔 1,000 元股息，站内 A 级复算口径） | 持股不满一个月卖出扣 200 元；一个月至一年扣 100 元；超过一年 0 元 |
| 和长期收益比 | 沪深 300 自 2005 年起年化 +7.02%（站内 A 级复算，见 [[A股长期收益与回撤]]）→ 3.93% ≈ 长期年化的 56% |
| 现实参照（A 级，原文 PDF） | 1991–1996 年美股某大型折扣券商 66,465 户中：交易最活跃者年化 11.4%，市场 17.9%，平均家庭 16.4%、年均换手 75% |

算例说明：151 元 = 63 + 88；3.93% = 7,852 ÷ 200,000；56% = 3.93 ÷ 7.02，全部可手算复核。滑点、佣金、换手频率均为假设参数；Barber & Odean 是美股样本，其「年化收益」口径与本算例的「成本拖累」不是同一个量，两个数并排只为说明「换手要付费、且代价与长期收益同量级」。

**三档频率对照表**（同一个账户、同一套费率，只改动手频率）：

| 频率 | 年往返数 | 年成本（元） | 占账户比例 | 税时钟 |
|---|---|---|---|---|
| 每周一轮 | 52 | 7,852 | 3.93% | 持股多不满一月 → 最高档 |
| 每月一轮 | 12 | 1,812 | 0.91% | 视时点，常落中间档 |
| 一年不动 | 0 | 0 | 0% | 持股超一年 → 免税档 |

表说明：三行的差别不在眼光，在频率。成本率与频率成正比——这是本条唯一「可复算」的结论：你多动一次，就多付一个 151 元（按本算例参数），且这个钱在任何行情下都要付。

**研究口径表**（A 级，原文 PDF；引用这些数字时必须保留的口径）：

| 数字 | 原文口径 | 写法注意 |
|---|---|---|
| 66,465 户 | 1991–1996 年某大型折扣券商的家庭账户 | 美股样本，幅度不直接搬 A 股 |
| 11.4% | 交易最活跃者的年化收益 | 原文是 annual return，不是净收益 |
| 17.9% | 同期市场的年化收益 | 与 11.4% 同为年化口径，才可比 |
| 16.4% | 平均家庭的年化收益 | 与 11.4% 分开写：一组是最活跃 vs 市场，一组是平均 vs 市场 |
| 75% | 平均家庭的年均换手率 | 换手口径，不是收益率 |
| 高 beta、小市值、价值股 | 平均家庭的持仓偏向 | 原文是 value stocks，不是 growth |

表说明：本站已解包 PDF 摘要逐字核对以上数字（核对于 2026-10-12）。摘要只给结论；正文里「最活跃组落后市场」在费用、选股、时点之间的分解未逐节核对，所以本条只引摘要数字、不写分解（见来源的「需人工核对」条）。

**常见错**
1. 只算佣金、漏印花税与滑点——印花税只向卖出方收（本站已核原文），卖得越多刮得越频；滑点不出现在交割单里，但每一笔都真实发生；
2. 把「感觉手痒」当「市场有机会」——触发源是情绪不是信息；标准动作是数往返笔数，不是找机会；
3. 用「这次是短线机会」跳过自查——如果每一笔的理由都是同一句话，触发源就从来不是机会；
4. 忽略红利税时钟——税按持有期限分档，换手把零档换成最高档；1,000 元股息差 200 元，约等于本算例往返成本的 1.3 倍；
5. 拿「巴菲特也换仓」给自己开灯——他的换手频率与成本结构和散户不是一回事；要比频率，先比谁的单笔成本是十万分之几（站内 B 级复算，见 [[博格：别试图跑赢市场，定投宽基指数]]）；
6. 把「没交易」当成「没在工作」——不交易是持仓状态，不是停工；定投宽基的人一次都没动手，复利照样在走（站内 A 级复算，见 [[A股长期收益与回撤]] 的长期口径）。

**做完你会得到**：五个数——月均往返笔数、单往返成本、年成本率（占账户比例）、税时钟检查结果、「手痒类」交易占比；外加一叠书面理由：「这笔交易对应我哪个判断变化」。把这五个数按月连起来，就是你自己的「动手成本曲线」——它下降的速度，就是你从「手痒」回到「决策」的速度。

**怎么算过关**：你能报出最近三个月的往返笔数、按你自己费率算出的年成本率、以及「想法变了才动」的书面记录条数（笔数 = 记录条数才及格）；只答得出「我最近好像交易有点多」= 不过关。第二档过关：连续两个月的往返笔数不升，且没有一笔卖在「持股不满一个月」的红利税最高档。

## 说人话

是什么：「多做多赚，不做手痒」——把动手当成努力，把空仓当成浪费。它没说的是：每一笔进出都在付费，而费用是按次收的，不是按年收的；不交易，成本为零；交易一次，成本就从第一个往返开始累积。

为什么发生：单笔费用看着极小，小到不值得算；可乘上一年的次数，就和宽基指数的长期年化收益同一个量级。更隐蔽的是税：分红税的税率看持股期限，换来换去，把免税档换成了最高档。而交易软件上，价格每动一下都在降低你动手的心理成本；你记住的永远是「差一点就抓到」那几次，说错的部分沉在群底——于是手痒被记成了盘感。

什么时候不成立：这不是「交易必亏」。如果你的每笔超额确实大于成本，交易就是你的生意，费用是进货价（站内 A 级复算，见 [[频繁交易的换手成本]]）。本条只要你做一件事：把「感觉手痒」和「想法变了」分开——前者在付费，后者才是决策。

## 收益

量级（口径：亏损）：算例中，50,000 元单次轮动的往返成本 151 元（0.302%），每周一轮全年 7,852 元 = 账户 200,000 元的 3.93%，约为沪深 300 长期年化 7.02% 的 56%；同一笔 1,000 元股息，持股不满一个月与超过一年之间差 200 元。现实参照（A 级，原文 PDF）：1991–1996 年美股 66,465 户家庭中，交易最活跃者年化 11.4%，同期市场 17.9%，平均家庭 16.4%。这个数怎么用：数你月均多少个往返，乘你的单往返成本，得到年成本率；拿它和账户去年实际收益比——大于收益，说明你在为「动手」付钱；再查一次卖出时点，把税时钟从最高档挪回零档。两个动作都不预测市场，只改变你自己的成本结构。

## 备注

- **适用前提**：佣金、过户费、滑点均为假设参数，换成你的实际费率数字会变（方向：佣金越高、滑点假设越大，拖累越大）；印花税 0.5‰ 为现行口径，随监管调整（见 [[频繁交易的换手成本]] 的来源节）。Barber & Odean 的样本是 1991–1996 年美股折扣券商家庭，机制可迁移，幅度不可直接搬到 A 股。另：本条只算「成本与税」的账，不预测任何标的的涨跌——它证明的是「动手要付费」，不是「动手必亏」。
- **已知反例**：真实情形：有交易者的每往返超额大于成本，高频是其赚钱方式——成本是「价格」不是「判决」（站内 A 级复算，见 [[频繁交易的换手成本]] 的已知反例段，该条不量化）。另有一个站内真实记录：B&O 样本里平均家庭（年化 16.4%）同样低于市场（17.9%）——差距不只发生在最活跃组，说明「少交易」本身不保证达标，仓位与选股仍在账里。这两条推翻的是「交易必亏」和「不动就赢」，不是「换手要付费」。还有一个常被忽略的方向：本条的成本算术对「大资金、低费率、有返佣」的账户不成立——费率结构不同，结论的幅度就不同，但「按次付费」的机制不变。
