## 怎么做

**什么时候用**：两种触发，都写在事前。其一，**定期**：你定的检查点到了（每季末 / 每半年 / 每年固定一天），不管行情涨跌都做一次配比检查；其二，**定阈**：大涨或大跌之后，某类资产占比偏离目标超过你写的阈值。注意：触发机制在开仓时定好，不是看到大涨之后临时起意「该调一调」——临时起意的那一刻，动作的理由已经是行情判断，不是机制。

**步骤**

1. 先写目标比例：股票 / 债券 / 现金各占多少——这是你自己的参数，由钱属于哪一格（[[先分清三种钱：保命钱、闲钱、搏钱]]）与可承受回撤决定；没有目标比例，就没有再平衡，只有择时；
2. 选触发方式：定期（固定检查点）或定阈（偏离超过自设阈值才动），二选一写在纸上，不混用、不临场改；
3. 检查点到了，先算漂移：每类资产当前占比 = 市值 ÷ 总资产，与目标对比，逐项写下偏离（个百分点）；
4. 偏离超过书面阈值 → 执行拉回：卖出偏高的资产、买入偏低的资产，拉回目标比例；未超过 → 不动，记录「本期已检查，偏离未触发」；
5. 每次操作记录三个数：漂移前的占比、拉回金额、拉回后的占比——记进 [[投资日记:记决策不记盈亏]]；
6. 单一市场内部的个股之间不做「再平衡」：个股之间卖涨买跌是轮动，是择时，不是本条的对象（边界与 [[自动化纪律:把规则交给制度]] 一致）。

**算例**（假设案例：收益率、比例、阈值全部为假设参数，不指向任何真实市场年份或产品）

初始条件：总资产 200,000 元（假设），目标比例股票 60% / 债券 40%，即 120,000 元股票 + 80,000 元债券；规则：每季度末检查一次，股票占比偏离 60% 超过 5 个百分点才拉回。

| 动作 | 数字 |
|---|---|
| 期初 | 股票 120,000 / 债券 80,000 / 合计 200,000，股票占比 60.0% |
| 某季度：股票 +25%（假设） | 股票 120,000 × 1.25 = 150,000 |
| 同期：债券 0%（假设） | 债券 80,000 |
| 检查点合计 | 150,000 + 80,000 = 230,000 |
| 当前股票占比 | 150,000 ÷ 230,000 = 65.2% |
| 漂移 | 65.2% − 60% = +5.2 个百分点（超过自设 5 个百分点阈值 → 触发） |
| 拉回金额 | 150,000 − 230,000 × 60% = 150,000 − 138,000 = 12,000 元（卖股票买债券） |
| 拉回后 | 股票 138,000 / 债券 92,000 / 合计 230,000，股票占比 60.0% |
| 漂移实际改变了什么 | 风险敞口：股票占比 60% → 65.2%，什么都没做，赌注却放大了 (65.2 − 60) ÷ 60 ≈ 8.7% |

为什么这是防守而不是收益：拉回做的事是把风险敞口拉回你事前认下的水平——按 [[一笔数学：亏一半要赚一倍才回本]] 的不对称，敞口每高一分，极端情形下回本所需的涨幅就高一分；「+5.2 个百分点的漂移」就是没注意时多押的那一分。单边强趋势里这个动作会「卖涨买跌」、可能跑输不操作的人——这是机制的固有代价（见备注已知反例）；「是否稳定跑赢」无单一官方口径，各家研究的口径（收益路径、波动率、成本假设）互不相同、不可直接比，证据状态声明见 [[自动化纪律:把规则交给制度]] 来源节，本条不引用任何回测数字。

**常见错**

1. 把再平衡当收益动作——「卖涨买跌」之后宣称「我判断对了」；单边趋势里这个动作会持续跑输，买的是纪律，不是收益；
2. 在单一市场个股之间做「再平衡」——那是个股轮动 / 择时，再平衡的对象是资产类别之间的比例；
3. 偏离快触发时临场改阈值（「再多偏离一点再调」）——阈值是纸上写的参数，临场改与止损线「往上挪一挪」是同一个形状；
4. 单资产组合也「再平衡」——只有股票一个资产类别，没有可拉回的比例，先看 [[别满仓，别单吊]] 的仓位上限。

**做完你会得到**：一张写好的目标比例与触发方式（定期 / 定阈、阈值多少），加每个检查点一条漂移记录（偏离几个百分点、是否触发、拉回金额）——组合的风险敞口从「随行情漂移」变成「在检查点回到自设水平」。

**怎么算过关**：随便指出你的多资产组合，你能立刻报出目标比例、触发规则（例如「每季末检查、偏离 5 个百分点拉回」）与最近一次检查的漂移数；只答得出「配比看着不对就调一调」= 不过关。

## 说人话

是什么：再平衡是周期性的「把配比复位」——开仓时定好各占多少，到检查点时，不管行情怎么涨跌，把实际配比拉回定好的那个比例。它看起来是「卖涨买跌」，但动作的依据不是行情判断，是「纸上这么写的」。

为什么发生：只要价格在动，配比就在漂——涨得多的资产占比越占越大，你的实际赌注在悄悄放大。这个过程是安静的：没有警报，没有提示，风险自己长大。定期检查加机械拉回，就是逼自己「看见漂移」的办法：看见了，赌注还是你事前认下的那个数。

什么时候不成立：其一，单边强趋势里「卖涨买跌」会持续跑输不操作的人，这是机制的固有代价，不是规则写错——先认了这一点才谈得上用；其二，对象是资产类别之间的比例（股票 / 债券 / 现金这类），单一市场内部个股之间卖涨买跌是择时，本条不管；其三，只有一个资产类别的组合没有比例可拉，先见 [[别满仓，别单吊]]。

## 收益

量级（口径：亏损）：本条的数字是「风险敞口漂移」：算例里股票占比从 60% 漂到 65.2%，实际赌注放大约 8.7%（(65.2 − 60) ÷ 60），而这个过程没有经过任何一次你的决定；拉回金额 12,000 元是把它拉回 60% 的代价（未计交易成本，小账户应先算成本占比，见 [[自动化纪律:把规则交给制度]] 的成本上限）。按 [[一笔数学：亏一半要赚一倍才回本]] 的不对称，敞口 65.2% 时极端情形回本所需的涨幅高于 60% 时——漂移的成本不在平时，在极端情形里。这个数怎么用：每个检查点先算漂移（个百分点）再对照自设阈值，超了就执行拉回，动作不再「想不想卖」；漂移记录里「未触发」也是记录——连续几个「未触发」与一次「触发拉回」同样有价值。

## 备注

- **适用前提**：只对多资产（股票 / 债券 / 现金，或宽基与债基这类资产类别）做，单一市场内部个股之间不做；目标比例、检查频率、阈值全部是自设参数，本站不给标准值；把这套机制固化成自动执行（纸 + 系统设置 + 熔断）见 [[自动化纪律:把规则交给制度]]。
- **已知反例**：真实情形一：单边强趋势里，再平衡机械地「卖出涨得最好的、买入跌得最惨的」，趋势延续时多个检查点都跑输不操作的人——它无法事前告诉你趋势会不会延续，这是风控机制的固有代价（与 [[自动化纪律:把规则交给制度]] 的声明一致）。真实情形二：股债同跌时拉回不改变方向——2022 年股债双杀里，按固定比例自动再平衡的产品在两个方向上同时被机械执行放大（见 [[2022股债双杀:通胀和加息一起砸下来]] 的社会学节），再平衡管的是漂移，不是方向。
