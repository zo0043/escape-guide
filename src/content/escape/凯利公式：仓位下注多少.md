## 怎么做


**什么时候用**：你算完这笔交易的期望值为正（见 [[期望值与破产：仓位是算术问题]]），准备决定「这笔用总资金的多少」的时候。

**步骤**
1. 写下两个参数：这笔交易的胜率 p，以及赢/输比 b（赢一次平均赢 b 个单位、输一次平均输 1 个单位）；
2. 算期望值 EV = p·b − (1−p)；EV ≤ 0 就不下注，公式的答案是 0；
3. 算满凯利 f* = p − (1−p)/b；
4. 拿 f* 和你自设的仓位上限比，取小者；实践中常用半凯利（f* ÷ 2）或更低。

**算例**（假设案例，不指向任何真实公司）：你看到一次机会：胜率六成、赢一次平均赢 1.5 个单位、输一次平均输 1 个单位（p 与 b 均为假设参数，不是市场统计值）。总资金 100,000 元。

| 动作 | 数字 |
|---|---|
| 胜率 p、赢输比 b（假设） | p = 0.6，b = 1.5 |
| EV = p·b − (1−p) | 0.6 × 1.5 − 0.4 = +0.5 > 0 → 值得下注 |
| f* = p − (1−p)/b | 0.6 − 0.4/1.5 = 0.3333 → 满凯利 = 33.3% |
| 满凯利仓位 | 100,000 × 33.3% ≈ 33,300 元 |
| 半凯利仓位（实践中更常用） | 100,000 × 16.7% ≈ 16,700 元 |
| 敏感性：真实胜率其实是 0.5 | 真实 f* = 0.5 − 0.5/1.5 = 16.7%——你的「满凯利」已是真实最优的 2 倍 |
| 敏感性：真实胜率其实是 0.4 | EV = 0.4 × 1.5 − 0.6 = 0，f* = 0（本不该下注）；若仍按 33.3% 下注，长期几何增长率 = 0.4·ln(1 + 1.5 × 0.3333) + 0.6·ln(1 − 0.3333) = 0 |

算例说明：公式来自最大化几何增长率——每次下注 f 比例，g(f) = p·ln(1 + b·f) + (1−p)·ln(1 − f)，令导数 g′(f) = p·b/(1 + b·f) − (1−p)/(1−f) = 0，解得 f* = (p·b − (1−p)) / b = p − (1−p)/b。表中数字均为算术确定，可复算。

**常见错**
1. 用「感觉」的胜率喂公式——p 高估一成，满凯利就系统性过度下注（见表中敏感性行）；高估 p 的代价远大于低估 p 的代价。
2. 把满凯利当日常仓位——公式假设「多次独立重复、无杠杆、无成本、参数恒定」，真实市场一条都不满足，所以实践中常用半凯利或更低。
3. EV ≤ 0 仍下注——此时 f* ≤ 0，公式的答案是「不下注」；硬下注，仓位越大死得越快。

**做完你会得到**：三个写下的数（EV、f*、实际用的仓位），以及实际仓位为何可能小于 f* 的理由（半凯利 / 自设上限 / 参数不确定）。

**怎么算过关**：你能报出 p、b 各是多少、从哪来的（哪个数据、多少笔历史），以及实际仓位为什么不高于 f*；只答得出「我有信心」= 不过关。

## 说人话

是什么：凯利公式回答的是「值不值得下注」之后的下一个问题：下多大注。把胜率写成 p，把平均赢输比写成 b（赢一次平均赢多少、输一次平均输多少），最优仓位比例就是 p 减去（输的概率）除以 b。下得比它多，长期会输得比赢得快；下得比它少，赚得慢，但不会死。

为什么发生：连续下注同一类游戏，长期增长不取决于「平均每次赢多少」，而取决于「赢与输的复利效果」。下注过重时，输一次就输掉更大比例，而亏一半需要翻一倍才回本——亏损的咬合比盈利深。公式找到的，正是「赢时增长速度」与「输时衰减速度」平衡最好的那个比例。所以它是「增长率」问题，不是「期望值」问题。

什么时候不成立：两种情形。其一，它要求多次独立重复——一次性交易（押某家公司的一次性公告）没有「长期复利」，这时用期望值与破产那条的「极端损失预算」更合适。其二，它的前提是你**知道** p 和 b——胜率写不出来，公式就没有输入，不能用「感觉」喂（见备注反例）。

## 收益


量级（口径：亏损）：满凯利是「长期几何增长率」最大的仓位——它是仓位的上限，不是建议值。算例中（p = 0.6、b = 1.5，假设参数）：满凯利 33.3%、半凯利 16.7%；胜率若高估一成（真实 0.5），真实最优只有 16.7%；高估两成（真实 0.4），真实最优为 0（本不该下注）。这个数怎么用：算出 f* 之后，取半凯利或更低做仓位上限；p 写不出来的交易，动作是不下注。

## 来源

推导型（无需外部出处，按来源规则记 A 级）：f* 由最大化几何增长率导出——每次下注总资金的比例 f，g(f) = p·ln(1 + b·f) + (1−p)·ln(1 − f)；令 g′(f) = p·b/(1 + b·f) − (1−p)/(1−f) = 0，解得 f* = (p·b − (1−p)) / b = p − (1−p)/b。数值验算：p = 0.6、b = 1.5 → f* = 0.6 − 0.4/1.5 = 0.3333（满凯利 33.3%）；EV = p·b − (1−p) = 0.5 > 0（值得下注）；若真实胜率 0.4，EV = 0.4 × 1.5 − 0.6 = 0，f* = 0（不下注）。数字由算术确定，比任何文献都确定。推导已于 2026-10-11 复核（本站 P0 来源核对笔记第 6 项，A 级推导型）。

## 备注

- **适用前提**：p 与 b 必须写得出来（哪个数据、多少笔历史——可以错，但要写得出来）；对象是可重复的一类下注中的单笔仓位；一次性交易请改用 [[期望值与破产：仓位是算术问题]] 的「极端损失预算」法。
- **已知反例**：真实情形：凯利公式对胜率高估极其敏感——1998 年长期资本管理（LTCM）式的量化基金崩盘（公开史料）即「模型方向大致正确、但参数（尾部风险概率）被低估、再叠加杠杆」的真实案例。这不是公式的反例（公式本身仍然正确），而是「实操必须打折（半凯利或更低）、且严禁杠杆」的真实依据。
- **关联条目**：[[期望值与破产：仓位是算术问题]]（EV 答「值不值得」，凯利答「下多大」，成对使用）、[[别借钱炒股]]（杠杆使 f* 上限失去意义——破产边界先于公式变化）、[[一笔数学：亏一半要赚一倍才回本]]（「下重了输得快」的算术根源）、[[先分清三种钱：保命钱、闲钱、搏钱]]（只有搏钱那一格适用凯利）。
