## 怎么做

**什么时候用**：三个具名场景。①回本执念：浮亏仓位「等回本就卖」，回本线是你自己画的，市场不认；②止损困难：到了事前写好的线，开始「再等等」「可能快反弹了」，线越挪越低；③处置效应：赚钱的拿不住、亏钱的撒不开，卖出清单里盈利仓的平均持有天数远短于亏损仓。另有一个常被漏掉的场景：④小概率上头——因为「听说有可能重组」「据说要停牌」重仓一只票，这是权重函数在投资里的样子：对极低概率过度反应，把百万分之一当一成概率下注。四个场景是同一个根：参照点定在成本价上，风险偏好跟着参照点变形。

**参照点对照表（先分类，再处理）**

| 参照点类型 | 例子 | 是否合法 | 处理方式 |
|---|---|---|---|
| 买入价（成本价） | 「我 20 元买的」 | 否 | 从理由里划掉 |
| 历史高点 | 「离高点还差一半」 | 否 | 划掉，与价值无关 |
| 别人给的目标价 | 群消息、研报目标价 | 否 | 先问出处，再划掉 |
| 自己推的估值 | 按现金流折现算的合理价 | 是 | 保留，作为唯一合法参照 |

**S 形价值函数的四个区间（对照自己的动作）**

| 区间 | 价值函数形状 | 风险态度 | 投资里的典型动作 | 对照动作 |
|---|---|---|---|---|
| 收益区（小赚） | 凹 | 风险厌恶 | 赚一点就落袋 | 问「未来值不值」，不问「赚没赚」 |
| 收益区（大赚） | 凹 | 风险厌恶 | 要么过早止盈，要么回吐后才走 | 事前写下止盈/减仓条件 |
| 损失区（小亏） | 凸 | 风险寻求 | 「再等等，快回来了」 | 触发事前止损线就执行 |
| 损失区（大亏） | 凸 | 风险寻求 | 补仓摊平、借钱翻本 | 停手；先降风险暴露 |

用法：把最近三笔决策填进这张表——同一笔交易，落在哪个区间，就预判自己会冒出哪种动作；预判到了，动作发生时才能认出来。

**四主张速查表（一条一场景）**

| 主张 | 一句话 | 投资里的场景 |
|---|---|---|
| 参照依赖 | 得失相对参照点判断，不按结果本身 | 回本执念、按成本价决策 |
| S 形价值函数 | 收益区怕风险、损失区追风险 | 赚了早跑、亏了死拿 |
| 损失厌恶 | 亏损端分量重于收益端 | 止损困难、落袋冲动 |
| 权重函数 | 极小概率被放大、中高概率被压低 | 赌重组、听消息重仓、忽视频繁小成本的累积 |

四条是同一个定理的四个侧面：参照点定了「哪里算亏」，价值函数定了「亏了赚了分别想干什么」，损失厌恶定了「哪端更重」，权重函数定了「概率被扭曲成什么样」。自查时按表逐条对照，缺哪条补哪条——只认「损失厌恶」四个字的人，通常只治好了死拿，没治好赌小概率。

四条主张的精确表述以论文原文为准（Econometrica 1979，付费墙，本机未取到逐字）；上表是中文维基转述的中文概括，只用于自查对照，不用于学术引用。

**三笔决策记录表（空白模板，复盘时填）**

| 字段 | 第一笔 | 第二笔 | 第三笔 |
|---|---|---|---|
| 标的与日期 | | | |
| 参照点（只准写一个） | | | |
| 是不是买入价 | | | |
| 落在哪个区间 | | | |
| 当天空仓会改变决定吗 | | | |
| 实际动作 | | | |
| 事后补的理由有几条 | | | |

这张表每周填一次，只填本周卖出的和本周犹豫过没卖的；填不满的空着，空格本身就是信息——空着越多，说明你对决策过程的记忆越依赖结果。连续填四周后看两列：一是「是不是买入价」里「是」的占比，二是「当天空仓会改变决定吗」里「会」的占比——两个占比就是你的参照点依赖度，比任何问卷都直接。

**步骤**

1. **写出最近三笔决策的参照点**：每笔只许写一个——成本价、历史高点、别人给的目标价、还是你自己推的估值。参照点是「买入价」的，这笔决策大概率被本条机制驱动。
2. **做一次反事实提问**：如果今天空仓、参照点消失，决定会变吗？（完整条目见 [[如果今天空仓，你还会买现在的持仓吗]]）答「会变」，说明驱动力是参照点，不是资产本身。
3. **把「已亏/已赚多少」从理由里划掉**：单笔决策只允许两类理由——看好它的未来，或不看好（与 [[损失厌恶：亏一笔比赚一笔难受得多]] 同一口径）。
4. **把止损线写进纸面**：买入前写下离场条件与最大亏损金额（见 [[买入之前先写下「错了怎么办」]]），让亏损区的「赌一把」在下单那一刻就预先支付。
5. **记录你自己的交换比例**：为避免确认一笔亏损，你占用了多少资金、多久——这是你个人的尺，比任何论文系数都贴近你自己。记法：每笔死拿的仓位写两个数——被占用的金额、从买入到今天的天数；一个月后把这些数按「亏损幅度」排序，你会发现自己在亏多少的时候最舍不得动，那个点就是你个人的拐点。
6. **识别处置效应**：把本周卖出按「持有天数 × 盈亏」分四格，盈利仓短、亏损仓长的形状出现时，就是本条机制在当班（口径见 [[结果偏误：按盈亏判决策是最常见的错]]）。
7. **给小概率上头装闸门**：任何「听说有可能……」的理由，先问三个数——概率是多少、证据是谁给的、错了亏多少；三个数答不出两个，就不该是重仓理由。这一条对应四主张里的权重函数：人对极小概率会过度反应，「万一呢」三个字在权重函数里被放大成了「很可能」。

**算例**（假设案例，标的为占位代码 999999，不指向任何真实公司；价格、天数、比例均为假设参数）

初始条件：总资产 20 万元。999999：年初 20.00 元买入 1,000 股（20,000 元），现价 14.00 元，浮亏 6,000 元（−30%）；另一只 10.00 元买入 1,000 股，现价 11.50 元，浮盈 1,500 元。

| 动作 | 数字 |
|---|---|
| 回本执念：等回 20.00 元需要的涨幅 | 30% ÷ (1−30%) ≈ 42.9%（算术见 [[一笔数学：亏一半要赚一倍才回本]]） |
| 参照点检查：最近三笔决策的参照点 | 均为成本价（买入价，非估值） |
| 反事实提问：今天空仓会按 14.00 元买它吗 | 答「不会」→ 卖出收回 14,000 元，理由只写「不看好它的未来」 |
| 个人交换比例：为不确认 6,000 元亏损 | 占用 14,000 元 × 已持有 5 个月，且未设离场条件 |
| 处置效应四格：盈利仓平均持有 | 12 个交易日；亏损仓平均持有 63 个交易日 |
| 同一机制的另一半 | 浮盈 1,500 元「落袋」→ 少赚的部分从未被记账 |
| 小概率上头（权重函数） | 用 20% 仓位赌「可能重组」——重组未发生前的期望值为负，仍重仓 |

算例说明：两个动作（死拿亏损、落袋盈利）的参照点都是成本价；对照动作的依据只有「未来值不值」。最后一行是权重函数的样子：极低概率事件被当成中高概率下注，与损失厌恶叠加时最贵——亏了不舍得走，赢了又拿不住。注意本算例不写「损失厌恶等于几倍」——该系数近年被证明测不准（见来源第 4 条），把不可靠的数字写进算例，等于给读者一把假尺。四个区间表的意义也在这里：它不预测你会赚会亏，只预判你在哪个区间会冒出哪种动作——预判到了，才谈得上拦截。

**常见错**

1. **拿具体系数做精确计算**：「亏损等于收益的若干倍」是二手转述的量级，且被证明可被操纵到消失甚至反转（A 级 PMC 全文）——方向可用，数值不可用。
2. **用理论给死拿找理由**：「我是损失厌恶，所以拿住」是识别偏差，不是豁免理由；识别之后，动作照旧按规则执行。
3. **只在亏损时想起这条**：过早卖出盈利仓是同一机制的另一半，只在被套时复盘的人永远看不到它。
4. **把参照点当价值锚**：自己按基本面推的估值是合法参照；买入价、历史高点、群里的目标价都是锚，见 [[锚定效应：成本价、高点都是锚]]。
5. **只治处置效应，不管权重函数**：「亏了赌、赚了跑」之外，「赌小概率」是同一条定理的另一面，只修一半等于没修。
6. **复盘时先看盈亏再读过程**：顺序反了就会被结果带着走，先读「当时的参照点和依据」，再看最后赚没赚。
7. **拿「四主张」给不执行找台阶**：「我处在损失区，追风险是正常的」——描述机制是为了拦截机制，不是给它发许可证；四条主张没有一条写着「所以不用止损」。

**做完你会得到**：一张三笔决策的参照点清单（每笔一个参照点 + 是不是买入价）、一次反事实提问的记录、以及你自己的「交换比例」数字（为避免确认 X 元亏损，占用了多少资金、多久）。

**怎么算过关**：对最近三笔卖出，你能说出每笔的参照点是什么、今天空仓会不会改变决定；并且能报出其中一笔的个人交换比例（资金 × 天数）。参照点写「成本价」且反事实回答「不会变」的笔数，就是还欠的整改项。

## 说人话

是什么：人不是按「多少钱」判断得失的，是按「比参照点高还是低」判断的。而亏损那一端的分量，明显比收益那一端重——丢一百块的痛，大过捡一百块的乐。于是亏了想赌（万一回来呢），赚了想跑（落袋为安）。

为什么发生：因为心里有把会滑动的尺。买入价成了参照点，价格低于它，每一分都是「亏」；高于它，每一分都是「赚」。这把尺还会让风险偏好变形：收益区里人怕风险，宁愿早点落袋；亏损区里人追风险，宁愿赌一把回本——同一只股票，赚着的时候拿不住，亏着的时候撒不开手。

什么时候不成立：三种情形。一、有规则的人不成立在「执行层」——止损线事前写在纸上，亏损区「赌一把」的冲动被规则接住，理论描述的冲动仍在，但不支配动作；二、具体倍数别当参数用——那个「重多少倍」的系数，近年被证明换个问法就能测到消失甚至反转，所以只可信方向、不可信数值；三、对用基本面推出估值锚的人，参照点是「公司值多少」而不是「我亏了多少」，理论的描述对象就换了。

## 收益

无量级（方向性）：它拦掉的是「以参照点而非未来价值驱动」的卖出，金额取决于持仓与频率，无法预设。可自查的口径：最近三笔决策的参照点，是「公司值多少」还是「我亏了多少」——后者超过一笔，说明尺子还卡在成本价上。

1. **理论出处**：Kahneman, D. & Tversky, A.《Prospect Theory: An Analysis of Decision under Risk》，Econometrica，1979，DOI 10.2307/1914185。本机 curl：DOI 302 至 JSTOR 后返回「Client Challenge」机器人页（HTTP 200 但无论文正文，约 3 KB）——**按取不到一手处理**。四个核心主张经中文维基百科「展望理论」条目核对（curl 200，核对于 2026-10-12），等级 **B**（权威二手转述，原文付费墙未逐条核对）。
2. **四个核心主张（B，中文维基「展望理论」转述）**：①参照点/参照依赖——决策取决于结果与参照点的差距，而非结果本身；②S 形价值函数——获益区间凹（风险厌恶）、损失区间凸（风险寻求）；③损失厌恶——多数人对损失比对收益更敏感；④权重函数——对极低概率过度反应、对中高概率反应迟钝。维基另列「四个基本结论」：确定效应（收益状态风险厌恶）、反射效应（损失状态风险偏好）、损失规避、参照依赖——措辞与四主张略有不同，精确表述以论文原文为准。论文中的具体公式与逐字表述需人工核对（JSTOR 取不到）。
3. **λ 的量级（B）与具体值（需人工核对）**：中文维基「损失规避」条目转述「损失带来的负效用为利得正效用的 2 至 2.5 倍」（B，curl 200，核对于 2026-10-12）。Tversky & Kahneman 1991《Loss Aversion in Riskless and Risky Choice》（Econometrica）给出的 λ≈2.25 具体值，本机取不到一手（JSTOR 机器人挑战页）——**λ=2.25 需人工核对**，本条不引用。
4. **λ 测量争议（A，PMC 全文）**：Walasek, Mullett & Stewart (2021)《Acceptance of Mixed Gambles Is Sensitive to the Range of Gains and Losses Experienced, and Estimates of Lambda (λ) Are Not a Reliable Measure of Loss Aversion》，JEP: General，DOI 10.1037/xge0001054，PMCID PMC8756608。本机 curl PMC 全文 HTTP 200（约 12.5 万字节），核对于 2026-10-12，等级 **A**。逐字摘录："estimates of λ are extremely unreliable ... it is futile to estimate λ from risky choice data"；"the tendency to reject 50–50 mixed gambles can be made to disappear or reverse"；"λ does not generalize across even random splits of a choice set"；以及所引 Walasek & Stewart (2015) 的结论："λ could drop to 1 (meaning loss aversion had disappeared) or below 1 (a reversal of loss aversion)"。
5. **口径声明（务必按此理解）**：近年受质疑的是「λ 这个系数测不准、换问法就能让它消失甚至反转」，**不是「损失厌恶不存在」**。本站口径：亏损比等额收益更重——方向可信；重多少倍——系数不可靠，禁止拿具体倍数做精确计算。

## 备注

- **适用前提**：针对「以已亏/已赚金额驱动动作」的情形；用基本面推导出的估值锚是合法参照点，不在划掉之列。四主张是描述性框架，不构成「必须卖出亏损股」的操作指令——它解释冲动从哪来，不替你做买卖决定。
- **已知反例**：系数层面有真实反例——Walasek, Mullett & Stewart 2021（A，PMC 全文，curl 200，核对于 2026-10-12）证明仅改变输赢金额范围，就能让「拒绝五五对赌」的倾向消失甚至反转，λ 估计跨随机拆分都不稳定；同文所引 Walasek & Stewart (2015) 甚至估计 λ 可降到 1 或 1 以下（损失厌恶消失或反转）。口径：这是「λ 测量不可靠」，**不是**「损失厌恶不存在」。另：λ≈2.25 的具体值本机未取到一手（JSTOR 挑战页），需人工核对；K&T 1979 原文的公式与逐字表述同样需人工核对。方向上，经典结论（亏损比等额收益更重）未被推翻——Walasek 等的批评针对的是「λ 这个度量」，不是现象本身；本机未取到针对方向性结论的可核实反例。被推翻的是系数，不是方向。
