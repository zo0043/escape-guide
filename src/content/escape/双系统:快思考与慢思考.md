## 怎么做

**什么时候用**：三个具名场景。①盘中被数字触发的即兴决策：涨幅榜跳动、分时急拉急跌、群消息刷屏，念头到下单只隔几分钟；②复盘时才想出理由：买入当时说不出一条可观测依据，收盘后却补得出三条；③复杂产品说明读不完：条款超过一页的衍生品、多层结构产品，读两页就跳过去只看收益率。三个场景的共同点是——决定已经做了，思考还没发生。

**两套系统的对照（先对表，再贴标签）**

| 维度 | 系统一（快） | 系统二（慢） |
|---|---|---|
| 速度 | 立即，念头到动作几分钟内 | 慢，要算账、查证、写下来 |
| 费力程度 | 不费力，默认值班 | 费力，要集中注意力 |
| 自主控制 | 不受自主控制，出现了才觉察 | 可自主调用，也可主动拒绝调用 |
| 典型触发 | 价格跳动、涨幅榜、群消息、亏损的数字 | 读产品说明、算仓位、写下买入理由 |
| 投资里的样子 | 即兴决策、事后补理由 | 事前写下规则、按纸执行 |
| 出问题的样子 | 动作做了，思考没发生 | 慢，但同样会被偏误供电 |

**步骤**

1. **给最近三笔盘中决策贴标签**。每笔写四个字段：从想法到下单用了多久、触发源是什么（涨幅榜/分时/群消息/自己的念头）、依据是一条事前写下的规则还是一时念头、做的当时能不能说出一条可观测依据。四个字段缺一个，这笔就是「系统一当班」的候选。
2. **建一张慢决策清单**：哪几类决策只允许系统二当班——新产品新工具（可转债条款、场外期权、结构化产品）、任何加杠杆动作、单笔超过你事先定好的总资产比例的买入。清单之外不设卡，设卡太多等于没卡。
3. **复盘时才想出理由的，记坏决策**：不论那笔最后赚没赚。买入当时说不出可观测依据、收盘后才补理由的，按 [[结果偏误：按盈亏判决策是最常见的错]] 的口径记进「过程错但赚」那一格——赚了更危险，它会奖励这个习惯。
4. **读不完的产品说明等于不懂**：归入 [[看不懂的不碰]]，不用「别人都买了」代替读懂。
5. **把高频场景规则化**：盘中高频出现的诱惑各写一条固定动作，例如「涨幅榜前五名当天不买」「急拉不追，等收盘再判」。规则是把系统二的慢决策提前到系统一触发之前，完整做法见 [[事前检查清单:下单前强制回答五问]]。
6. **每周一次对照复盘**：用 [[投资日记:记决策不记盈亏]] 的模板统计本周「系统一当班」笔数，目标只降不升。

**慢决策清单模板（示例，具体参数自定）**

| 清单项 | 触发场景 | 固定动作 |
|---|---|---|
| 新产品新工具 | 第一次买可转债、场外期权、结构化产品 | 条款读不完就不买；先过 [[看不懂的不碰]] |
| 加杠杆 | 任何融资、配资念头出现 | 推迟到次日；先读 [[别借钱炒股]] |
| 大额单笔 | 单笔超过你定下的总资产比例 | 写下可观测依据 + 最大亏损金额，再下单 |
| 涨幅榜当天 | 盘中被数字触发的买入念头 | 只记录、不动作，收盘后再判 |

清单的写法只有一条纪律：每项都要有「固定动作」，写「要谨慎」不算固定动作。清单每周复盘时更新一次，平时不加项——加项太勤，等于没有清单。

**自查节奏（周/月两级，各十分钟）**

| 时间盒 | 动作 | 产出 |
|---|---|---|
| 每周一次 | 给本周每笔决策贴四字段标签 | 「系统一当班率」周值 |
| 每月一次 | 复盘当班率最高的两个触发源 | 各写一条固定动作，进慢决策清单 |
| 每月一次 | 检查慢决策清单有没有被执行 | 没执行的项，改写法不是改决心 |

节奏的意义：当班率是个比率，单周波动大，连续四周的趋势才说明问题；触发源按出现频率排序，排前二的才值得立规则——给罕见场景立规则，规则会被忘掉。

**当班率信号与整改对应表**

| 信号 | 最可能的触发源 | 对应整改 |
|---|---|---|
| 周当班率超过一半 | 涨幅榜、群消息 | 「涨幅榜当天不买」进清单 |
| 慢决策清单连续被跳过 | 清单项没有固定动作 | 重写清单，每项补一个动作 |
| 「事后补理由」笔数居高 | 没有记录模板 | 先上 [[投资日记:记决策不记盈亏]] |
| 当班率不降反升 | 整改只写在脑子里 | 把整改项写进下周复盘表 |

信号和整改一一对应，不许「信号归信号、整改归情绪」——那一对应不上，当班率就永远只是个数。

**算例**（假设案例，标的为占位代码 999999，不指向任何真实公司；价格、金额、比例均为假设参数）

初始条件：总资产 30 万元。某交易日 14:32，你在涨幅榜看到 999999 涨到 +7%，用 3 分钟决定买入 20,000 元（约占总资产 6.7%）；下单时说不出一条可观测依据；收盘后你补出三条理由。次日该股 −4%。

| 项目 | 数字 |
|---|---|
| 决策耗时（想法→下单） | 3 分钟 |
| 触发源 | 涨幅榜 +7%（盘中被数字触发） |
| 依据类型 | 一时念头（当场无可观测依据） |
| 事后补出的理由 | 3 条（均在收盘后产生） |
| 次日 −4% 的浮亏 | 20,000 × 4% = 800 元 |
| 若执行慢决策清单 | 推迟到收盘后；先写一条可观测指标；写不出 → 不买 |
| 可统计口径 | 「系统一当班」笔数 ÷ 本周总决策笔数 |

同一个月里另两笔的标签（同一张表的另外两行）：

| 笔数 | 耗时 | 触发源 | 依据类型 | 当场可观测依据 |
|---|---|---|---|---|
| 第一笔 | 3 分钟 | 涨幅榜 +7% | 一时念头 | 无 |
| 第二笔 | 隔夜（当晚写完次日下单） | 自选股预警 + 事前规则 | 事前写下的规则 | 有：事前写下的离场条件 |
| 第三笔 | 4 分钟 | 分时急拉 | 一时念头 | 无 |

算例说明：800 元不是重点——重点是把三笔的三个字段（耗时、触发源、依据类型）变成可统计的东西。三笔里两笔是「一时念头」，你的系统一当班率就是三分之二；这个数比任何性格测试都准，也直接指向整改对象：缩短决策耗时没有用，把慢决策清单立起来才有用。另注意第二笔：它慢，不是因为它想了三小时，而是因为它把思考提前到了昨晚——慢决策的本质是「提前」，不是「拖长」。

**常见错**

1. **把「慢」当「对」**：慢决策同样会错——系统二也会被 [[确认偏误：你的信息流只喂你想看的]] 和 [[过度自信：你大概率跑不赢市场]] 供电，慢只是必要条件，不是充分条件。
2. **把「快」当直觉天赋**：没经过训练的领域，快等于没检查。专家的快是长期复盘练出来的模式识别，你的快多半是荷尔蒙。
3. **读不完说明但照买**：把系统二的缺失包装成系统一的自信——「感觉靠谱」不是依据。
4. **用「当时太冲动」解释一切**：单一归因掩盖真问题——规则缺失、清单缺位、记录模板没有统计字段，三条都要各归各位。
5. **只统计亏掉的决策**：坏习惯恰恰是被盈利奖励出来的——「一时念头买的那笔赚了」会被记成功绩，而不是坏决策，于是当班率永远统计不出来。
6. **把慢决策清单当万能挡箭牌**：清单防的是即兴，不防判断错误；按清单慢慢做完、依然看错，是另一类问题，归 [[结果偏误：按盈亏判决策是最常见的错]] 管。
7. **拿「系统一/系统二」当性格标签用**：「我是系统一人」不是结论，是逃避——两个系统人人都有，差别只在当班时机；能改的是清单和规则，不是人格。
8. **复盘时只复盘亏的**：赚的决策更要贴标签——「过程错但赚」的那一笔，是坏习惯的奖金，不统计它，下一笔同样的冲动会带着更大的仓位回来。

**做完你会得到**：一张三笔决策的标签表（耗时/触发源/依据类型/当场理由数），一张慢决策清单（哪几类决策不许当场做），以及一个「系统一当班率」的周统计口径。

**怎么算过关**：随机抽三笔盘中决策，对每笔都能报出四个字段——多久、被什么触发、规则还是念头、当场能否说出一条可观测依据。三笔全部当场说得出一条可观测依据，或说不出的已写进下周整改项；只答得出「当时没多想」= 不过关。

## 说人话

是什么：你的脑子里有两套值班系统。一套快、自动、不费力——价格一跳、念头就来了，手比脑快；另一套慢、费力、要集中注意力——算账、查条款、写理由，都归它管。盘中做决定的大多时候，是快的那套在值班。

为什么发生：因为慢思考太贵。大脑的默认设置是省力，注意力更是稀缺资源——盯一整天盘的人，到下午连读完一段产品说明的注意力都凑不出来。于是越累、越急、越亏，人越依赖快的那套：昨天的动作今天照做，眼前的数字直接变成动作。压力越大，快的那个抢班越狠。

什么时候不成立：三种情形。一、如果你练过——专家的「快」是大量复盘练出的模式识别，不是没检查的冲动，别把自己的快也当成那种快；二、如果规则事先写好了，快系统触发的那一刻，执行的是纸面上的慢决策，快慢就不冲突；三、这条理论本身带着证据警告——原书引用的部分研究被指难以复现，作者本人也承认过于相信功效不足的研究，所以它是个贴标签、做统计的解释框架，不是能精确预测你行为的工具。

## 收益

无量级（方向性）：它拦掉的是「系统一当班时做的不可逆决定」——加杠杆、新产品、满仓单吊，这类决定的代价事后无法撤回，金额取决于你的持仓与频率，无法预设。可自查的口径：最近三笔盘中决策里，几笔在做的当时就能说出一条可观测依据——低于两笔，说明你的盘中没有系统二值班。

## 备注

- **适用前提**：针对「盘中即兴、事后补理由」型决策；对几年才做一两笔的长期持有者，本条优先级低于把持有逻辑写清楚。慢决策清单只卡「不可逆 + 高复杂度」的决策，卡得越多越形同虚设。另外，本条是自查工具，不是诊断书——它不判断你有没有病，只统计你的决策是在哪套系统当班时做出来的。
