## 怎么做

**什么时候用**：两种时刻。①同一条规则你已经破过两次以上（自律失效，需要外部约束）；②你要做一个不可逆或高杠杆的决定之前（借钱、融资、满仓单吊）——事前承诺比事后懊悔便宜得多。反过来，一条从来没破过的规则不需要承诺；把所有规则都公开，只会让承诺贬值。

**步骤**

1. **把承诺写成一句可观测的动作**，必须含三要素：时间窗（多长时间内）、禁止范围（不做什么，具体到动作）、核销方式（怎么证明做到了）。判定标准：这句话念给第三个人听，他能判断你某天有没有做到。示例：「未来 90 天内不新开融资合约、不新增任何借款；每日收盘后在日志里记一句『未新增杠杆：是 / 否』。」
2. **告知一个具体的人**：不是发在群里（那是表演，看的人不需要为你的承诺负责），是告诉一个你不想让他失望的人。只约定两件事：他负责在你可能违约时问一句，不负责评价对错。判定标准：你能说出他的名字，以及上次报告是哪一天。
3. **押一点真疼的钱（可选）**：金额 = 真的疼但不影响生活（月收入的一成上下，假设参数）；违约时把钱捐给指定机构，并把凭证发给告知对象。判定标准：违约那一刻，你会因为舍不得这笔钱而停一下——停一下，这一条就起作用了。
4. **写明核销周期**：每日一句、每周一张截图、每月一次对账，三选一或叠加。承诺里没有核销方式，就不可证伪；不可证伪的承诺等于没有。
5. **违约后重写，不作废**：破了一次，把破例的原因写进新承诺，并把核销频率提高一档（每月 → 每周，或每周 → 每日）。隐瞒一次，整个机制作废——从那天起要重写承诺，而不是假装旧的还有效。
6. **与既有规则对齐**：承诺不许和 [[别借钱炒股]]、[[先分清三种钱：保命钱、闲钱、搏钱]] 冲突；它是这两条的执行装置，不是替代品。冲突时以更严的那条为准。写承诺之前先把这两条读一遍——它们已经存在的规则不需要重新承诺，需要承诺的是你反复破的那一条。

**承诺模板（三种最常见的 A 股变体）**

| 想守住的规则 | 承诺原文（示例） | 核销方式 |
|---|---|---|
| 不借钱 / 不加杠杆 | 未来 90 天不新开融资合约、不新增任何借款（含场外配资、消费贷、信用卡分期转入） | 每月 1 日融资余额与征信简版截图发给告知对象 |
| 单票仓位不超两成 | 未来 60 天单一标的市值不超过总资产 20% | 每周五收盘后持仓截图一张 |
| 不用杠杆工具 | 未来 180 天不开通、不使用任何带强制平仓条款的工具 | 每季度一次账户品种清单截图 |

三个变体的共同点：禁止范围都落到**具体动作与具体品种**，核销方式都是**一张截图**。写不出截图的承诺，说明它的范围还不够具体——那是承诺本身的问题，不是核销方式的问题。

**有效与失效的边界**

| 边界 | 有效的形态 | 失效的形态 |
|---|---|---|
| 承诺对象 | 配偶 / 父母 / 不做交易的朋友（你不想让他失望，他不需要为你的盈亏负责） | 荐股群、交易圈朋友（利益同向，会鼓励） |
| 承诺内容 | 可观测动作（不新开融资、不借钱、单票仓位不超过两成） | 结果（赚钱、跑赢、回本） |
| 核销方式 | 一张截图、一句日志、一次对账 | 凭自觉、凭印象 |
| 押金 | 真疼但不影响生活 | 不疼（形同没有）或太重（诱使隐瞒） |
| 条数 | 一次一条 | 一次七八条（承诺通货膨胀，全都守不住） |

**告知对象怎么选（A 股语境）**：优先「不做交易但信得过的朋友」——他没有立场鼓励你，也不会被行情带着走；其次是配偶或父母，情绪成本最高，但只报动作与核销结果，不逐笔报金额，避免把家庭关系变成监控；最次是公开社群，只在能承受评价压力时用，且必须配一个可核销的硬指标（截图、余额），否则只是许愿。**不要选的人**：荐股群、交易圈朋友、券商客户经理——前两类利益与你同向，第三类的利益在你的交易量上。

**算例**（假设案例，不指向任何真实公司、真实券商与真实基金；金额、比例、日期全部为假设参数）

背景：2026-05-06，账户持仓 28 万元，已开通两融资格。当日看到「融资利率下调」的推送，想加 1:1 融资，把仓位推到 56 万元。此前同一条「不借钱炒股」的规则已经破过两次（一次是信用卡分期转入，一次是向亲戚借过五万元，均已还清但有过记录）。

**第一步（写出来）**：承诺原文一句——「未来 90 天内，不新开融资合约、不新增任何借款（含场外配资、消费贷、信用卡分期转入）；每日收盘后在交易日志里记一句『未新增杠杆：是 / 否』。」三要素齐：时间窗 90 天、禁止范围四个具体动作、核销方式每日一句。

**第二步（告知）**：告诉两个人。给不做交易的朋友老陈的版本加一条核销动作：「每月 1 日我把两融账户的融资余额截图发给你，余额必须是 0。」给妻子的版本就是同一句承诺，不加截图义务——家庭关系不该被变成监控。

**第三步（押金）**：与老陈约定，若 90 天内新增杠杆，把 2,000 元捐给一家指定机构并转发凭证。2,000 元约为月收入的 8%（假设参数）：疼，但不影响生活。

**为什么值得为它花这些成本（算术）**：

| 项 | 数字（假设参数） |
|---|---|
| 自有资金 | 280,000 元 |
| 拟融入资金（1:1） | 280,000 元 |
| 拟建总仓位 | 560,000 元 |
| 维持担保比例平仓线（假设） | 130% |
| 触发平仓所需跌幅 | (560,000 − 280,000 × 1.30) ÷ 560,000 = 35.0% |
| 若跌 35% 时自有权益 | 364,000 − 280,000 = 84,000 元 |
| 自有资金损失 | 280,000 − 84,000 = 196,000 元，亏 70% |
| 承诺的成本 | 一次告知 + 每月一张截图 + 2,000 元押金（未触发则零成本） |

**第四步（第 23 天，机制真正被用上）**：融资利率正式下调，自选股连涨三天，出现「只融一周、赚了就还」的念头。动作序列：①打开承诺原文，念一遍；②给老陈发消息：「我想融一周，承诺上写的是 90 天内融资余额为 0。」③老陈回：「截图发我。」④未执行，当日日志记「未新增杠杆：是」。

**第五步（第 90 天，核销）**：两融融资余额 0；日志里 90 句「是」；押金未触发，2,000 元未捐。承诺到期，选择续期或终止——续期就把「已守 90 天」写进新承诺，这一步是让机制积累信用，而不是每次都从零开始。

**核销记录的形态（到期时要能拿出来的东西）**

| 核销项 | 本例第 90 天的记录 | 用途 |
|---|---|---|
| 融资余额截图 | 0 元（每月 1 日一张，共 3 张） | 证明禁止范围未被触碰 |
| 日志中的每日一句 | 90 句「未新增杠杆：是」 | 证明核销是连续的，不是补的 |
| 押金凭证 | 无（未触发，故无捐赠凭证） | 违约时才有；无 = 未违约 |
| 告知对象的确认 | 老陈每月回复「收到」共 3 次 | 证明承诺有外部见证，不是自说自话 |

四样里最容易被跳过的是第四样——告知对象不回「收到」，核销就退回成自觉；这也是为什么第二步要约定「他负责问一句」：问句本身就是承诺的一半。

**告知时怎么说（一段可以直接照念的话）**：「我给自己定了一条规则：未来 90 天不新增任何杠杆和借款。我会在每个月的 1 号把融资余额截图发给你，麻烦你收到后回一个『收到』；如果哪个月我没发，你问我一句。你不用给我任何建议，也不用懂股票——我需要的就是有人知道这件事。」这段话的要点是：把对方的义务压到最低（回一个字、问一句话），把核销动作写死（每月 1 号、截图、余额为零）。

**常见错**

1. **承诺写成结果**——「我要在这个月赚 10%」不可观测，月底没赚也无法判断是市场问题还是你违约；承诺只能写动作。
2. **把承诺发在群里**——看的人不需要为你的承诺负责，点赞不是监督；告知对象必须具体到一个人，且他愿意被你在违约时打扰。
3. **押金不疼或太重**——两百元形同没有，五万元会诱使你隐瞒；真疼但不影响生活，是唯一能用的区间。
4. **一次承诺七八条**——条数越多，全守的概率越低，破一条就全线崩塌；一次只承诺一条最痛的。
5. **违约后假装承诺还有效**——隐瞒一次，机制的根基（可核销）就没了；正确动作是重写承诺并提高核销频率，旧的作废。
6. **把告知对象当军师**——你要的是他问那一句，不是他分析行情；提前说清「不给建议」，否则他会在你自己放水时替你找理由。
7. **承诺到期就悄悄结束**——到期不续期、不核销，机制留下的信用归零；到期那天要么续期（把「已守 N 天」写进去），要么明确终止并写一句「为什么不再需要它」。

**做完你会得到**：一句写下来的承诺（含时间窗、禁止范围、核销方式）、一个说得出名字的告知对象、一个押金安排、以及到期时的核销记录（本例：余额 0、日志 90 句、押金未触发）。三个可直接执行的产出：你最常破的那条规则是什么；它的违约成本算出来是多少（本例 196,000 元 / 70%）；核销频率要不要在续期时提高一档。

**怎么算过关**：你现在能说出三样——承诺原文、告知对象的名字、上次核销日期；一样说不出，说明承诺还在纸面上。再看记录：本周期内至少完成了一次核销（本例是月度截图）——核销是承诺唯一的存在证明，没有核销记录的承诺视为未承诺。

## 说人话

是什么：自己管不住自己的时候，把想守住的那条规则写成一句具体的话，然后告诉一个具体的人，让他盯着你。规则从此不再只属于你——它属于一个会问你「昨天做了没有」的人。

为什么发生：因为破规则的代价是延迟的、抽象的，而破规则的收益是立刻的、具体的：今晚加杠杆，今晚就可能多赚；不加的收益是「三个月后没有爆仓」，这件事根本没发生，你感觉不到它的存在。告诉一个人的作用，是把那个看不见的代价变成看得见的提问——你下次想破规则的时候，眼前会多一张脸和一个要回答的问题。这不是意志力变强了，是环境变了。

什么时候不成立：一、如果这条规则你本来就没破过，承诺是多余的仪式；二、如果承诺的内容是结果（「我要赚钱」「我要跑赢指数」），它不可观测，等于没承诺；三、如果告知对象和你的利益同向（荐股群、交易圈朋友），他会鼓励你而不是拦你——承诺机制在最需要它的时候恰好失效。

## 收益

量级（口径：亏损）：承诺本身不产生收益，它改变的是「可观测动作是否发生」。算例里被拦下的是一笔 28 万元、1:1 的融资：按假设的 130% 维持担保比例，标的跌 35.0% 即触发强平，自有权益从 280,000 元降到 84,000 元，亏 **70%**（196,000 元）；而为它付出的承诺成本是一次告知、每月一张截图与 2,000 元押金（未触发则为零）。这个数怎么用：先算出「如果不承诺，最坏会怎样」这个数，再决定押金与核销频率的成本——最坏数是自有资金七成时，2,000 元与一次月度截图是极便宜的保险；最坏数只有几千元时，这套机制是浪费，别用。

## 备注

- **适用前提**：只用于自律已反复失效的规则，或高杠杆 / 不可逆决定之前；对从未破过的规则是多余仪式，对不可观测的结果完全无效。承诺内容必须与 [[别借钱炒股]]、[[先分清三种钱：保命钱、闲钱、搏钱]] 一致，它是执行装置，不是替代品。
- **已知反例**：真实情形一，来源文献（Ashraf, Karlan & Yin 2006）的场景是储蓄产品，而公开承诺在减肥、戒烟等自控场景的实验结论混合，存在「公开后违约 → 羞耻感 → 彻底放弃」的失效路径——A 股语境里对应的形态是承诺被破一次之后连规则一起扔掉。真实情形二，A 股的特殊失效：告知对象是配偶时，极端行情下的追问可能变成家庭冲突，冲突会促使隐瞒，而隐瞒一次即令整个机制作废。真实情形三，押金可被合理化——「这次真的不一样」会让人宁愿捐款也要下单，赎罪券化的押金比没有押金更糟（它给违约标了价，且价格是固定的）。
- **关联条目**：[[别借钱炒股]]（承诺最常见的标的规则）、[[先分清三种钱：保命钱、闲钱、搏钱]]（保命钱不进任何融资安排）、[[别满仓，别单吊]]（融资与满仓叠加时的最坏形态）、[[过度自信：你大概率跑不赢市场]]（「只融一周」式念头的来源）、[[戒断机制:想买先写下来等一天]]（清单的告知对象即承诺对象的最小形态）、[[自动化纪律:把规则交给制度]]（承诺是制度的对外版本：一个有人核销的制度）、[[投资日记:记决策不记盈亏]]（核销记录写入日志）。
- **有效期**：三要素与选人标准为自设，可改；改承诺内容时必须同步改核销方式，否则承诺不可证伪。算例中的金额、比例、日期全部为假设参数。核对日期 2026-10-12。
