## 怎么做

**什么时候用**：看到任何「某大师年化 XX%」的说法（包括本章各条目收益节里的数字）时；想亲手核一遍本站某条大师业绩时；或者你要给自己的账户写业绩对比、希望它「无法被嘴硬反驳」时。

**四件套：为什么数字必须配齐四样**（方法一）
1. **数字**：单说「数字」不可证伪——「巴菲特赚得多」是口号不是事实；但单有数字没有下面三样，它随时可以被换区间、换口径重算出一个新版本。
2. **区间**：起止年份决定年化的值——1965–2024 与 1965–2013 是两笔不同的数（后者不含 2008 金融危机年）。不写区间的年化，等于没写。
3. **对比基准**：同期跑的是什么指数、含不含股息——同样年化百分之二十，同期基准是百分之十还是百分之三十，结论从「神」变「平庸」。
4. **来源**：谁说的——官方信/年报/监管报告（A 级）、大师本人著作（B 级）、媒体与维基转引（C 级），证据等级完全不同；来源打不开等于没有来源。
本站约定：四件套缺一，不写数字；拿不到可核业绩，写「无可核公开业绩」的诚实声明（见步骤 5），不留白、不用形容词充数。

**怎么读一张业绩对比表：复利曲线的四个口径陷阱**（方法二）
1. **起止年份**：同一笔 60 年的累计，按 60 年开方得 19.95%，按 61 年开方得 19.59%（差 0.36 个百分点，算例第 5 行可复算）——年数不是脚注细节，是变量。
2. **费前/费后**：同一只基金、同一段区间，费前 66% vs 费后 39%（Medallion 公开口径，C 级转引，仅用于演示）——一个「费」字差出近一倍。
3. **股价 vs owner earnings**：巴菲特股东信对比表是「每股市值」（股价）口径；「owner earnings 口径表」在 2004–2025 共 16 封信 + 2024/2025 年报全文中 grep 零命中（本站核对记录，需人工核对）——市面转述再流行，一手文件里没有的口径就不许引用。
4. **基准选择**：股东信用 S&P 500 **含股息**（1965–2024 年化 10.4%）；换成不含股息的价格指数，基准更低，「跑赢 X 个点」只在与原文相同的基准下成立。

**步骤**（核实任意一位大师的业绩，五步）
1. 找一手源：该机构的官方信/年报/监管报告优先（巴菲特 = berkshirehathaway.com/letters/；LTCM = 美联储年报）；书目、媒体、维基只当线索，不当数字来源。
2. 定位业绩表或业绩段，逐字摘录：表头（口径定义）、每行数字、脚注（财年/月份例外），一个不漏。
3. 取「累计收益」（Overall Gain）行做几何年化：CAGR = (1 + 累计%)^(1/n) − 1，n 写清楚（哪年到哪年、几年）。
4. 双口径交叉验证：① 累计收益直接开方；② 年度变动连乘。两者偏差 ≤ ±0.1pp → 通过；不一致 → 按四陷阱逐条找口径差。
5. 写成四件套：数字（标注值 + 复算值）+ 区间（起止年 + n）+ 对比基准（哪个指数、含不含股息）+ 来源（URL + curl 状态码 + 核对日期）；一手源拿不到的，该条收益节写「无可核公开业绩 + 试过什么 + 为什么拿不到 + 拿到后如何改」。

**算例**（可复算：用巴菲特 2024/2025 股东信官方对比表复算 CAGR；完整 60 行年度表见本站核对记录）：

信件原文（逐字，表尾两行）：2024 信 "Compounded Annual Gain – 1965-2024: 19.9% / 10.4%"、"Overall Gain – 1964-2024: 5,502,284% / 39,054%"；2025 信 "Compounded Annual Gain – 1965-2025: 19.7% / 10.5%"、"Overall Gain – 1964-2025: 6,099,294% / 46,061%"。脚注（逐字）："1965 and 1966, year ended 9/30; 1967, 15 months ended 12/31."

| 步骤 | 计算 | 结果 |
|---|---|---|
| ① 读累计（2024 信，伯克希尔） | $1 × (1 + 55,022.84) = $55,023.84，1964-12-31 → 2024-12-31 共 60 年 | 终值 55,023.84 |
| ② 几何年化，n=60 | 55,023.84^(1/60) − 1 | **19.95%** |
| ③ 对照信件标注 | 标注 19.9% | 偏差 0.05pp ✅ |
| ④ 基准同口径（S&P 500 含股息） | (1 + 390.54)^(1/60) − 1 = 391.54^(1/60) − 1 | **10.46%**（标注 10.4%，偏差 0.06pp ✅） |
| ⑤ 口径陷阱：同一笔数据改按 n=61 | 55,023.84^(1/61) − 1 | 19.59%（比第 ② 步低 0.36pp） |
| ⑥ 交叉验证（2025 信，n=61） | 60,993.94^(1/61) − 1；461.61^(1/61) − 1 | 19.80% / 10.58%（标注 19.7% / 10.5%，偏差 0.10 / 0.08pp ✅） |
| ⑦ 独立复算（61 个年度变动连乘） | 1965–2025 年率连乘（本站独立复算） | 19.71% / 10.51% ≈ 标注 19.7% / 10.5% ✅ |

算例说明：CAGR = (终值 ÷ 初值)^(1/n) − 1，n 为年数（本例 60 或 61）；开 n 次方 = ln(终值)÷n 再取 e 的该次方，计算器可复验。两条判读结论：其一，复算值与官方标注偏差在 ±0.1pp 以内 → 数字可引用；其二，偏差超 ±0.1pp → 先找口径差（起止年/费用口径/起算基准日），不直接宣布「数字造假」。第 ⑥ 步比第 ⑦ 步离标注略远的原因：脚注里 1965/1966 是 9/30 财年、1967 年是 15 个月，「60 年」实际跨度约 61.25 年，Overall Gain 的 $1 起算基准日（1964-12-31）与财年起算（1964-09-30）也差约三个月——这正是「口径」的实体。另（复算纪律示范，正好是口径陷阱的实体）：信里 "Overall Gain 39,054%" 是百分比增幅，$1 终值 = 1 + 390.54 = **$391.54**（46,061% 同理得 **$461.61**），此口径下 2024/2025 两信比值 = 140.5:1 / 132.1:1。本站核对记录 §1.2 的 S&P 终值 $390.54/$470.61 各有一处换算笔误（$390.54 漏加基数 1、$470.61 数字错位，正确应为 $391.54/$461.61；2026-10-11 队长第一轮复算 140.9:1 / 129.6:1 即以这两个笔误终值为分母，已被正确终值推翻）；决定性交叉验证：2025 信 S&P 终值 $461.61 ÷ 1.179（2025 年年率）= $391.53，与 2024 信终值吻合、与 $390.54 不符。本条算例一律按信件自身口径（1 + 累计%）引用。

**常见错**
1. 把基金网站/排行页的「年化」当事实，不查区间——同一只基金不同区间两个数，排行天然选最好看的那段。
2. 费前/费后混引——66% 与 39% 是同一基金同一段的两个口径，混引即失实。
3. 引用一手文件里不存在的口径（如「owner earnings 表」）——grep 零命中就是零命中，市面转述再整齐也不算来源。

**做完你会得到**：一套可复算的核实流程（一手源 → 逐字摘录 → 双口径复算 → 四件套）和一条判据（±0.1pp）。这条判据可用来核本站任何大师条目的收益节，也可用来核你自己的账户（把自己的「累计 + 起止年」代进公式）。

**怎么算过关**：给你任意「累计收益 + 起止年」，你能当场算出 CAGR 并说明 n 取几；给你任意一张业绩表，你能说出它可能踩四个口径陷阱中的哪一个；只能读出「年化 XX%」而说不出区间、基准与来源 = 不过关。

## 说人话

是什么：这是本章末尾的元条目——不写某位大师，写「大师的业绩该怎么写、该怎么读」。「他赚了多少」不是一个数，是四样东西：数字、多少年、跟什么比、谁说的。缺任何一样的业绩节是口号不是事实；查不到一手来源的数字，本站不写，写也要写「无可核公开业绩」。

为什么发生：复利曲线对口径极其敏感。起止差一年，年化差出零点几个百分点；费前费后之间差出将近一半；股价口径与收益口径是两条完全不同的曲线；基准选 S&P 含股息还是价格指数，「跑赢」和「跑输」可以互换。数字越权威越容易被原样转引，但原样转引意味着连它的口径一起继承——继承而不自知，就会被数字骗。

什么时候不成立：三条边界。其一，四件套针对「有公开可核业绩」的条目；真正拿不到一手的（或一手源不可达），正确写法是诚实声明，不是降低标准去收二手转引。其二，同一口径复算差在零点几个百分点以内才算过线；两个数若口径本来就不同（费前对费后），差得再多也不算复算失败，是口径差，正文不得混写。其三，本条算例用巴菲特股东信表（A 级一手源）做示范，方法与具体的人无关——但某个人的一手源若永远拿不到，第一步就失败，唯一正确输出是「无可核公开业绩」。

## 收益

量级（口径：收益）：本条是方法论，自身的「收益」= 复算判据的实测值。用 2024 股东信官方表（A 级）：55,023.84^(1/60)−1 = 19.95%（标注 19.9%，偏差 0.05pp）；391.54^(1/60)−1 = 10.46%（标注 10.4%，偏差 0.06pp）。用 2025 股东信（A 级）：60,993.94^(1/61)−1 = 19.80%（标注 19.7%，偏差 0.10pp）；461.61^(1/61)−1 = 10.58%（标注 10.5%，偏差 0.08pp）。年度变动连乘独立复算 19.71% / 10.51%（本站独立复算）。判据：同口径复算偏差 ≤ ±0.1pp → 数字可引用。这个数怎么用：读任何业绩表（含你自己的账户）先写下区间与 n，自己复算一遍年化；偏差超判据时先找口径，不先下结论。

## 备注

- **适用前提**：四件套适用于一切带「数字 + 区间」的条目；示范用巴菲特股东信（A 级），某大师的一手源不可达时，流程止于第 1 步并输出「无可核公开业绩」，不得用二手转引绕过。
- **已知反例**：真实情形一：「owner earnings 口径」在中文材料广泛流传，但 2004–2025 一手文件无此表（grep 零命中）——「看起来很权威」的数字也可能是转述的幻影，这是本条要防的真实案例；真实情形二：巴菲特股东信表自身带口径例外（1965/1966 财年止于 9/30、1967 年为 15 个月），连一手源都要读脚注才能复算对。
