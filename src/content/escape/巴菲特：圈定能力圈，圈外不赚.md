## 怎么做



**什么时候用**：有人推荐一只你听不懂的票，而它正在大涨的时候。

**步骤**
1. 写下「我能理解、能评价」的生意清单——判据是你能说清它怎么赚钱、竞争格局如何、大致值多少；
2. 清单之外的东西，无论多少人赚钱、消息多好，都不参与；
3. 每次被圈外标的吸引时，把它加进「待理解清单」，不加进「持仓」；
4. 只有当你能独立写出它的赚钱逻辑，才把它移进能力圈清单。

**算例**（假设案例，不指向任何真实公司）：最近一个月有人推荐了你 10 只票。逐只用「三问」判定：能说清它怎么赚钱吗？能说清竞争格局吗？能大致说清它值多少吗？

| 候选 | 三问结果 | 判定 |
|---|---|---|
| 票 A（自己行业里见过的生意模式） | 赚钱逻辑 ✓ / 竞争格局 ✓ / 大致估值 ✓ | 圈内：可进可买清单 |
| 票 B（新技术，只听说过名字，说不清怎么赚钱） | ✗ /  / ✗ | 圈外：待理解清单 |
| 票 C（朋友说「它很赚钱」，你只会复述朋友的话） | ✗ / ✗ / ✗ | 圈外：待理解清单 |
| 票 D（读过它的年报，但说不清值多少） | ✓ / ✓ / ✗ | 圈外：待理解清单（缺估值） |

10 只 → 过三问的 1 只 → 可买清单 1 只、待理解清单 9 只；对那 9 只，仓位 = 0。

算例说明：三问的答案必须是你自己能讲出来的，不是从研报或群消息里抄来的；「三问」是一道判定门槛，过了才有资格谈买，没过就只能进待理解清单。

**常见错**
1. 把「我懂一点」当「我能评价」——说得出来名字、板块、上过新闻，不等于能评价。
2. 事后把赚了钱的票移进圈里——圈要在买之前画，不是买之后。
3. 把「待理解清单」当「等一等就买」——加进清单不是通过判定，三问通过才是。

**做完你会得到**：一份写下来的能力圈清单（每家公司带三问答案）和一份待理解清单；你的持仓全部在前者上。

**怎么算过关**：你能不看研报，用三句话讲清清单里任一公司怎么赚钱；讲不清 = 不在圈里。

## 说人话

是什么：巴菲特在股东信里说，你不必是每家公司的专家，你只需要能评价能力圈内的公司；圈的大小不重要，知道边界在哪才是关键。圈外赚钱的机会是真的，但那是别人的圈。

为什么发生：做不会的生意，代价不只是「可能亏」，而是你**判断不了自己是不是在亏**。不懂一门生意，就分不清「暂时波动」和「生意真的坏了」，分不清「我判断错了」和「市场错了」，最后只能被价格牵着走：拿不住就在低点割，亢奋了就在高点加。划边界，本质是给自己留「判断权」——圈内的输赢你看得懂原因，圈外的你连输赢的账都算不明白。

什么时候不成立：两种情形。其一，边界是自己画的，而人会系统性高估自己的能力——觉得「我懂了」的那一刻，常常恰恰是最不懂的时候（见备注反例），所以圈要往小里画。其二，圈不是静态的——你懂的生意，行业结构一变逻辑就变，旧理解失效，圈其实已经缩了；以为圈还在原地，就是圈外了。

## 收益



无量级（方向性）：它消灭的是「做了不会的生意」这一整类亏损，属书目引用（巴菲特致股东信），本环境未逐封打开原文，按来源规则不引数字。可自查的口径：持仓里每一只是否都在能力圈清单上。
