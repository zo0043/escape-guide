## 怎么做

**什么时候用**：四个具名场景，出现任何一个就用——①你被拉进一个「先免费后收费」的荐股群，正在犹豫付不付第一笔会员费；②大 V 晒出收益截图或「实盘记录」，你想「跟着他做」；③直播间里「老师」在喊单，弹幕整齐一片「已跟上」；④你已经付过一次费、跟着操作过一把，正在考虑「升级更贵的服务」。也用于两个复盘场景：⑤上个月你顺从过的每一个「小请求」，后来把你引到了哪里；⑥你准备向别人推荐某个「老师」之前——先拆一遍他的结构，那通常是最快清醒的方式。

**步骤**
1. 拆话术：把对方最近十句话逐条标上用了六原则里的哪条（社会认同 / 权威 / 承诺一致最常见）；标不出来，先怀疑自己漏看了，别先相信；
2. 查权威的壳：这个「老师」的机构有没有牌照、牌照是否对应当前这项服务（见 [[查一家机构有没有牌照]]）？「老师」是自称还是持牌执业？晒的收益能不能对应到可查的账户？
3. 查社会认同的样品：群里的「已跟上」「昨晚八十人建仓」有多少是托儿？截图能不能伪造、名单可不可见（结构见 [[断言-重复-传染：叙事是如何被制造的]]）？
4. 画承诺升级链：列出你已经被引导做过的每一步（点赞 → 回复 → 进群 → 晒单 → 付费 → 加资金），再问一句：下一站要求我做什么、收多少钱；
5. 可证伪测试：把他的话换成「标的 + 价位 + 时点 + 说错了怎么算」；换不出来 = 话术不是信息（完整路径见 [[亏钱的理念:听消息]]）；
6. 已经付费的：保全证据（聊天记录、转账记录、群成员与群主账号），再按 [[别跟荐股群的「老师」]] 逐项核；遇到诱导转账到私人账户、承诺收益分成的话术，直接按 [[被「杀猪盘」盯上：先固证，再报警]] 固证报警。

六原则速查表（B 级：Cialdini 归纳，未逐条核对；加粗三条是本条重点）：

| 原则 | 一句话 | 投资场景里的常见形态 |
|---|---|---|
| 互惠 | 收了人情就想还 | 免费资料、免费诊股、试用名额 |
| **承诺/一致** | 迈过一小步，就会续上大步 | 点赞 → 回复 → 进群 → 付费 → 追加资金 |
| **社会认同** | 看别人怎么做，尤其在不确定时 | 「八十人已建仓」、弹幕「已跟上」、晒单截图 |
| **权威** | 对专家头衔自动降低核查 | 「老师」「首席」「十年操盘手」、白大褂式包装 |
| 喜好 | 对喜欢的人更容易顺从 | 同乡、同校、嘴甜的主播、姿态低的助理 |
| 稀缺 | 越难得越想要 | 「最后三个名额」「今晚十二点截止」 |

**算例**（假设案例，不指向任何真实公司，代码用 999999）：一个「先免费后收费」群的四周升级链，和一次晒单话术的逐项拆解。

算例一：承诺升级链（登门槛结构，B 级结构借用，无具体数字引用）。

| 周次 | 群方动作（话术） | 生效原则 | 你的状态（假设） |
|---|---|---|---|
| 第 1 周 | 免费送「明日金股」，只要点赞 + 回复「已领取」 | 互惠 + 承诺一致（第一步） | 领了，回复了 |
| 第 2 周 | 晒「学员」盈利截图，群内托儿跟进「老师真准」 | 社会认同 | 你开始每天看群 |
| 第 3 周 | 「为过滤白嫖党」，收费 999 元进核心群 | 承诺一致 + 权威 | 你付了 |
| 第 4 周 | 「老师带你布局翻倍票」，要求资金从 10,000 元加到 50,000 元 | 承诺升级 + 稀缺 | 你犹豫 |
| 第 5 周 | 「上次没跟的学员错过了 20%，这批再不带第二批」 | 承诺一致 + 社会认同（错失叙事） | 你跟了 |
| 第 6 周 | 「内部通道额度有限，直接打给助理私人账户」 | 稀缺 + 权威（绕过可核渠道） | 停下 = 分界线 |

算例二：晒单话术拆解（每一行都问一遍「可核吗」）。

| 话术元素 | 表面信息 | 可核性 |
|---|---|---|
| 「昨晚 80 人建仓」 | 很多人都在买 | 名单不可见 → 社会认同的展示，非证据 |
| 「收益 37% 实盘截图」 | 老师能赚 | 截图可伪造，无对应账户 → 不可核 |
| 「最后三个优惠名额」 | 稀缺 | 制造紧迫，与标的无关 |
| 「我从不喊亏钱的单」 | 老师准 | 只展示说对的部分 = 样本裁剪（见 [[确认偏误：你的信息流只喂你想看的]]） |
| 「跟着我的人都赚了」 | 成功案例多 | 退出者不在群里，你看到的是存活样本 |

算例三：钱上的账（可手算复核）。

| 项目 | 数字 |
|---|---|
| 确定支出：第一笔会员费 | 999 元（假设参数） |
| 若执行「资金加到 50,000 元」，追加投入 | 40,000 元 |
| 追加后一个月标的价格 −10% | 40,000 × 10% = 4,000 元浮亏 |
| 确定支出 + 一个月浮亏合计 | 999 + 4,000 = 4,999 元 |
| 若未入群、未追加 | 0 元；错过的「涨幅」事前不可知 |

算例说明：三个算例的数字（999 元、80 人、37%、4,000 元）均为假设演示参数，不指向任何真实群、真实大 V 与真实标的。承诺升级链借的是 Freedman & Fraser 1966 的结构（B 级，具体数字需人工核对）；「最后三个名额」「跟着我都赚了」这类话术与标的基本无关，是纯粹的说服装置——识别它们不需要任何金融知识，只需要停下来拆一遍。

**常见错**
1. 「我没花钱，只是看看」——免费正是第一步：点赞和回复就是你的第一个承诺，价格设计在后面；
2. 「老师有牌照」——查到的可能是别家机构的牌照、过期或已注销的；牌照必须和「这个具体的人、这项具体的服务」对得上（见 [[查一家机构有没有牌照]]）；
3. 「群里那么多人赚钱，总不会是假的」——群成员构成不可见，托儿与真实学员无法区分（见 [[先搞清楚：你的交易对手是谁]]）；
4. 「我就付一次，不升级」——升级链的设计就是让你在下一次觉得「都付了，不如跟到底」；
5. 把说服当说服力——话术结构和观点对错无关；结构识别出来了，观点仍然要单独核；
6. 只防「坏老师」，不防「好话」——家人与持牌机构的风险提醒同样含权威与承诺结构，判断依据始终是「可不可核」，不是「谁说的」；
7. 把「我懂了」当「我免疫了」——六原则的识别是每次现场重做的练习，不是一次学会的护身符；升级链会换话术，你的拆解表要跟着换行。

**做完你会得到**：一张「话术拆解表」——对方用了六原则里的哪几条、权威的壳是否可查、社会认同的样品是否可核、承诺升级链的下一站是什么；以及一句书面结论：这个「老师」的话里，哪些部分可以证伪。拆解表模板（遇到说服场景时填）：

| 字段 | 怎么填 | 假设案例的填法 |
|---|---|---|
| 对方身份 | 自称 / 持牌？机构名？ | 「老师」，无机构 |
| 牌照可查吗 | 官方页面能查到且对应当前服务？ | 查不到 |
| 晒的收益可核吗 | 有对应账户或可查记录？ | 只有截图 |
| 用了哪几条原则 | 从速查表里挑 | 社会认同 + 权威 + 承诺一致 |
| 承诺升级链下一站 | 要求我做什么、收多少 | 付 999 元，随后加资金 |
| 可证伪的部分 | 标的 + 价位 + 时点 | 都没有 |

**怎么算过关**：对最近一个你想跟的「老师」，你能答出三件事——他的机构牌照能不能在官方页面查到、他晒的收益能不能对应到可查账户、他给你的下一个请求是什么；三件事缺一件 = 不过关，动作是不付费、不跟单、先固证。

## 说人话

是什么：你不是被道理说服的，是被套路一步步带着走的。Cialdini 把套路归纳成六条，和投资关系最紧的三条是：社会认同——看别人怎么做，自己就怎么做；权威——被称作「老师」、顶着光环的人，说的话自动打折怀疑；承诺一致——一旦迈了一小步，就会为了「我说过的话」继续迈大步。

为什么发生：大脑爱省力——「别人都买」「老师说的」「我都进了群了」三个理由都不用动脑子。更关键的是升级结构：先让你点个赞、回复一句，再进群，再晒第一笔单，再付第一笔钱，最后追加资金。每一次小的顺从都在抬高下一次顺从的门槛，等你觉得「要不跟到底算了」，你已经走在设计的路上而不是自己的路上。

什么时候不成立：一、这六条是说服的武器库，不是骗局的专属——持牌机构的风险提示、家人的劝告同样在用权威与承诺结构；区别在信息可不可核，不在话术本身。二、Cialdini 的归纳是 B 级（书，原文未逐条核对），Milgram 服从比例等具体数字本站未核到一手，标需人工核对——本条只借结构，不引数字，更不把六原则当成「已被精确测量的效应」。

## 收益

量级（口径：亏损）：会员费与跟单浮亏两项相加——算例三中，确定支出是第一笔会员费 999 元（假设参数）；若再执行「资金从 10,000 元加到 50,000 元」而标的一个月下跌 10%，追加的 40,000 元一个月浮亏 4,000 元，合计 4,999 元——会员费是确定成本，浮亏看行情，两者相加就是这条链在第一个月的最小代价。这个数怎么用：下次被拉进免费群，先问自己「这个链的下一站收多少钱」，把 999 元换成对方的真实报价写下来；报价越具体，你越早看清那是生意，不是运气。若报价拿不到（「看情况」「看觉悟」），那本身也是答案——不可核的定价，对应的是不可核的服务。

## 来源

- Cialdini《影响力》（*Influence: The Psychology of Persuasion*）六原则——互惠、承诺/一致、社会认同、权威、喜好、稀缺：**B 级**（权威二手：书，本站未对原文逐条核对）。与投资场景最相关的是三条：**社会认同**（以他人的行为推断自己该怎么做，尤其在与自己相似的人不确定时）、**权威**（对被称为专家、穿着与头衔到位的人自动降低核查）、**承诺/一致**（一旦迈出一小步，会为「我说过的话」继续迈大步，逐级升级）。需人工核对：六原则的逐字表述、原书各章引用的实验细节与效应描述。
- Freedman & Fraser (1966)「登门槛」实验（foot-in-the-door，先请人挂小招牌、再请立大招牌，*Journal of Personality and Social Psychology*）：**B 级**——经典实验，本站未核到原文（付费墙）。本条只借「先小请求、后大请求」的**结构**，不引任何具体百分比；文中若出现该实验的数字，一律标需人工核对。该结构在投资场景的对应：免费 → 进群 → 付费 → 追加资金 → 代操，每一级只比上一级贵一点、大一点。
- Milgram (1963) 服从实验（*Behavioral Study of Obedience*）：**B 级**——经典研究，本站未核到原文。流传的「约 65% 服从到最大电击」等具体数字**需人工核对**，正文不引用。本站只借其定性结论：在权威在场且责任可转移的结构里，普通人会做出独自一人时不会做的行为——对应场景是直播间喊单与「老师」带盘时，散户执行自己原本不会下的单。
- **社会认同**：在情况不明、且看到与自己相似的人正在做某件事时，人会拿他人的行为当行动依据。投资场景的放大器是「相似性」——群里的「学员」、弹幕里的「散户家人」都被刻意做得与你相似；越像你，越像证据。
- **权威**：头衔、着装、头衔证书、历史战绩的展示会让人自动下调核查力度。本站的核验动作不是「否认权威」，而是把权威还原成可查项：牌照、执业范围、历史记录的完整口径（含说错的部分）。
- **承诺/一致**：人会为「我已经做了」寻找一致性理由——付过费的人更难承认自己错了，于是继续跟、继续加。这正是升级链的发动机：每一级都在增加你退出的心理成本。
- 本站口径：六原则到投资话术的映射（荐股群、大 V 晒单、直播喊单、先免费后收费）是本站分析，没有一手统计；「听老师话的散户整体亏多少」无公开统计（没有统一口径统计按荐股交易者的账户盈亏），本条只给结构拆解与自查。
- 站内复算：算例中的算术（会员费 999 元、追加 40,000 元、一个月浮亏 4,000 元）为推导型 A 级，可手算复核，核对于 2026-10-12；站内 A 级复算见 [[先搞清楚：你的交易对手是谁]]（「告诉你消息的人赚的是谁的钱」）；站内 B 级复算见 [[别跟荐股群的「老师」]]（荐股群专项查证）、[[确认偏误：你的信息流只喂你想看的]]（只记说对的）、[[断言-重复-传染：叙事是如何被制造的]]（一句话怎样被重复成共识）、[[查一家机构有没有牌照]]（牌照核验路径）、[[亏钱的理念:听消息]]（消息的可验证性）；站内 C 级复算见 [[被「杀猪盘」盯上：先固证，再报警]]（已入局后的固证与报警路径）。
- 同轮新条目：[[群体心理:人群里没有个人]]（社会认同背后的匿名 / 传染 / 暗示性）、[[心理学研究的证据强度:哪些结论能信]]（为什么六原则只能标 B、经典实验的数字要标需人工核对）。
- 本站核对范围（如实记录）：Cialdini 六原则的**清单本身**按研究笔记的通说转述（B），本站未打开原书；Freedman & Fraser 1966 与 Milgram 1963 本站均未核到原文（付费墙），只核到研究笔记记录的二手叙述。因此本条的引用边界是「结构」，不是「数字」——这一边界与 [[心理学研究的证据强度:哪些结论能信]] 的三步核验一致：先看有没有复现与原文，再看效应量，最后看样本。

## 备注

- **适用前提**：针对「有人在对你说服」的场景——荐股群、直播、大 V、课程、付费社群；说服工具本身中立，持牌机构的合规提示与家人的风险提醒同样含权威与承诺结构，区别在信息可不可核，不在话术。
- **不适用情形**：你自己写下的交易计划、事先定好的规则提醒（如止损位、再平衡日）不属本条范围——那些是「承诺一致」的建设性用法：用小的书面承诺锁定未来的自己，与被人设计的升级链方向相反。
- **已知反例**：真实情形：付费社群与「老师」里也有持续输出可核信息的人——把推荐记录留全、按规则下单、错了可查的付费者中，确实有人赚回了会员费（真实情形，本条不量化）。反例推翻的是「所有荐股群都是骗局」，推不翻「话术结构需要被识别」；结构识别与信息核验是两件事，都要做。
- **分界线动作**：算例一第 6 周的「直接打给助理私人账户」是全场最清晰的一条红线——可核渠道（对公账户、持牌机构托管）之外的一切收款理由，都按不可核处理；到这一步，动作不是「再想想」，是停止付款并固证。
- **与证据分级的关系**：六原则是 B 级，两个经典实验是 B 级，具体数字需人工核对——这不影响本条的使用：本条从头到尾没有依赖任何效应量数字，用的是「结构拆解 + 可核性测试」。结构识别是逻辑练习，不是统计推断。
- **给同伴用**：把速查表与拆解表模板转给家人时，附一句「先拆结构，再谈观点」——多数争执停在「他是不是好人」，而表格问的是「他的哪句话可以证伪」；后者可判定，前者不可判定。
