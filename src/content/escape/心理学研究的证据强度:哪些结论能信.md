## 怎么做

**什么时候用**：三个时刻——①你准备把一个心理学结论变成钱上的动作之前（别人的文章、畅销书、课程、短视频，或本站其他条目）；②你看到「研究证明」四个字的时候；③你自己引用某条结论去说服别人之前。本条的三步核验不需要统计学训练，需要的是停下来问三个问题。

**步骤**
1. **看复现**：这个结论有没有**预注册的独立复现**？原始研究与复现是不是同一批人？只找到 1 项未复现的小样本研究 = 先按「存疑」处理，不管它多有名；
2. **看效应量**：报的是不是效应量（d 或 r）与置信区间？区间含不含零？只报「显著 / 不显著」不报效应量的，按不完整处理——「显著」不等于「效应值得你为它花钱」；
3. **看样本**：样本多大？是否预注册？效应量与你要付的成本比是否划算？样本小于每组几十人的「惊人效应」，先怀疑再引用；
4. 查发表偏倚：这个结论如果是因为「显著」才登出来（阴性和复现没人登），你看到的整体样本就是被裁剪过的——此时「所有人都这么说」不增加证据；
5. 用下面的分级与判定表归类：稳固 / 有争议 / 存疑，再决定它能不能进你的决策；
6. 管钱的动作只从「稳固 + 有算例」的结论里出；「有争议」的只作方向提示，不作精算依据；「存疑」的一律不进决策——包括本站自己引用的结论。

分级与判定表（「这条结论能不能用来管钱」；右列是本站的使用规则）：

| 结论 | 分级 | 复现 / 证据状态（等级） | 能不能用来管钱 |
|---|---|---|---|
| 损失厌恶存在（方向） | 稳固 | 多来源定性一致；但 λ 系数测量被证极不可靠（A·PMC 全文） | 能：作方向性纪律（不摊平、不扛亏），见 [[损失厌恶：亏一笔比赚一笔难受得多]] |
| 锚定存在 | 稳固 | 定性稳健（站内 B 级） | 能：作自查机制（查成本价锚），见 [[锚定效应：成本价、高点都是锚]] |
| 损失厌恶 λ≈2.25 | 有争议 | λ 估计极不可靠（A）；2.25 具体值需人工核对；维基「2 至 2.5 倍」为 B | 不能：别拿系数做精算 |
| 自我损耗（意志力耗尽） | 存疑 | 预注册多实验室复现 d = 0.04、区间跨零（A·摘要）；原始中等效应的数值需人工核对 | 不能：别拿「今天意志力差」当破戒理由 |
| 权力姿势 | 存疑 | 2010 原始有效应（A·摘要）→ 2015 大样本复现无效应（B+·题名） | 不能：摆姿势不改变风险承受 |
| 启动效应 | 存疑 | 卡内曼自认「过于相信功效不足的研究」（B·维基转引，原始出处需人工核对） | 不能：不据此设计任何盘前仪式 |
| 「某技巧月增二成」 | 存疑（默认） | 单条未复现小样本 → 按算例三步核 | 不能，直到出现预注册复现 |

判定表的读法：左列是结论，不是人——分级跟着结论走，不跟着提出者走；「稳固」只保证方向，不保证系数；「存疑」不等于「假」，等于「不许拿它管钱」。

与本站 A/B/C 的关系（第 6 步的依据）：本站 A 级告诉你「这条来源本站取到一手、可复算」，B 级是「权威二手、原文未逐条核对」，C 级是「历史文本或取不到一手」；而本条的三步告诉你「这个结论本身站不站得住」。两套尺子量不同的东西：OSC 2015 的数字是 A 级来源，报告的是失败；勒庞《乌合之众》是文本 A，实证是 C（见 [[群体心理:人群里没有个人]]）；两条 A·摘要（Wood 2002、Neal 2011）只支撑到「习惯由情境线索触发」这一层（见 [[习惯回路:看盘是一种成瘾]]）。看到本站某条写着 A，先别急着信结论——先问它过没过这三步。

**算例**（假设案例，不指向任何真实研究）：现场核一条流行说法——「每天开盘前用五分钟写下今日交易计划的人，当月收益比不写的人高二成」。假设这条说法的全部依据是 1 项研究（假设参数：实验组 30 人、对照组 30 人，报 d = 0.6）。

| 步骤 | 现场核验 | 结果 |
|---|---|---|
| ① 看复现 | 只找到 1 项原始研究，0 项预注册独立复现 | 按 OSC 2015 口径（A·摘要：复现显著的比例只有三成六），先按存疑处理 |
| ② 看效应量 | 原文报 d = 0.6（假设），未报置信区间 | 缺区间 → 不完整；补算见下 |
| ③ 看样本 | 每组 30 人，共 60 人 | 检出限估算：√(15.7 ÷ 30) ≈ 0.72 → 该设计只有约八成把握检出 d ≥ 0.72 的效应，而它声称 0.6 |

补算（可手算复核）：双尾 α = 0.05、检验力八成时，两组等样本设计所需人数 n ≈ 15.7 ÷ d²；d = 0.6 → n ≈ 44 人/组，而原文只有 30 人/组——**对它的主宣称效应功效不足**。这次「检出了」，更可能是噪声把估计抬高了；效应量收缩的方向与 OSC 2015「复现效应量约为一半」（A·摘要）一致。再看估计精度：d = 0.6、n = 30/组时，标准误 SE ≈ √(60 ÷ 900 + 0.36 ÷ 116) ≈ 0.264，95% 区间 ≈ 0.6 ± 0.52 = [0.08, 1.12]——区间宽到「真实效应可能很小也可能很大」，没有决策价值。

钱上的翻译（假设案例）：

| 项目 | 数字 |
|---|---|
| 该说法承诺的月增厚收益 | 2%（假设参数） |
| 按 OSC 收缩口径（约为一半）折算后 | 1% |
| 10 万元账户一个月的差额 | 100,000 × 1% = 1,000 元 |
| 执行成本（确定的） | 每天 5 分钟 × 22 个交易日 = 110 分钟/月 |
| 判定 | 成本确定、收益方向不可判 → 不能用来管钱 |

算例说明：以上研究参数（30 人/组、d = 0.6、月增厚 2%）均为假设，不指向任何真实论文；三步核验的结论只对这个假设案例成立。真实世界遇到同样形状的说法（单条研究、惊人数字、没有复现），按同一张表走一遍即可——核验方法不依赖你懂不懂统计，只依赖你问不问那三个问题。

**常见错**
1. 把「登在权威期刊」当可信——期刊同行评议筛不掉假阳性；OSC 2015 复现的正是发表在一流心理学期刊上的 100 项研究（A·摘要）；
2. 把「我不懂统计」当免检理由——三步都不需要懂统计：看有没有复现、看效应量和区间、看样本多大；
3. 看到「复现失败」就全盘否定心理学——损失厌恶、锚定这类方向性结论是稳固的；要否定的是具体系数和单条惊人结论，不是整个学科；
4. 用「这是经典研究」跳过核验——经典不等于复现过：权力姿势与自我损耗都曾是经典，复现结果一个无效应、一个区间跨零；
5. 把本站的 A 级当「结论正确」——A 只说明来源可核，不说明结论可靠；可靠度要看复现、效应量、样本（这也是本条存在的原因）；
6. 核验完一次就存档——结论的分级随新证据变，本条表格要跟着更新；更新以新的复现为准，不以「我又看到一篇文章」为准。

**做完你会得到**：一张「结论核验卡」——任何一条心理学结论，你都能填出：有没有预注册复现、效应量与区间、样本多大、发表偏倚风险，以及它的分级（稳固 / 有争议 / 存疑）和「能不能用来管钱」的判定。核验卡模板（抄走即可用）：

| 字段 | 填法 | 假设案例的填法 |
|---|---|---|
| 结论原话 | 一字不改抄下来 | 「写下计划的人当月收益高二成」 |
| 出处 | 论文 / 书 / 文章，附链接 | 某畅销书章节（无 DOI） |
| ① 有没有预注册复现 | 有 / 无 / 查不到 | 无（只找到 1 项原始研究） |
| ② 效应量与区间 | d 或 r + 95% 区间 | d = 0.6，未报区间 |
| ③ 样本多大 | 总样本 / 分组 | 60 人（每组 30） |
| 发表偏倚风险 | 只发表显著结果的领域？ | 高 |
| 分级 | 稳固 / 有争议 / 存疑 | 存疑（默认） |
| 判定 | 能不能用来管钱 | 不能，直到出现预注册复现 |

**怎么算过关**：拿最近一次影响你下单的「心理学说法」，按三步当场核一遍，说出它的分级与判定；三步里任何一步答「不知道」，而你已经按它做了动作 = 不过关，动作是把这条结论从决策依据里降级为「科普阅读」。

## 说人话

是什么：心理学出过一大批反常识的漂亮结论，后来其中很大一批复现不出来。有个大项目把一百项已发表的研究用高检验力设计重做一遍：原文里绝大多数报告了统计显著，重做后只有三成六还显著，重做的效应量平均只有原来的一半。于是「这条结论能不能用来管钱」就不能只看它登在哪个期刊、是谁说的。

为什么发生：原因不止一个——原文可能本来就没效应、只是小样本加只发表显著结果凑出来的运气；也可能是被挑过的样本把效应放大了；还可能是复现时的执行细节不同。共同点是：单个小样本研究的「显著」本来就很脆，而发表系统偏爱显著，于是文献里堆着一批被放大的结论——连《思考，快与慢》的作者都承认，自己把太多信心放在了功效不足的研究上。

什么时候不成立：一、「三成六复现显著」不等于「六成四的结论是假的」——复现失败的原因有很多种，包括复现本身的问题；正确的用法是给结论分级，不是全盘否定心理学。二、分级是动态的：今天存疑的结论可能明天被更好的实验救回来；今天稳固的也可能被新证据改写——损失厌恶的方向性结论稳固，但它的那个系数 λ 的测量已被一手全文证明极不可靠，这就是「结论活着、系数死了」的样子。

## 收益

量级（口径：亏损）：本条量纲是复现率与效应量，不是金额——OSC 2015（A·摘要）复现的 100 项研究：原文 97% 报告统计显著，复现后 36% 仍显著，复现效应量约为原效应量一半，47% 的原效应量落入复现效应量的 95% 区间，39% 被主观判定复现；若不假设原结果有偏，合并后 68% 显著。Hagger 2016 预注册多实验室复现（23 个实验室、2,141 人）得到 d = 0.04，95% 区间跨零。这个数怎么用：下次看到「研究证明」，先要三个数——有没有复现、效应量和区间是多少、样本多大；三个数拿不出两个，这条结论就不进你的决策，只进你的科普阅读。

## 备注

- **适用前提**：针对「要把心理学结论变成钱上动作」的读者；纯科普阅读、纯兴趣了解不需要过这三步——门槛只设在「管钱」这道门上。
- **不适用情形**：有预注册、有独立复现、效应量与区间齐全、样本充足的结论，不需要从零核验，直接用分级表的判定即可；本条的核查对象是「形状像结论的东西」，不是全部文献。
