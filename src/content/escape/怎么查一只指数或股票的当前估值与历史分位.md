## 怎么做

**什么时候用**：你已经按 [[赚钱的理念:估值纪律]] 算出了一个「它值多少」、准备按折扣率决定出不出手，却卡在第一步——「现在的市盈率、市净率是多少，在历史上算贵还是便宜」没有答案；或者你在第三方页面看到「当前处于历史一成二的分位」这类结论，想自己复算一遍的时候。这条给你三件事：官方源给什么、分位数怎么算、第三方数字按什么等级处理。

**步骤**

1. 先分清两层：**绝对值**（当前市盈率、市净率）官方源直接给；**分位数**（当前值在历史序列里排第几）几乎没有官方源发布，要么自己从序列算，要么把第三方的结果当二手处理；
2. 取绝对值：指数走中证指数官网（估值字段随官方计算规则调整，跨年比较前先看口径，实测见 [[查历史数据:中证指数与FRED怎么用]]）；个股与基金走披露平台（见 [[查一家上市公司的基本盘]] 与 [[查基金与公司基本面]]）；
3. 建序列：把同一口径的历史市盈率、市净率取成一张表，同时写明窗口（几年）、频率（按日还是按月）、亏损期公司怎么处理——三项不定，序列就不成立；
4. 算分位：数出历史值中低于当前值的个数，除以序列长度，算式见算例；
5. 定门槛：把分位数翻译成动作的两条线（多少以下才出手、多少以上不碰）是**你自己的纪律参数**，本条不给这两个数字——本条只保证分位数算对；
6. 记录：序列来源、窗口、频率、口径说明、当前值、计数、分位、核对日期八样写进笔记，缺一样这个数不能进决策。

**算例**（假设案例，不指向任何真实指数；全部输入为 999999 式占位参数，仅演示算法与记录格式）

任务：把「现在贵不贵」变成一个可复算的分位数。

输入（占位）：某指数近十年共 2420 个交易日的市盈率序列，窗口 2016-01-04 至 2025-12-31，日频率，亏损期公司已按「剔除并单列」处理；当前市盈率 = 12.00。

| 步 | 动作 | 算式 / 结果 |
|---|---|---|
| 1 | 序列长度 | 历史 2420 个 + 当前 1 个 = 2421 |
| 2 | 计数 | 历史值中市盈率低于 12.00 的有 726 个 |
| 3 | 算分位 | 726 ÷ 2421 = 30.0% |
| 4 | 判定 | 门槛 25% / 75%（假设参数，非本站结论）→ 30.0% 落在中间带 → 不出手 |
| 5 | 记录 | 来源、窗口、频率、口径说明、当前值、计数、分位、核对日期 八样齐全 |

窗口敏感性（同一批占位数据只换窗口，说明为什么窗口必须写进笔记）：窗口从十年缩到五年，序列长度与计数同时变，分位从 30.0% 变成 42.0%（占位演示）。**分位数不是指数的属性，是「指数 + 窗口 + 频率」三者的属性**——报分位数不报窗口，等于报了一个没有单位的数字。

判定标准：本例的产出是一个带窗口的分位数，不是一个「贵」或「便宜」的形容词。若第 3 步的计数你自己复算不出来，问题在序列不在算术——回到第 3 步补口径说明。

**常见错**

1. 把第三方页面的分位数当一手引用——分位数是派生统计，官方源基本不发布；拿不到原始序列时按二手处理并标「需人工核对」，不要把页面上的数字挪进来源节；
2. 换窗口凑结论——五年窗口显得贵就换十年，这是先有结论再选参数；窗口要在取数之前定下并写进笔记；
3. 跨口径比较——市盈率有静态、滚动两种算法，市净率有最新报告期与最新股本两种口径，混用即错（同一天同一指数两种市盈率能差出两位数百分点）；
4. 把亏损期公司算进均值——亏损企业的市盈率为负或无定义，直接污染均值；处理方式（剔除、单列、还是只用正数子集）必须写明，不能默默算；
5. 用分位数替代折扣率——分位数回答「历史上算不算贵」，折扣率回答「相对你算出的价值便不便宜」；两个都便宜才出手，只有一个便宜不动（纪律判据见 [[赚钱的理念:估值纪律]]）。

**做完你会得到**：一条带八字段的分位笔记——序列来源、窗口、频率、口径说明、当前值、计数、分位、核对日期；以及两张你自己定下的门槛线。

**怎么算过关**：给你任意一只指数或股票，你能当场说出当前市盈率与市净率、它们取自哪个官方入口、分位数用的几年窗口与什么频率、以及计数过程。说不出窗口的分位数 = 你引用的是别人的结论，不是自己的复算。

## 说人话

是什么：贵不贵这个问题，官方只回答一半——它告诉你现在市盈率、市净率是多少，但不告诉你这个数在历史上算高还是低。后半句得自己算：把过去几年的同一个数收成一列，数一数有几个比现在低，除一下就是分位。

为什么发生：因为「历史上算高还是低」不是事实，是选择——选几年、按天算还是按月算、亏损的公司算不算，三个选择各偏一点，同一个今天能算出三成也能算出七成。所以报分位数不报窗口，等于报了一个没有单位的数字，别人既没法信也没法复核。

什么时候不成立：两种情形。其一，指数成立没几年，序列短到没有统计意义，这时该写「序列太短，无法给分位」，不是硬算一个；其二，公司正在换商业模式（重资产转轻、并表范围变化），历史序列前后不可比，该做的是分段而不是拉一条长序列。

## 收益

无量级（方向性）：本条不给你「省了多少钱」的数字——那需要一个真实的估值判断加一个未来的价格，两者都无法在本条内验证。方向是确定的：按 [[赚钱的理念:估值纪律]] 出手之前，先有一个自己复算过的分位数，替代第三方页面上的结论。它改变的是「买贵了」这个风险有没有被度量，不是产生一笔可计的收益。
