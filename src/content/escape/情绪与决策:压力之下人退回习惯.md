## 怎么做

**什么时候用**：三个具名场景。①暴跌日盯盘：分时每动一次手痒一次，收盘后想不起自己看过什么；②连续亏损后乱操作：想一把赢回来，换股、加仓、改规则一起发生；③借钱补仓：用新的压力对抗旧的压力，把决策质量再往下推一档。三个场景的共同点——动作密度远高于平常，而依据密度远低于平常。

**情绪标记词表（先命名，再动作）**

| 标记词 | 典型伴随念头 | 危险动作 | 拦截动作 |
|---|---|---|---|
| 慌 | 「再跌怎么办」 | 割在低点、不敢执行既定止损 | 只触发事前规则，不新决策 |
| 不甘 | 「就不信它不回来」 | 死拿、补仓摊平 | 推迟到次日；先写离场条件 |
| 赌 | 「一把赢回来」 | 换股、加大仓位 | 停手线；当天不开新仓 |
| 麻木 | 「跌麻了，随便吧」 | 停止记录、放任仓位 | 强制归档一笔到日记 |

**步骤**

1. **给情绪贴标记**：按修行篇「情绪标记法」，用一个词命名当下的状态——慌 / 不甘 / 赌 / 麻木。写不出词，就写「写不出」，那也是一种标记。
2. **命名与动作之间强制间隔**：标记写完，动作至少推迟到次日；想当天做的，把理由写满一张纸再决定。间隔时长按自己的情况定，写进规则之后不许临场改。
3. **设一条停手线**：连续亏损达到自己定下的笔数，当天不再开新仓、不再改规则——停手日的产出只能是记录，不能是动作。
4. **「借钱补仓」念头按高危处理**：出现一次，就回到 [[别借钱炒股]] 的口径重读一遍，再决定要不要继续看盘。
5. **暴跌日只执行、不决策**：当天只允许触发事前写下的规则（见 [[买入之前先写下「错了怎么办」]]），新决策一律推迟到收盘后、最好是次日。
6. **事后归档到日记**：把标记词、间隔、动作数写进 [[投资日记:记决策不记盈亏]] 的模板——没有记录，下次同样的场面在你眼里依然是第一次。
7. **平时就练「退回路」**：情绪标记和间隔要在不亏钱的日子也练，练到成为习惯——压力日退回的才是标记法，而不是刷新行情。

**停手线与间隔（自设参数表）**

| 参数 | 示例值 | 说明 |
|---|---|---|
| 连亏停手脚 | 连亏三笔 | 笔数按自己的连亏承受力定，写下来才算数 |
| 标记与动作间隔 | 至少隔夜 | 写进规则之后不许临场改 |
| 单日浮亏警戒 | 总资产百分之三 | 达到即进入「只执行、不决策」模式 |
| 借钱念头处置 | 出现即停手，重读规则 | 不设「就一次」的例外 |
| 停手日产出 | 只许记录，不许动作 | 记录也按 [[投资日记:记决策不记盈亏]] 的模板写 |

**高压决策记录表（空白模板，当晚填）**

| 字段 | 内容 |
|---|---|
| 日期与当日浮亏 | |
| 看盘次数 | |
| 标记词（一个或多个） | |
| 念头清单 | |
| 每个念头与动作的间隔 | |

填表纪律只有一条：当晚填，不隔夜补——隔了一天，「标记词」会被结果改写（这正是 [[后见之明：「我早看出来了」是错觉]] 在个人记录里的样子），表格就废了。连续记满一个月，你会拿到自己的高压日画像：哪个标记词出现频率最高、哪类念头最常跳过间隔——那就是你个人版本的「退回习惯」。

**高压日分级与对应模式**

| 等级 | 判定 | 当日模式 |
|---|---|---|
| 轻度 | 浮亏未达警戒线 | 正常交易 + 每笔贴标记 |
| 中度 | 达到单日浮亏警戒线 | 只执行、不决策；新决策推迟到次日 |
| 重度 | 触发停手脚 | 停手日；产出只能是记录 |

分级的用处是把「今天状态不好」这种模糊判断变成可判定的开关：到哪条线，进哪个模式，不需要当天重新评估自己——评估自己这件事，在高压日正是最不准的。

**算例**（假设案例，标的为占位代码 999999，不指向任何真实公司；价格、天数、利率均为假设参数）

初始条件：总资产 20 万元。999999 于 8.00 元买入 5,000 股（40,000 元）。此后三日连跌至 6.80 元，浮亏 6,000 元。第四日盘中你出现三个念头：想盯盘到收盘、想借 20,000 元补仓、想换入一只「跌得少」的股票。

| 项目 | 数字 |
|---|---|
| 浮亏 | (8.00 − 6.80) × 5,000 = 6,000 元（−15%） |
| 当日看盘次数（行情软件刷新计数） | 47 次 |
| 情绪标记 | 「不甘」+「想赌回来」 |
| 动作 A：借 20,000 元补仓（年息 6%，假设参数） | 6.80 元可买约 2,941 股；补仓后成本 ≈ (40,000 + 20,000) ÷ (5,000 + 2,941) ≈ 8.10 元 |
| 动作 A 的后续：补仓后再跌 10% 至 6.12 元 | 浮亏 ≈ (8.10 − 6.12) × 7,941 ≈ 15,700 元，另计一年利息约 1,200 元 |
| 动作 B：换入「跌得少的」 | 无证据支持的新决策，且产生于压力日 |
| 动作 C（对照）：标记 + 隔夜 + 只执行事前规则 | 写下「不甘」；当晚不动作；次日只看是否触发事前写下的离场条件 |
| 停手线（自设） | 连亏三笔停手一天——本例连亏一笔未触发，但浮亏已达总资产 3%，接近警戒线 |

三个念头当天的处置记录（同一张表的另一面）：

| 念头 | 出现时间 | 标记词 | 与动作的间隔 | 实际动作 |
|---|---|---|---|---|
| 盯盘到收盘 | 13:05 | 慌 | 无间隔，当天执行 | 看到 14:40 一笔急拉，差点追进 |
| 借 20,000 元补仓 | 14:10 | 赌 | 隔夜 | 当晚写下三条理由，次日放弃 |
| 换入「跌得少的」 | 14:55 | 不甘 | 无间隔 | 未执行（收盘），但写进了自选股 |

算例说明：三个念头都发生在同一天、同一情绪状态下。动作 C 不保证结果更好（次日可能继续跌），它保证的是决策不在注意力被情绪占满的时刻做出——这一条无法用收益数字量化，能记录的只有「标记词、间隔、动作数」三样。再看处置记录那一栏：「盯盘到收盘」和「换股」两个念头没有间隔、当天执行，「借钱补仓」因为隔了夜才被自己的三条理由劝退——间隔本身不产生判断力，但间隔给判断力留了出场时间。

**常见错**

1. **「我再盯一会儿就卖」**：盯盘时长本身不产生信息，只产生动作冲动；行情软件的刷新次数是可核实的自变量。
2. **连亏后加大仓位「赢回来」**：把波动当对手、把加仓当解药——压力日做的加仓，是质量最低的加仓。
3. **用借钱消除压力**：压力从市场转移到催款方，决策质量更低；借钱补仓同时撞上 [[别借钱炒股]] 与本条两条红线。
4. **冷静时写规则、情绪上来时改规则**：规则的效力全在「临场不改」；要改，把「为什么改」写进新记录（口径见 [[投资日记:记决策不记盈亏]]）。
5. **只在暴跌日才想起标记法**：标记和间隔是技能，不是急救包——平时不练，压力日退回的只能是刷新行情。
6. **把「没动作」当成没风险**：盯盘四十七次本身也是动作，它消耗注意力、抬高后续所有决策的出错率，要一并记进动作数。
7. **用「状态不好」概括一切**：「状态不好」不可执行，「不甘 + 隔夜 + 只执行规则」才可执行；标记词的用途就是让模糊的状态变成能打勾的条目。
8. **停手日里偷偷看盘**：停手日的产出只能是记录——看盘不记录，等于把停手日过成了半个交易日，规则从内部被拆掉。

**做完你会得到**：一份高压决策记录（标记词/间隔时长/动作数）、一条写进规则的停手线、一次「借钱补仓」念头的归档（出现过几次、每次怎么处理的）。

**怎么算过关**：最近三笔高压决策，你能说出当时的标记词、标记与动作之间隔了多久、当天的动作数；「借钱补仓」念头出现次数为零，或每次都按 [[别借钱炒股]] 处理过。

## 说人话

是什么：压力大的时候，人不做复杂判断，只做熟悉动作。暴跌日盯盘盯到脑子发麻，你做的不是「决定」，是昨天动作的重复——大脑把省电模式开到了最大。

为什么发生：急、亏、被催，注意力全被情绪占满，留给算账的部分所剩无几。大脑于是挑最省力的路径：昨天怎么做的今天照做，手里有什么习惯就退到什么习惯。你平时练的是止损，退回的就是止损；平时练的是盯盘，退回的就是乱按。

什么时候不成立：两种情形。一、压力源与市场无关（家事、疾病、长期失眠）时，先处理人，不处理仓——这时候的任何决策都该推迟；二、如果你说的「情绪」其实是兴奋（暴涨日的亢奋），方向相反、机制同类：都是快思考夺权，见 [[双系统:快思考与慢思考]]。另外，本条机制本身没有本机核过的一手数字，「有压力就一定亏」是方向性说法，不是可量化的定律。

## 收益

无量级（方向性）：它拦掉的是压力日的不可逆动作（借钱补仓、满仓换股、临场改规则），金额无法预设——本条的记录口径是「标记词、间隔、动作数」，不是收益。可自查的口径：最近一次暴跌日，你的动作数是几个、其中几个是事前规则里写过的。

## 备注

- **适用前提**：针对「压力/情绪状态下产生的交易动作」；压力源与市场无关时，先处理人、推迟一切决策。停手线、间隔时长均为自设参数，按自己的连亏承受力定——参数没有标准答案，有答案的是「提前写下来」这个动作本身。另：本条只拦「压力日的不可逆动作」，不拦所有交易；震荡市里的正常调仓不在拦截范围。
- **已知反例**：本机未取到任何一手研究，本条不提效应量；同时须注意反向说法——「适度压力提升表现」在文献中亦有讨论（方向性，阈值需人工核对），所以本条的结论不是「有压力就一定亏」，而是「高压 + 不可逆动作」这个组合最贵。另一个真实边界：有外部约束的人（参加实盘比赛、替人管钱、有风控线）被迫停手，效果反而好于自设规则——说明这条的难点从不是「知道」，而是「执行时没有旁观者」。另：专业交易者有交易日志与风控替他们执行「停手」，散户版全靠自设规则，没有外部机制保证。
