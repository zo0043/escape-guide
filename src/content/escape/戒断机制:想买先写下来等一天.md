## 怎么做

**什么时候用**：任何「突然想买」的时刻——收盘后、周末、暴涨或暴跌当天的晚上，尤其管用。共同特征是理由只有一句话、劲很大。反之，研究了三个月、理由写满三页的买入，不需要这一层，直接走 [[事前检查清单:下单前强制回答五问]]。

**步骤**

1. **写什么（五个字段，缺一不可）**：标的与代码 / 想买的金额 / 理由一句话 / 情绪一个词 / 愿意等的时长。写进一个固定文件，文件名固定为「想买清单」——不是微信收藏、不是脑子里、不是自选股备注。判定标准：换一台设备也能打开。
2. **等多久（默认一个交易日）**：清单上必须有两个时间字段——写入时间与复审时间。周一晚上写的，复审时间是周二收盘后；周五晚上写的，顺延到下周一收盘后（跨周末不顺延成两天手动盯盘）；假期前最后一个交易日写的，顺延到节后第一个交易日收盘后。复审时间没到，不许打开这条目。
3. **复审三问**：①理由变了吗——价格变了不算理由变，财报、公告、行业数据变了才算；②符合 [[买入之前先写下「错了怎么办」]] 的三句话吗——缺止损位、缺证伪条件的，不通过；③如果现在空仓，还会买吗。三问全过，才允许进入 [[事前检查清单:下单前强制回答五问]]；任何一问不过，条目状态改为「继续等」，并标注缺什么。
4. **谁监督**：把清单发给一个具体的人（选人标准见下），只约定两件事：对方不评价对错，只在你提前下单时问一句「清单上是怎么写的」；每周把清单的归档数量报给对方一次。判定标准：你能说出这个人的名字，以及上次报告的日期。
5. **一天都忍不住怎么办**：说明不是冲动是执念。处理是把金额砍到原来的三分之一，再复审一次；仍然想买，走五问。执念的特征是「等了一天还想买」，但它同样必须过五问——本条与五问是串联的两关，不是二选一。
6. **每周归档一次**（建议周五收盘后）：把到期条目标成三种状态之一——「意愿消失」「仍想买并已走五问」「已买入」。归档条目不许删：**意愿消失率**是这套机制唯一的效果指标。

**「想买清单」模板（一行一条，七个格子）**

| 字段 | 本例 | 填写要求 |
|---|---|---|
| 写入时间 | 周一 20:30 | 精确到分钟，用来算半衰期 |
| 标的与代码 | 999999 | 不用昵称 |
| 想买金额 | 36,000 元（占 9%） | 必须是能算出仓位的数 |
| 理由一句话 | 三季度订单同比增四成（财报原文第三节） | 注明出处位置，不许只写结论 |
| 情绪一个词 | 兴奋 | 从 [[情绪标记法:先命名再操作]] 的词表里选 |
| 复审时间 | 周二收盘后 | 写死，不许随时改 |
| 状态 | 继续等 / 意愿消失 / 已走五问 / 已买入 | 每周五归档时统一改 |

七个格子里最常空的是「情绪」和「复审时间」——空一个，这条目就失去了作为时间盒的效力。

**清单的三种坏形态（写坏了就等于没写）**：①只写标的不写金额——无法判断规模，也无法计算仓位；②不写复审时间——随时可以看，时间盒消失；③情绪栏空着——缺了它，你分不清「想买」和「想马上买」，而这两者的处理方式完全不同。

**删 App 与限频的操作边界**：删 App 删的是「打开入口」，不是账户权限。三条红线：①不能影响止损与风控——如果删了 App 会让你没法及时止损，就别删；②必须保留一个能在一小时内完成止损的备用通道（网页版或另一台设备），并实际演练过一次；③删除动作本身要写进日志，否则一周后你会以为自己「早就戒了」。限频限的是「打开与下单次数」：可执行形态是每周下单次数上限、每日打开行情软件次数上限、关掉弹窗与秒级提醒（减少触发器）。边界有两条：上限只约束你手动下的单，不约束条件单与定投的自动扣款（那是制度，不是操作）；上限值自设，但写下来才算数。

| 动作 | 允许 | 不允许 |
|---|---|---|
| 删 App | 删主屏入口、移进二级文件夹 | 删到没有备用通道、删掉风控能力 |
| 限频 | 每周手动下单 ≤ N 次、每日打开 ≤ M 次 | 把条件单与定投也算进 N |
| 关提醒 | 关弹窗、关秒级刷新、关自选股异响 | 关掉到价提醒（那是风控） |

**复审三问的展开（每问的合格线与常见误答）**

| 问 | 合格 | 常见误答 | 为什么不合格 |
|---|---|---|---|
| ① 理由变了吗 | 财报、公告、行业数据变了 | 「价格跌了 / 涨了」 | 价格是结果不是理由；价格变了一切都没变 |
| ② 三句话写了吗 | 买入理由 + 止损位 + 证伪条件都在 | 「理由很硬，不用止损」 | 没有止损位就没有最大亏损金额，等于没写 |
| ③ 空仓还会买吗 | 「会，而且金额不变」 | 「会，但只想买三分之一」 | 金额缩小说明是劲衰减不是理由变化，应重新等一天 |

三问里最常被糊弄的是第三问：人会把「劲小了」误判成「想清楚了」。判定方法很简单——把金额写下来，金额缩了就是劲缩了。

**监督人怎么选（三种可执行形态）**

| 人选 | 为什么有效 | 注意 |
|---|---|---|
| 配偶 / 父母 | 情绪成本最高，「报告」本身有约束力 | 只报条目数量与状态，不逐条报金额，避免把家庭关系变成监控 |
| 不做交易的朋友 | 无利益冲突，不会替你分析行情 | 提前约定他只负责问那一句，不给建议 |
| 同事 / 公开社群 | 社会评价成本 | 只在你承受得住评价压力时用；亏损密集期不要用 |

三种人可以叠加（一个近身 + 一个远端），但至少要有一个人是「不做交易」的——交易圈内的人会在你自己放水的时候替你找理由，这是监督人机制最典型的失效方式。监督人的人数上限是三人：超过三个，报告本身会变成负担，而你会在某个周五选择不报——不报的那天，机制就开始失效。

**半衰期：这套机制唯一的过程指标**。从「写入时间」到「劲消失」的时长，就是你个人买入念头的半衰期（本例约一天半）。它比收益更能说明问题：半衰期以小时计的人，时间盒要按小时设（先冷静一晚再复审）；半衰期以周计的人，一天的默认时长对你无效，要改成一周。测法很简单：清单里每条「意愿消失」的条目，记下从写入到复审时劲消失的时长，取三个月的中位数。

**算例**（假设案例，标的为占位代码 999999，不指向任何真实公司；时间、价格、股数全部为假设参数）

初始条件：总资产 40 万元。周一 20:30，999999 收 12.00 元，当日 +6.1%。想买 3,000 股（36,000 元，占 9%），「想马上买」。

| 时间 | 动作 | 记录内容 | 判定 |
|---|---|---|---|
| 周一 20:30 | 写入清单 | 999999 / 36,000 元 / 「三季度订单同比增四成（财报原文第三节）」 / 「兴奋」 / 等一个交易日；复审时间 = 周二收盘后 | 五字段齐全，合格 |
| 周一 20:35 | 告知 | 把清单截图发给老陈，约定「我提前下单时你问一句清单上是怎么写的」 | 监督人在位 |
| 周二 09:30 | 只观察 | 开盘 12.30 元（+2.5%）。触发规则：写入后涨超 2% 的条目，复审时先问「我买的是理由还是涨势」 | 想买的劲少了一半 |
| 周二 14:50 | 只观察 | 999999 收 11.60 元（−3.3%），成交量为前五日均量 1.8 倍。新念头出现：「跌下来了，更想买」 | 这是 [[锚定效应：成本价、高点都是锚]]（以 12.30 为新锚）叠加 [[赌徒谬误：「跌多了该反弹了」]]，不是新理由 |
| 周二收盘后 | 复审三问 | ①理由变了吗：财报数据没变，但「订单增四成」三天前就公布、价格三天已涨 9%，该买的理由早被买过；②三句话写了吗：只有理由，没有止损位与证伪条件 → **不通过**；③空仓还会买吗：会，但只想买 1,000 股 | 状态改为「继续等」，标注缺项：止损位、证伪条件 |
| 周三 09:35 | 复审 | 逐条核对：财报数据仍成立；「想马上买」的劲已消失（记录原文：「现在看它和看别的票没区别」） | 状态改为「意愿消失」 |
| 周五收盘后 | 归档 | 本月清单共 7 条：意愿消失 5 条、仍想买并走完五问 1 条、已买入 1 条；意愿消失率 = 5 ÷ 7 ≈ 71% | 归档条目保留，不删除 |

对照：若周一晚直接买入 3,000 股 @12.00，到周三 11.40 元的账面 = (12.00 − 11.40) × 3,000 = **−1,800 元**（占总资产 0.45%）；实际执行是 0 股，36,000 元未投入。必须说清的一点：这 1,800 元**不能记成「戒断帮我赚到的」**——没写清单的世界线不存在，无法验证；记录里只写一句「按规则未买入，理由：缺止损位与证伪条件」。同理，若 999999 次日直接涨停，延迟者付出的是真实的机会成本，而且事后无法证明那是机会——延迟机制的成本和收益都不可验证，这是它必须和五问串联使用的原因。

**常见错**

1. **把清单写成许愿池**——写了一年从不复审，或复审时把「理由没变」当成买入许可；理由没变只说明它没被证伪，不说明它值得买。
2. **价格变了就当成理由变了**——跌了 3% 赶紧「复审」，涨了 2% 就忘掉复审；复审时间是写死的，价格不在触发条件里。
3. **监督人选了交易圈里的人**——他会鼓励你买，因为他自己也在场内；选人的标准是「他不需要为你的盈亏负责，但你需要为向他报告负责」。
4. **删了 App 就以为戒断了**——删的是入口，不是冲动；冲动会绕到网页版，而网页版没有时间盒。删 App 只在配合「备用通道仍能止损」的前提下有效。
5. **意愿消失率接近零还不调整**——说明你要么本来不冲动（那这套机制对你无用，承认它），要么在复审时放水（把「继续等」都改成了「已买入」）。
6. **跨周末手动盯盘**——周五晚写的条目，周六周日反复打开看，等于把「一个交易日」改成「两天实时行情」；规则是到下周一收盘后，中间不许看。
7. **只对买入用清单，对卖出不用**——「想割」的冲动同样是冲动，而且方向相反；卖出清单的复审三问照用，问二换成「符合事前写下的离场条件吗」。

**做完你会得到**：一个固定文件「想买清单」（每条含五字段、两个时间、三种状态之一），一张月度归档统计（意愿消失率），以及一个说得出名字的监督人。三个可直接执行的产出：你的意愿消失率是多少；你的念头平均半衰期是多长（从写入到「劲消失」的时长，本例约一天半）；哪类理由最容易被写进清单（本例是「财报数据 + 涨势」，前者是理由，后者是劲）。

**怎么算过关**：本月清单里至少有三条到期条目，且每条都有明确状态；你能报出本月意愿消失率和一个具体数字（本例 5 ÷ 7 ≈ 71%）；你能说出监督人的名字和上周报告的日期。三条缺一条，说明这套机制还在纸面上。

## 说人话

是什么：想买一只票的时候，不许下单，只许写字——把想买的标的、金额、理由、情绪写进一个固定文件，然后等一个交易日，到点了再决定买不买。多数时候你等到那个点，发现自己不想买了。

为什么发生：想买的劲有半衰期，而且短得惊人。刚看到一条消息、刚拉了一根阳线的时候，那股劲处在峰值，这时候做的决定全是它做的；过一天，同样的消息还在，劲少了一半，你才有机会看见自己当初想买的真正原因——是标的，还是那股劲。写字是把念头从脑子里搬到纸上的唯一办法：念头在脑子里是连续的、自洽的、越来越有道理的，搬到纸上才会显出它有多薄。

什么时候不成立：一、对必须即时成交的场景（复牌、一字板、马上要止损失控的平仓），延迟一天等于放弃，这类动作走风控流程，不走本条；二、对定投与再平衡这类机械规则，延迟一天只会破坏纪律；三、如果你等了一天还是想买，这不代表延迟失败——它只说明这笔该进入下一道审查（下单前五问），本条是过滤器，不是判决书。

## 收益

量级（口径：亏损）：唯一可量的是清单条目本身。本例一条 36,000 元、占总资产 9% 的买入意愿，隔日复审时消失；若周一晚直接买入，到第三日账面 −1,800 元（占总资产 0.45%）。这个数怎么用：先统计自己一个月的意愿消失率（本例 5 ÷ 7 ≈ 71%），再决定要不要把「等一个交易日」设成默认规则——消失率越高，说明你的买入念头里冲动占比越大，一天时间盒越值钱；消失率接近零，说明你本来就不冲动，这套机制的边际价值低，别为它消耗意志力。

## 备注

- **适用前提**：只对「想买」类动作生效；止损、平仓、降杠杆等风控动作必须即时执行，走 [[买入之前先写下「错了怎么办」]] 的事前条件，不走延迟。定投与再平衡的自动扣款不受清单约束——那是制度，见 [[自动化纪律:把规则交给制度]]。
- **已知反例**：真实情形一，制度层面的对照是存在的——金融消费领域普遍设有冷静期或犹豫期（如人身保险的犹豫期，具体天数以合同与监管规定为准，本条不引用具体数字），说明「延迟」是被监管者认可的保护机制；但股票交易没有法定冷静期，且延迟对真机会的代价真实存在：复牌、一字板、突发利好后的标的，一天之后可能买不进或贵得多，延迟对待这类标的事实上等于放弃。真实情形二，失效形态常见于清单本身：条目只写理由不写金额（无法判断规模）、复审时间不写（随时可看）、监督人是交易圈朋友（鼓励而非拦阻）。
- **关联条目**：[[锚定效应：成本价、高点都是锚]]（「跌下来了更想买」的机制）、[[赌徒谬误：「跌多了该反弹了」]]（同一个念头的另一面）、[[频繁交易的换手成本]]（意愿消失率高的账户通常换手也高）、[[事前检查清单:下单前强制回答五问]]（通过延迟后的下一关）、[[投资日记:记决策不记盈亏]]（清单归档条目并入日记）、[[情绪标记法:先命名再操作]]（五分钟筛冲动，一天筛执念）。
- **有效期**：五字段、默认时长与归档规则为自设，可改；改默认时长时必须同步改「写入时间 / 复审时间」两个字段的填写说明。算例中的价格、股数、比例全部为假设参数。核对日期 2026-10-12。
- **与其他修行条目的顺序**：先 [[情绪标记法:先命名再操作]] 筛掉急性冲动（五分钟），再用本条的清单筛掉隔夜执念（一天），两关都过才进 [[事前检查清单:下单前强制回答五问]]；顺序颠倒会让五问的答案写在情绪峰值上，成色最差。
