## 怎么做

**什么时候用**：三个时点，其他时间不要打开。①买入前十分钟：写「买入记录」，只写事实与理由，不许写「预计涨到多少」；②卖出后当天：补「结果记录」，只补事实，不改上面任何一个字；③每周固定一个时间盒（建议二十分钟）：读本周记录，只做归类与提问。浮亏的时候打开日记是情绪书写，不是复盘——那是它唯一不该被使用的时刻。

**步骤**

1. **建一个文件，九个字段固定不变**：日期时间 / 标的与代码 / 方向 / 金额 / 仓位占总资产比例 / 买入理由 / 信息来源 / 情绪 / 可逆性。字段不许增删，增一个「目标价」字段，整本日记的方向就歪了。
2. **买入记录在下单前写完**，写完才允许下单；写不完就说明这笔不该买——空着不写也是记录，写「今天想买 999999，理由写不出来，未买」。
3. **买入理由必须含一个可观测指标**（成交额、排名、某个财报数字、某条公告），不能是「感觉要涨」「资金在进」。判定标准：一周后你还能不能用同一个指标重新验证这句话。
4. **信息来源逐条列，并标注是否互相转引**：两条群聊消息说的是同一句话，算一条。独立链的条数才是这一栏的数字，消息的条数不是。
5. **情绪只准写一个词**：兴奋 / 怕错过 / 不甘心 / 心安。写一句话（「又慌又想赌」）等于没写，一周后你无法用一句话归类。
6. **可逆性写两条**：多久能退出、退出有没有额外成本（赎回费、锁定期、跌停卖不出去）。这一栏是给「错了怎么办」兜底的，见 [[买入之前先写下「错了怎么办」]]。
7. **卖出当天补三条**：卖出价、触发的是哪一条事前写下的条件、卖出时的情绪。事前没有条件的，这一栏写「无事前条件」——这就是一条坏记录，要留着，它是你下周的整改对象。
8. **原文冻结**：买入记录落笔即不许改，要补充就新起一段写「补充」。这是整条的地基——一旦允许改，日记就退化成一个可以被自己随时编辑的故事。
9. **每周一次时间盒复盘**，只问四个问题：本周几条记录？每条的信息来源有几条独立链？哪条记录里出现了新的偏差词（对表 [[确认偏误：你的信息流只喂你想看的]] 与 [[羊群行为：为什么市场会「一起错」]]）？有哪条买入记录被改过字？
10. **每周按四格归类**：把本周记录照 [[结果偏误：按盈亏判决策是最常见的错]] 的口径分进「过程对且赚 / 过程对但亏 / 过程错但赚 / 过程错且亏」四格，重点盯第三格。

**九字段填写标准（写不出这一栏，就等于这一栏不合格）**

| 字段 | 合格的样子 | 不合格的样子 |
|---|---|---|
| 日期时间 | 2026-03-02 14:52 | 「上个月」 |
| 标的与代码 | 999999 | 「那只券商股」 |
| 金额 | 60,000 元 | 「一点仓位」 |
| 仓位占比 | 60,000 ÷ 600,000 = 10% | 「不多」 |
| 买入理由 | 「板块成交额连续三日放大，个股涨幅第一」 | 「感觉要涨」 |
| 信息来源 | ①行情软件板块排行 ②群聊两条（互转，算一条）→ 独立链 1 条 | 「听人说的」 |
| 情绪 | 「怕错过」 | 「有点紧张但又想买」 |
| 可逆性 | 次一交易日可卖，无锁定期 | 没填 |

**算例**（假设案例，标的为占位代码 999999，不指向任何真实公司；价格、股数、比例全部为假设参数）

初始条件：总资产 60 万元。2026-03-02 买入 999999 共 3,000 股，成交价 20.00 元，金额 60,000 元，占 10%；事前写下「跌破 18.00 元离场」。2026-03-10 以 17.95 元卖出，得 53,850 元，实际亏损 6,150 元。

**记法 A：只记盈亏（账本式）**

| 日期 | 动作 | 价格 | 金额 | 盈亏 |
|---|---|---|---|---|
| 03-02 | 买入 999999 | 20.00 | 60,000 | — |
| 03-10 | 卖出 | 17.95 | 53,850 | −6,150 |

三个月后翻看，能得出的结论只有一句：「追高吃了亏，以后不追高。」这句话不可执行——「追高」没有定义，涨多少算高？它也不能解释两件事：为什么这次明明触发了止损还是亏了 6,150 元而不是预算的 6,000 元；下次再遇到「板块成交额放大」，这条记录给不出任何可用信息。

**记法 B：记决策（本条模板）**

买入记录（2026-03-02 14:52，下单前写完，此后冻结）：

| 字段 | 内容 |
|---|---|
| 日期时间 | 2026-03-02 14:52 |
| 标的与代码 | 999999 |
| 方向 | 买入 |
| 金额 | 60,000 元 |
| 仓位占比 | 60,000 ÷ 600,000 = 10% |
| 买入理由 | 所属板块近三日成交额连续放大，个股为板块内涨幅第一 |
| 信息来源 | ①行情软件板块排行（一手）②自选股群两条消息（互相转引，算一条）→ 独立链 1 条 |
| 情绪 | 「怕错过」（落笔时心跳快） |
| 可逆性 | 次一交易日可卖，无锁定期，滑点未知 |

结果记录（2026-03-10 收盘后追加，上文一字未动）：

| 字段 | 内容 |
|---|---|
| 卖出价 | 17.95 元 |
| 触发条件 | 事前写下的「跌破 18.00 元离场」——已触发 |
| 实际亏损 | (20.00 − 17.95) × 3,000 = −6,150 元，比预算的 6,000 元多 150 元（止损价到成交价的滑点） |
| 卖出时情绪 | 「松了口气」 |

一周后二十分钟时间盒复盘，从这份记录里能读出五件事——同一笔亏损，两种记法的差别全在这里：

| 复盘问题 | 记法 A（账本） | 记法 B（决策日记） |
|---|---|---|
| 依据是什么 | 已遗忘，或被改写成「当时就知道要跌」 | 板块成交额 + 个股排名，一个可观测指标 |
| 信息来源几条独立链 | 无从查起 | 1 条（群聊两条互转只算一条） |
| 规则执行了没有 | 「亏了就是没做好」 | 事前写了 18.00 元，触发了，执行了——过程对但亏 |
| 亏损与预算的差 | 没有「预算」这个概念 | 6,150 − 6,000 = 150 元，是滑点，下周把止损单改进条件单 |
| 三个月后能复现什么 | 一句「不追高」 | 一张能逐项核对的表 |

记法 B 产出的三个可执行动作：①信息来源补到两条独立链（这一笔只有一条，是记录里唯一的硬伤）；②止损单改用条件单，消除 150 元滑点；③把「怕错过」这个词留在情绪栏，下次落笔前先识别它。而 [[结果偏误：按盈亏判决策是最常见的错]] 与 [[后见之明：「我早看出来了」是错觉]] 在个人层面的样子，正是这件事：不是市场在骗你，是你自己的记录方式把过程扔了、只留下结果，而结果是最容易被事后改写的那一部分。

**常见错**

1. **浮亏时打开日记写感受**——那是情绪书写，写出来的每个字都在为持仓找理由。写入时点只有买前与卖后，套中不写。
2. **复盘时修改买入记录**——「当时其实也想到了某风险」，一旦动笔改，三个月的记忆就被这一笔覆盖。要补就新起一段写「补充」，原文冻结。
3. **只记亏的、不记赚的**——最该记的是「过程错但赚」那一类，账本天然只记得亏，日记必须强制记赚，否则四格里的第三格永远是空格。
4. **把日记写成预测打卡**——每周回看「我猜对了没有」，两周就会放弃。评分对象是理由和信息来源，不是猜得多准。

**做完你会得到**：一个文件，每笔交易两组九字段记录（买入记录 + 结果记录），外加每周一张四格归类表。三个可直接执行的产出：本周几条记录的信息来源只有一条独立链（下一条的目标：补到两条）；几条记录缺「触发条件」栏（下一条的目标：买入前先写离场条件）；本周发生几次记录改写（目标：零次）。

**怎么算过关**：随机抽一个月里的一笔亏损，你能在六十秒内报出四个数——买入金额、仓位占比、事前写下的离场条件、实际亏损与预算的差额；报不出任何一个，说明这笔当时只记了盈亏。再抽一笔赚钱的交易，说出它的信息来源有几条独立链——答「没注意」，这条就是「过程错但赚」，正是下次最该拆的一类。

## 说人话

是什么：大部分人记的其实是账本——哪天买了什么、多少钱、赚了还是亏了。账本只能回答「我运气如何」，回答不了「我当初为什么这么决定」。投资日记记的是后者：下单那一刻你是怎么想的、依据是哪一条、心跳快不快、能不能反悔。这些才是下次能改的东西。

为什么发生：因为结果是市场最后塞给你的，理由是当时你自己写的。不写下来，理由就会在记忆里被结果悄悄替换——赚了，记忆里那个理由变得比当时更充分；亏了，它变得比当时更蠢。于是一次亏损过去三个月，你能想起来的只剩「我亏了多少」和一个被改写过的模糊影子，下次遇到同样的场面，那场面在你眼里是全新的，于是同样的错可以犯很多次，而每一次都觉得是第一次。

什么时候不成立：一、如果你是几年才做一两笔的长期持有者，单笔的「理由」基本等于公司基本面，日记的边际价值低于把持有逻辑写清楚这件事本身；二、如果你从来不按自己写下的规则办事，日记只是新一本账本，先解决「写了不做」；三、日记不防止你亏钱，它只保证你亏的那笔在三个月后还能被完整复盘——把它当止损工具用会失望。

## 收益

无量级（方向性）：它改变的是复盘质量与重复犯同一类错的概率，金额无法预设——同一笔亏损在两种记法下的盈亏完全相同（都是 −6,150 元），差别在三个月后你能不能说出「依据是什么、信息来源几条链、规则执行了没有」。可自查的口径只有一个：随机抽三笔过往交易，几笔能在六十秒内报出「事前写下的离场条件」——低于两笔，说明你的历史记录里只有账，没有决策。

## 来源

1. **后见之明的机制**：Fischhoff, B.（1975）《Hindsight ≠ Foresight: The Effect of Outcome Knowledge on Judgment Under Uncertainty》，Journal of Experimental Psychology: Human Perception and Performance, 1(3), 288–299。知道结果之后，人会系统性地高估自己事前「早就知道」的程度——这是「只记盈亏」会让记忆被结果改写的机制来源。文献引用，只引定性结论，无 URL。核对于 2026-10-12（书目信息）。
2. **结果偏误的机制**：Hershey, J. C. & Baron, J.（1988）《Outcome Bias in Decision Evaluation》，Journal of Personality and Social Psychology, 54(4), 569–579。同一份决策过程，只向评价者透露结果好坏，就足以改变其对决策质量的评分——本条据此把「记决策」与「记结果」拆成两组互不覆盖的字段。文献引用，只引定性结论，无 URL。核对于 2026-10-12（书目信息）。
3. **机制表述的开放核对页**（本站 curl 200，2026-10-12）：`https://en.wikipedia.org/wiki/Hindsight_bias`、`https://en.wikipedia.org/wiki/Outcome_bias`。百科不是一手来源，仅用于核对两条机制的标准表述；本条的定性结论以上述两篇原始文献为准。
4. **等级声明**：本条的「九字段模板」是自设工具，不属于任何已发表研究，没有对应实证出处。来源只支撑「记忆会被结果改写」「评分会被结果污染」这两个机制；模板字段是这两个机制的工程化，等级记 B。散户记日记与否对收益的影响「无公开统计」（就这一确切问题确认不存在公开研究，不是本站没查到），本条不作任何此类主张。

## 备注

- **适用前提**：只适用于你自己下的单。基金定投、他人管理的账户没有「决策」可记，要记的是纪律有没有破。一年只做一两笔的长期持有者，优先级低于把持有逻辑写清楚。
- **已知反例**：真实情形——机构与专业交易者普遍有交易日志（事后交易报告、决策备忘录），形式与本条一致，但那是留痕与合规工具，且多数有第三方复核；散户版没有复核人，日志不变形全靠「原文冻结」这一条自设约束维持，没有外部机制保证。另有已发表研究（Bastardi、Benartzi & Sunstein，Management Science，2005 一系的结果偏误实验）发现经验丰富的交易者因知道「结果噪音大」而较少表现结果偏误——经验本身是对冲，但依赖自觉，不构成对普通人的豁免。（书目引用，原文未逐条核对，无 URL；核对于 2026-10-12）
