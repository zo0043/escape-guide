## 怎么做



**什么时候用**：你听说了某只「别人都在买」的票，却说不清它好在哪的时候；或者你在生活里先发现某个产品、门店很好，想查查它有没有上市的时候（这是正面用法）。

**步骤**
1. 写下「我知道、而市场还不知道或不理解」的关于这家公司的事，一句话；
2. 写不出来就不买——哪怕它最近涨得多好；
3. 若线索来自生活观察，补一步：把「产品好」换算成「它靠什么赚钱、能不能持续」；
4. 把这个判断记下来，日后核对是你对还是市场对。

**算例**（假设案例，不指向任何真实公司）：你在消费品行业工作。近两个月你发现自家公司的新品卖得特别好：销售端动销明显加快，两家同行来找你谈代工。你查到一家上市公司「票 A」做同类生意。同时朋友推荐「概念票 B」（最近很火，你说不清它怎么赚钱）。

| 动作 | 结果 |
|---|---|
| 为票 A 写认知差一句话 | 「它的新品动销连续加快，我的渠道周转明显变快，两家同行已谈代工——市场尚未反映在股价里」 |
| 这句话能否被公司公开披露验证 | 能（看中报营收、存货、新品收入占比）→ 继续 |
| 为票 B 写认知差一句话 | 只能写出「它在涨、很多人在谈」→ 信息项 0 → 放弃 |
| 票 A 的仓位（若验证通过） | 小验证仓：闲钱的 5%（假设参数）——先确认信息为真，再谈加不加 |
| 票 B 的仓位 | 0 |

算例说明：5% 验证仓是自设参数，用来验证「认知差是否真实」，不是加仓决定；若公开披露不支持那句话，仓位撤掉，而不是「拿着等」。

**常见错**
1. 写「我觉得它会涨」代替信息——「我觉得」是感受，不是认知差；认知差必须指向具体的事（某个产品、某个渠道、某批客户）。
2. 把「我用过」当「我懂」——天天用某个产品，不等于懂它怎么赚钱、风险在哪（见备注反例）。
3. 写完不验证——认知差那句话是假设，它的对错由公司披露决定，不由你写得好不好决定。

**做完你会得到**：一句话的「认知差」陈述（或一个明确写下的放弃决定），以及一份日后核对的判断记录。

**怎么算过关**：那句话是**信息**（你确实知道某件市场还没定价的事），不是**感受**（「我觉得它会涨」）；且你能说出这句话能在哪份公开披露里验证。

## 说人话

是什么：大摩基金经理林奇的名句：你所知的，胜过他们所知的。你天天用、天天吃、天天穿的东西，如果你比一般投资者更懂它的生意怎么赚钱、风险在哪，那就是你的信息优势。但「懂」必须可检验，不是感觉。

为什么发生：市场价格是共识的产物，共识来自公开信息。你有两类信息是共识里没有的：一是你所在行业和渠道的细节——产品真的卖得动、客户真的在换，这类信息会滞后于公司财报出现；二是你长期使用它的判断——耐不耐用、口碑、复购。你能把这类信息写成一句话，而且它未来可以被验证，你就有相对「只看研报的市场」的一点优势。

什么时候不成立：两种情形。其一，「熟悉」不等于「信息」——你天天用的东西，往往早就是人尽皆知的公开事实（最热门的产品全市场都知道它火），这时你的「懂」没有优势。其二，你写下来的本身就是错觉——人会高估自己懂的东西，上一轮概念股行情就是「我懂」的集体案例（见备注反例）。

## 备注

- **适用前提**：你确实身处那个行业、或确实长期用过那个产品；「认知差一句话」必须能在公司公开披露里验证（可以错，但要可验证）。A股语境下散户的信息优势通常限于自己所在的行业。
- **已知反例**：真实情形：二〇一五年 A 股行情中，大量散户追「自己知道的」（互联网加、共享类热门概念），认为「我懂它」——那种「懂」是表层印象，成了亏损的入口。这是「熟悉 ≠ 信息优势」的真实案例，本条 disputed 据此置 true。
- **关联条目**：[[看不懂的不碰]]（本条的反向）、[[查一家上市公司的基本盘]]（验证认知差一句话的下一步）、[[巴菲特：圈定能力圈，圈外不赚]]（能力圈是边界，林奇是边界内找线索的正向方法）。
- **有效期**：方法不过期；「认知差」本身有半衰期——市场把你的那句话定价进股价后，优势即消失。
