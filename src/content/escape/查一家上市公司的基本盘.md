## 怎么做

**什么时候用**：准备买入某只 A 股上市公司之前；或者听到一只股票的「实控人」「质押」「ST」相关说法，想自己动手核实的时候。

**步骤**
1. 打开巨潮资讯网（<http://www.cninfo.com.cn>，「信息披露」栏目），输入股票代码或公司名称，核对公司全称与代码一致（防止查错公司）；
2. 在披露栏目按「年度报告」筛选（半年报亦可），打开最新一份年报 PDF；
3. 在 PDF 里依次检索五个关键词并记录：「实际控制人」（谁真正控制公司）、「股东人数」（报告基准日有多少名股东）、「质押」（大股东是否质押所持股份、比例多少）、「分红」或「利润分配」（近三年分红记录），并记下股票简称上是否带 ST/*ST 标记；
4. 到交易所披露栏目（上交所 https://www.sse.com.cn/disclosure/listedinfo/announcement/ 或深交所 <http://www.szse.cn/disclosure/index.html>，两页均为动态加载，正文需人工查阅）找临时公告：有没有「股份质押」「风险提示」「ST」相关公告；
5. 把五件事汇成一页「基本盘五查记录」，每件写「看到了什么、在哪里看到的（哪份公告、什么日期）」。

**研报能不能信：先看谁付的钱**（第 5 步之后、把结论写进记录之前）

研报在站内被提到过多次，但没有一条讲怎么用——这里是它的位置：**研报是二手，永远不是一手**。它可以是线索（告诉你该去查哪份公告），不能是结论（替你看完那份公告）。三问过一遍再决定要不要采信：

| 问 | 为什么问 | 不通过时的处置 |
|---|---|---|
| 谁写的、谁付的钱 | 卖方研报由券商发布、其收入来自交易佣金与投行业务，存在结构性立场；署名分析师与机构名要能查到 | 只作线索，不进来源节 |
| 结论指向哪个公告 | 一条可核的研报论断，应能指回某份年报、问询回复或临时公告的具体段落 | 指不回去的，标「需人工核对」 |
| 数字和公告一致吗 | 研报的预测数字是估算，公告的数字是事实——两者混用即错 | 只引公告数字，估算另标 |

最容易踩的一处：把研报的**目标价**当成估值依据。目标价是「某机构在某假设下的估算」，既不是公告数字，也不对你承担任何责任；锚定效应条目已经指出，任何先看到的数字都会变成后面判断的标尺（见 [[锚定效应：成本价、高点都是锚]]）。正确用法是反过来——研报说「某业务将放量」，你去查这条业务在年报里的收入、毛利率与产能披露，放没放量以公告为准。研报的价值在它提出的问题，不在它给出的答案。

**算例**（假设案例：示例中的公司与代码均为占位，不指向真实公司）

初始条件：你准备核查某上市公司（假设名「XX 科技」，代码 999999 为占位）是否值得买入。

| 动作 | 数字／结果（假设） |
|---|---|
| 1. 巨潮搜索代码 999999，核对公司全称 | 命中 1 条：「XX 科技」，代码与名称一致 |
| 2. 年报栏目按近 1 年筛选 | 返回 1 份年度报告 |
| 3. PDF 检索「实际控制人」 | 命中 1 处：实控人「张三」（假设姓名），直接及间接持股 45% |
| 4. PDF 检索「股东人数」 | 报告基准日股东 12 万人（假设数字） |
| 5. PDF 检索「质押」 | 主要股东「张三」质押其持股的 30%（假设数字） |
| 6. PDF 检索「分红」 | 近三年每股分红 0.5 元、0.4 元、0 元（假设数字） |
| 7. 查交易所栏目临时公告（质押／ST 相关） | 0 条；股票简称无 ST/*ST 标记 |
| 8. 汇成五查记录 | 五项各带「看到了什么 + 在哪里看到」 |

结论：五件事都「正常」，得到的也只是「未发现风险披露」，不是「这家公司安全」；任何一项异常（实控人不明、质押比例过高、简称带 ST 等），都是认真存疑或放弃的信号。

**常见错**
1. 查错公司：代码与名称对不上，查成了另一家公司的年报——核实的第一步是确认代码与全称一致；
2. 以为看完年报就算完——年报是报告基准日的快照，质押与 ST 状态会变，必须再查最新临时公告；
3. 看到「没找到质押公告」就认为「没有质押」——披露缺失不等于事实不存在，记录里应写「未见披露」，不是「无质押」。

**做完你会得到**：一页「基本盘五查记录」，五个字段（实控人、股东人数、股权质押、ST 风险、分红记录），每个字段带「看到了什么 + 在哪里看到（公告名称 + 日期）」——用来决定「这家公司能否进入『买多少』环节」，并在每次持仓复核时重新验证。

**怎么算过关**：五个字段全部填写，每个字段都能回答「这条信息从哪来」（哪份年报／哪份公告、什么日期）；查不到的字段写「未见披露」而不是留空。

## 说人话
是什么：年报是公司的自画像，自画像要对着原件看。五件事就是五个「原件」：谁真正控制这家公司，多少人分着这块蛋糕，大股东有没有把蛋糕抵押出去，公司有没有被挂上风险警示的牌子，公司过去有没有真的给股东分过钱。

为什么发生：市场的「故事」通常讲的是公司的未来，而五件事问的是公司的「现在」：实控人决定你实际押注的是谁，质押比例决定大股东会不会被迫卖出，ST 风险决定你是否在受限制的状态里，分红记录决定它是不是只会讲未来。未来可以讲，现在可以查。

什么时候不成立：这套流程有边界，其一，五件事只能核实「披露过的信息」，核不了没披露的事实——公告少或披露延迟时，你得到的是「未见披露」，不是「没问题」；其二，五件事是入门级检查，不是完整尽调——如果要投大钱，财务报表和行业逻辑仍要逐项读；其三，五件事与研报三问都只对「公开信息」负责，任何「内部消息」「未公开调研」都不在这套流程能核的范围内（见 [[别转发「内部消息」：编造传播本身就是违法]]）。

## 收益

无量级（方向性）：它拦掉的是「持有一家不知道实控人、质押与风险状态的公司」这类亏损，金额取决于公司与仓位，无法预设。可自查的口径只有一个：你的每只持仓，能否答出五件事并指得出来源。
