## 怎么做

**什么时候用**：你准备买入一只基金（主动、指数、ETF 均可）之前；或已经持有、想做定期体检的时候；以及听到「明星基金经理」「历史业绩」想自己核实的时候。这条把「查什么、在哪查、A 股有哪三个特别的坑」走成一遍流程。

**步骤**

1. 先定性：指数基金还是主动基金？指数基金重点查跟踪与费率，主动基金重点查人与风格——入口相同，侧重点不同；
2. 找最新一版招募说明书，读四件事：投资范围与业绩基准、费率结构、申购赎回规则、基金经理与改聘条款；
3. 拉最近两期季报加最近一期年报，看三件事：规模变化、持仓集中度、报告期股票成交金额（用来算换手率）；
4. 到基金业协会信息披露平台核对产品与管理人公示、基金经理有无变更记录；
5. 专查 A 股三个坑：明星经理换人、迷你规模贴近清盘线、打新收益占比；
6. 汇成一页核查记录，每项写「看到了什么 + 在哪份文件、什么日期看到的」。

**查什么：核心五件事（另加两项补充）**

| 查什么 | 在哪份文件 | 具体看什么 |
|---|---|---|
| 招募说明书（最新版） | 基金公告（巨潮） | 投资范围与业绩基准、费率、申赎规则、经理条款 |
| 季报（最近两期） | 基金公告 | 规模变化、前十持仓、报告期股票成交金额 |
| 换手率 | 半年报 / 年报的成交金额自己算 | （买入 + 卖出）÷ 2 ÷ 平均净资产，口径写清 |
| 费率 | 招募说明书「基金费用」 | 管理费、托管费、销售服务费、申购赎回费 |
| 规模 | 定期报告「基金资产净值」 | 趋势（连续下滑 = 迷你化），不是单期绝对值 |
| 业绩比较基准 | 招募说明书「基金的业绩比较基准」 | 基准是什么，决定这只产品「本该」长什么样 |
| 分红方式 | 招募说明书「收益分配」 | 现金分红还是红利再投资，默认选项是什么 |

**指数基金专项**（被动产品的核查重点换一行）：跟踪误差（与基准的日收益差）、费率（决定长期差距的主项）、规模与流动性（ETF 看盘口深度与折溢价）、是否还是宽基（有没有漂移成主动）。这三四项在招募说明书、定期报告与交易所行情里都能拿到；跟踪误差的基准数字可以自己按日重算（工具见 [[查历史数据:中证指数与FRED怎么用]]）。主动基金的「人」这一维，在指数基金里基本不存在——所以五个坑里只有费率与规模两个适用。

**在哪查：入口以本站 2026-10-12 实测为准**

| 站点 | 本站状态 | 用途 |
|---|---|---|
| 巨潮资讯网 `www.cninfo.com.cn` + 基金公告检索接口 | HTTP 200，检索实测可用 | 招募说明书、定期报告全文（PDF） |
| 基金业协会信息披露平台 `gs.amac.org.cn`（含公募基金栏目） | HTTP 200 | 产品公示、管理人公示 |
| 中国证监会 `www.csrc.gov.cn` | HTTP 200 | 基金管理公司名录、规则文件 |
| 天天基金 F10 `fundf10.eastmoney.com` | HTTP 200，内容动态加载 | 费率 / 规模 / 经理的汇总展示，字段需人工目检 |
| 深交所披露栏目 `www.szse.cn` | HTTP 200 | 上市基金（ETF / LOF）公告 |
| 上交所基金栏目 | **HTTP 403，本环境打不开** | 标「需人工核对」，换巨潮或深交所 |

巨潮基金公告检索的可用姿势（2026-10-12 实测，返回公告标题与 PDF 地址）：

```bash
curl -s -X POST "http://www.cninfo.com.cn/new/hisAnnouncement/query" \
  -d "pageNum=1&pageSize=10&column=fund&tabName=fulltext&searchkey=招募说明书&seDate=2026-01-01~2026-10-12"
```

实测返回：`searchkey=招募说明书` 命中 1,550 条、`searchkey=季度报告` 命中 1,065 条（窗口 2026-07-01~2026-10-12），字段含 `secCode / secName / announcementTitle / adjunctUrl`（PDF 链接）。第三方汇总页（天天基金 F10 一类）字段全但会变，只当目录，不当证据。

**A 股特有坑（三个）**

1. **明星基金经理换人**。你冲着经理来，公布季报时经理已换——「基金经理变更公告」与协会公示里查得到，排行榜不提示。变更后的历史业绩与新经理无关，把它当作「这只产品过去的表现」，不要当作「这个人的能力」；
2. **迷你基金清盘线**。规模长期贴近清盘线会触发清算（常见触发条件为连续若干工作日资产净值低于五千万元或持有人不足二百人，以基金合同与现行运作办法为准——条款原文本环境未逐条核对，标**需人工核对**）。清盘不等于亏损，但等于「强制变现 + 可能的费用与冲击成本」，且通常发生在你最不想卖的时候。查规模趋势，不是单期规模；
3. **打新收益占比**。部分产品的历史业绩里，底仓打新收益占比可观。打新规则（市值门槛、中签分配、报价约束）变化会直接改变这块收益——它不是经理能力，是规则红利。在定期报告的费用与其他收益项里核对，把「非能力收益」从业绩里剔出来再评价（规则现行版本查 [[查规则只去这三个地方]]）。

**算例**（假设案例：基金名与代码均为占位，不指向任何真实产品；代码 999999 为占位符；所有数字为演示参数）

初始条件：你准备买「XX 行业混合」（假设名），总资产 500,000 元，计划投 50,000 元。按 20 分钟清单走一遍：

| 分钟 | 动作 | 入口 | 记录（假设结果） |
|---|---|---|---|
| 0–3 | 定性 + 找招募说明书 | 巨潮基金公告检索 | 找到最新版（假设：2026 年 6 月更新）；投资范围：股票资产 60%–95%；基准：某行业指数收益率 × 80% + 中债总指数 × 20% |
| 3–6 | 读费率 | 招募说明书「基金费用」 | 管理费 1.2%/年、托管费 0.2%/年、销售服务费 0.4%/年（假设） |
| 6–10 | 最近两期季报 | 巨潮 `searchkey=季度报告` | 规模：上期 8.0 亿 → 本期 0.6 亿（假设）→ 迷你化，预警 |
| 10–13 | 产品与经理公示 | 基金业协会信息披露平台 | 产品在公示中；基金经理 3 个月前变更（假设）→ 明星经理已换人 |
| 13–16 | 算换手率 | 年报 / 半年报成交金额 | 报告期股票买入 45 亿、卖出 42 亿，平均净资产 8 亿（假设）→ (45 + 42) ÷ 2 ÷ 8 = **543.8%** → 极高 |
| 16–18 | 费用与打新核对 | 季报费用与其他收益项 | 无打新专户（假设）；管理费按新经理任期已计 |
| 18–20 | 汇成一页 | — | 五项记录各带来源；结论：放弃（换人 + 迷你 + 高换手三项同时出现） |

如果这份清单的结论是「买」，20 分钟只是第一遍——持有之后每季再走一遍简版（只看规模、经理、费率三项是否变化）：

| 频次 | 查什么 | 触发动作 |
|---|---|---|
| 每季（季报披露后） | 规模趋势、经理是否变更、费率是否调整 | 经理换人 → 重估「我买的是人还是产品」；规模连续下滑 → 准备退出 |
| 每年（年报披露后） | 全年换手率、费用明细、打新依赖 | 换手率异常抬升 → 问「风格漂移了吗」 |

结论：20 分钟买到的不是「这只基金好不好」的答案，是「这只基金的经理、规模、费率、换手率、打新依赖分别是什么、从哪看到的」记录。五项里两项以上触发预警（换人、迷你化、换手率异常、打新占比高），动作是不买或只放试探仓；零项触发，才进入「买多少」的环节（见 [[博格：别试图跑赢市场，定投宽基指数]]、[[先分清三种钱：保命钱、闲钱、搏钱]]）。上表换手率口径：报告期成交金额为半年报或年报披露口径，除以平均净资产，不是年化外推——引用时连口径一起写。

**常见错**

1. 只看排行榜和历史业绩——业绩是结果，清单查的是「这个结果是谁、在什么规模、靠什么产生的」；
2. 把单期规模当趋势——迷你化的信号是连续多期下滑，单期变小可能只是申購节奏；
3. 把第三方汇总页当唯一来源——天天基金 F10 一类页面字段全但会变、内容动态加载，以招募说明书与定期报告原文为准；
4. 忽略打新收益——收益结构里的「非能力部分」要在买之前识别，不是亏了之后；
5. 上交所基金栏目打不开就换源硬闯——本环境返回 403，换巨潮或深交所，或标「需人工核对」。

**做完你会得到**：一页核查记录，五个字段（招募说明书版本与费率、最近两期规模、现任经理与上任日期、报告期换手率、打新依赖），每字段带「从哪份文件、什么日期看到的」。

**怎么算过关**：对任一你想买的基金，你能报出五项：费率合计（管理 + 托管 + 销售服务）、最近两期规模、现任经理上任日期、报告期换手率、有无打新依赖；任何一项答「不知道」，结论就是还没查完，动作是不买。

## 说人话

是什么：买基金之前要查五件事：合同怎么写、报告怎么说、人换没换、规模多小、钱是怎么赚的。工具是几个官网：巨潮拿全文，基金业协会查公示，交易所拿上市基金的公告。第三方页面可以当目录，不能当证据。

为什么发生：基金是「别人的操作」，你看到的业绩曲线是结果；曲线背后是谁在管、管多大一笔钱、靠什么赚的，全在定期报告里。A 股有三个特别的坑：冲着明星经理来，来的时候经理已经换了；规模小到贴着清盘线，不知不觉被强制变现；业绩里有相当一块来自打新，那不是经理的本事，是规则的红利，规则一变就没了。

什么时候不成立：两种情形。其一，纯被动指数基金的核查重点不同——跟踪误差、费率、规模（流动性）三样就够，人的因素让位于产品设计；其二，任何一次核查都是时点快照，规模、经理、费率都会变，所以这条是「买之前查一次、持有后每季查一次」的流程，不是「查完就保险」。

## 收益

量级（口径：亏损）：算例里，20 分钟的清单拦掉的是「经理换人 + 规模从 8 亿降到 0.6 亿 + 换手率 543.8%」的一只假设基金；费率一项，管理费加托管费加销售服务费合计 1.8%/年（假设参数），按费前年化 7.02%（官方口径，取自 [[A股长期收益与回撤]]）、本金 500,000 元、10 年复利计算，1.8% 与 0.3% 两档费率的终值差约 **13 万元**（824,407 元 vs 956,335 元，可复算）。这个数怎么用：把想买的每只基金先过这 20 分钟清单，五项里两项以上触发预警就不买——省下的是「买错产品」这一类亏损，金额取决于投入，但流程对每只基金都只花 20 分钟。

## 备注

- **适用前提**：面向公募基金（主动、指数、ETF / LOF 均可）；私募、专户、雪球一类结构性产品的核查入口不同，私募公示走协会平台，结构性产品条款见 [[别用杠杆工具]]；
- **已知反例**：真实情形：规模长期偏小的基金中，亦有业绩持续优秀、直至做大规模者——迷你化是风险信号，不是业绩判决；换手率高的基金里亦有成功的事件驱动型选手。反例推翻的是「三项全中必亏」的强命题，不推翻本条的动作判据：三项同时出现时，你至少要知道自己买了什么；
