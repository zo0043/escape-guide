## 怎么做

**什么时候用**：两处。①单笔交易结束后（卖出当天或定投扣款日），给这一笔打一次分；②月末汇总一次，看四格分布与维度短板。不用于盘中——盘中没有「已完成的过程」可评，那段时间的用途是执行，不是评价。

**步骤**

1. **先打分，后看账**：打开评分表时，账户盈亏那一栏必须是盖住的（另一张表、另一个文件、或者干脆关机重启后再看）。流程顺序不可交换，这是本条唯一不能被简化的地方。
2. **四个维度各 25 分**：信息质量 / 推理链 / 仓位与可逆性 / 预案，总分 100。每个维度只从三档锚点里选（见下表），不许打 17 分这种需要解释的分数。
3. **评分的唯一依据是 [[投资日记:记决策不记盈亏]] 的字段**：日记里没有的字段，该维度直接按最低档打，不许凭记忆补。没有日记就没有过程分，先补记录。
4. **70 分是合格线**：≥ 70 记「合格」，< 70 记「不合格」，且必须写一条整改项，具体到字段（「补一条一手来源」「把止损单改进条件单」「仓位降到 15% 以下」）。写不出整改项的低分是无效评分。
5. **两张表永不相加**：过程分一张表，实际盈亏另一张表；任何汇总、排名、月度总结里都不许把两个数加在一起或互相抵消。
6. **月末按四格归类**：照 [[结果偏误：按盈亏判决策是最常见的错]] 的口径，把本月交易分进「过程对且赚 / 过程对但亏 / 过程错但赚 / 过程错且亏」，重点盯第三格（过程分 < 70 但赚钱的那些）。
7. **连续两个月没有一笔不合格，要自查**：要么你的流程真的稳定（罕见），要么评分在放水——抽查一笔过程分 ≥ 85 的交易，看它的四个维度是否都拿得出日记里的证据。

**月末汇总表（十分钟，只看过程，不看盈亏）**

| 统计项 | 本月 | 上月 | 说明 |
|---|---|---|---|
| 评分笔数 |  |  | 含定投扣款日 |
| 平均过程分 |  |  | 只统计过程表 |
| 最低的维度（四个里最差的那个） |  |  | 下个月只改这一个 |
| 过程分 < 70 的笔数 |  |  | 每笔须有整改项 |
| 「过程错但赚」的笔数 |  |  | 本月最危险的一格 |
| 连续零不合格的月数 |  |  | 到两个月就抽查 |

汇总表的每一行都只引过程表，不引盈亏表；两张表在文件里分开放，文件名都不要写「收益」。

**为什么是四个维度而不是一个总分**：一个总分只能告诉你「不合格」，四个维度才能告诉你「不合格在哪」。案例 A 的总分是 10 分，但真正要改的是信息质量与预案两项——仓位与可逆性那一项的 0 分是这两项的结果（因为没有预案，所以只能满仓）。反过来，案例 B 的 85 分里藏着两个 5 分的扣点，它们指向两个完全不同的整改动作。维度拆得越细，整改项越具体；整改项越具体，下一笔的过程分才真的动得了。

**四个维度与三档锚点（每维度 25 分）**

| 维度 | 20–25 分 | 10–15 分 | 0–5 分 |
|---|---|---|---|
| 信息质量 | 独立链 ≥ 2 条，至少 1 条一手（公告 / 财报 / 交易所数据），且记在买入前 | 2 条但互相转引；或都是一手但买入后才补记录 | 单一来源（群聊 / 博主 / 短视频），或说不出来源 |
| 推理链 | 买入理由含可观测指标 + 证伪阈值，且阈值能在买入前检验 | 有指标无阈值；或阈值要买入之后的数据才验得完 | 叙事句（「感觉要涨」「资金在进」），或理由写不出 |
| 仓位与可逆性 | 单一标的 ≤ 总资产 15%，且写下离场条件与最大亏损金额 | 仓位 15%–30%；或只有金额、没有离场条件 | 满仓 / 单吊 / 借钱 / 杠杆；或不知道仓位占比 |
| 预案 | 止损位 + 最大亏损金额 + 止盈或证伪条件，三样写在买入前 | 缺一样（缺一样在该档内再扣 5 分） | 一样都没有；或写的是「跌了再补」 |

**算例**（假设案例，标的为占位代码 999999，不指向任何真实公司；金额、价格、概率全部为假设参数）

两笔交易，同一个账户，同一个月。账户总资产 30 万元。

**案例 A：赚钱的坏决策**

| 项 | 内容 |
|---|---|
| 信息来源 | 自选股群一条推荐，群内三人转发同一张图（互相转引） |
| 买入理由 | 「老师说的，要启动」 |
| 仓位 | 30 万元全额买入 999999，占总资产 100%，单吊一只 |
| 预案 | 无止损、无证伪条件、无最大亏损金额 |
| 结果 | 两周后 +18%，卖出得 354,000 元，赚 54,000 元 |

过程分：信息质量 5 + 推理链 5 + 仓位与可逆性 0 + 预案 0 = **10 分（不合格）**；实际盈亏 **+54,000 元**。

**案例 B：亏钱的好决策**

| 项 | 内容 |
|---|---|
| 信息来源 | ①公司季报（一手）②行业数据库（一手，与季报口径独立）→ 独立链 2 条 |
| 买入理由 | 「三季度营收同比增四成、经营现金流转正；若四季报营收增速跌破 10%，判断失效」 |
| 仓位 | 45,000 元，占总资产 15%，事前写下离场条件 |
| 预案 | 止损位对应 8% 幅度，最大亏损 3,600 元，条件单已挂 |
| 结果 | 第 5 个交易日触发止损，实亏 3,600 元（止损单为手动执行，非条件单自动成交） |

过程分：信息质量 20 + 推理链 20（阈值需四季报数据，属买入后验证，扣 5）+ 仓位与可逆性 25 + 预案 20（止损未走条件单，扣 5）= **85 分（合格）**；实际盈亏 **−3,600 元**。

**对照评分表（同一张表，两栏）**

| 维度（各 25 分） | 案例 A | 案例 B |
|---|---|---|
| 信息质量 | 5 | 20 |
| 推理链 | 5 | 20 |
| 仓位与可逆性 | 0 | 25 |
| 预案 | 0 | 20 |
| **过程分** | **10（不合格）** | **85（合格）** |
| **实际盈亏** | **+54,000 元** | **−3,600 元** |
| 按结果会学到的 | 「满仓单吊听推荐也能赚，下次还敢」 | 「止损就是亏钱，下次不设」 |
| 按过程会学到的 | 「下次先补两条独立链、先写预案」 | 「下次把止损单挂进条件单，别手动」 |

案例 A 多算一步：把「满仓单吊 + 群聊推荐」当成一个可以重复的策略，它的盈亏分布（假设参数：50% 概率 +18%、50% 概率 −25%）期望 = 0.5 × 54,000 + 0.5 × (−75,000) = **−10,500 元**。这 54,000 元是负期望分布里的一个样本；而且满仓 −25% 之后需要 **+33.3%** 才回本（亏的不对称，见 [[一笔数学：亏一半要赚一倍才回本]]；仓位与期望的关系见 [[期望值与破产：仓位是算术问题]]）。案例 B 的 3,600 元则是同一套流程的**成本**——买保险也付保费，止损金就是这笔保费。

月末四格归类：案例 A 落「过程错但赚」（本月最危险的一格，它的记忆权重最大），案例 B 落「过程对但亏」。若只看账户，本月净赚 50,400 元，是个「好月份」——而这正是 [[结果偏误：按盈亏判决策是最常见的错]] 说的：好结果会教会你错误的东西。

**常见错**

1. **先看盈亏再打分**——分数会被结果牵着走，两张表做得再漂亮也没用；顺序是机关，不是仪式。
2. **凭记忆补字段**——「当时其实也想到了风险」，日记里没有的一律按最低档；要改的是记录习惯，不是分数。
3. **低分不写整改项**——「下次注意」不是整改项；合格标准是能指到具体字段和具体动作。
4. **把过程分和盈亏平均起来看**——「平均下来还行」等于把两个口径加在一起，正是本条要禁止的动作；两表永不相加。
5. **给赚钱的交易自动打高分**——这是结果偏误最常见的入口；抽查方法：本月过程分最高的三笔里，应该至少有一笔是亏钱的。
6. **同一维度反复打同一档却不整改**——三个月都卡在「信息质量 5 分」，说明改的不是评分习惯而是信息源结构（去补公告、财报、交易所数据），继续打分只是记录失败。

**做完你会得到**：一张月度过程分表（每笔四个维度分 + 总分 + 合格标记 + 整改项）、一张独立的盈亏表、一张四格归类表。三个可直接执行的产出：哪个维度平均分最低（下个月只改这一个）；几笔的过程分 < 70（每笔对应一条字段级整改）；「过程错但赚」有几笔（每笔都要在日记里写清它错在哪）。

**怎么算过关**：随机抽两笔交易——一笔赚钱的、一笔亏钱的——你能分别报出它们的四维分数和整改项，且赚钱那笔的分数不必然高于亏钱那笔；如果赚钱那笔的分数总是更高，说明你还在按盈亏打分。再看本月记录：是否至少有一笔「过程错但赚」被标了出来——一笔都没有，要么你只做了对的事（罕见），要么第三格被跳过了。

## 说人话

是什么：给每一笔做过的交易打分，但打的是「这笔决策做得怎么样」，不是「这笔赚了没有」。分数只有四个来源：你的信息来源干不干净、推理站不站得住、仓位留没留退路、事前有没有预案。赚亏一分都不进这张表。

为什么发生：因为盈亏是市场给的，决策质量是自己做的，两者之间隔着运气。如果打分的时候先看见盈亏，分数就会被结果牵着走——赚了，叙事句也变成「有逻辑」；亏了，照规矩止损也变成「太冲动」。所以流程上必须先打完过程分、封存，再去看账户。顺序就是这条的全部机关：把「先看结果」这个动作从流程里拿掉，评分才评的是决策。

什么时候不成立：一、一年只做一两笔的长期持有者，单笔评分样本太少，季度评一次即可，逐笔评是噪音；二、评分者是自己，没有第三方复核，自评分数天然偏高——所以合格门槛与整改项必须落到具体字段，落到字段才可被别人核对；三、过程分高不保证赚钱，它只保证你在重复一个可辩护的流程；把过程分当收益预测用，会失望。

## 收益

量级（口径：亏损）：评分表唯一固定的数字是四个维度各 25 分、总分 100、合格线 70 分；算例给出的反差是——同一账户同一个月里，**+54,000 元配过程分 10**，**−3,600 元配过程分 85**，两个方向同时说明结果替代不了过程。这个数怎么用：把 70 分当门槛，低于 70 的每一笔必须落到一个字段级整改（补一手来源 / 把止损单挂进条件单 / 仓位降到 15% 以下），写不出整改项的低分视为无效；连续两个月零不合格，按上面的抽查法验一遍评分有没有放水。
